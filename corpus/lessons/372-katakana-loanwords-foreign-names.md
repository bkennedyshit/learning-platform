# 37.2 — Katakana: Loanwords & Foreign Names

> *"Once you can read katakana, you can read thousands of 'Japanese' words you already know — they're English, French, and German in disguise."*

Katakana represents the same phonetic inventory as hiragana — the same 46 sounds — but with angular characters used for a different set of purposes. The effort to learn it is about 60% of hiragana (the sounds are already learned; only the shapes are new). The payoff is immediate: menus, product names, technology terms, and your own name in Japanese all become readable.

---

## 🎯 Learning Objectives

By the end of this chapter you will be able to:

1. Read and write all 46 base katakana characters with 100% accuracy.
2. Read voiced (dakuten), semi-voiced (handakuten), and youon katakana combinations.
3. Read extended katakana combinations used for non-Japanese sounds (ファ, ウィ, ティ, etc.).
4. Decode loanwords (gairaigo) from foreign languages written in katakana.
5. Write your own name in katakana.

---

## 📚 1. When Katakana Is Used

| Use | Examples |
|-----|---------|
| **Loanwords** (gairaigo) from Western languages | コンピューター (konpyuutaa = computer), テレビ (terebi = TV), コーヒー (koohii = coffee) |
| **Foreign names** (people, places, brands) | ビル (Biru = Bill), アメリカ (Amerika = America), マクドナルド (Makudonarudo = McDonald's) |
| **Onomatopoeia and sound effects** | ドキドキ (doki doki = heartbeat sound), ガーン (gaan = shocked) |
| **Scientific/technical terms** (some) | ウイルス (uirusu = virus), ロボット (robotto = robot) |
| **Emphasis** (like italics in English) | deliberately using katakana for a Japanese word for stylistic effect |
| **Foreign language words being cited** | ハロー (haroo = "Hello" being referenced) |

Learning katakana is faster when you explicitly map each character to its hiragana counterpart. Many pairs share visual similarities:

| Hiragana | Katakana | Sound | Memory hint |
|---------|---------|-------|------------|

## 📚 3. Dakuten, Handakuten, and Youon in Katakana

Identical rules to hiragana — same sounds, angular shapes:

**Voiced (dakuten):**
ガ ギ グ ゲ ゴ (g) | ザ ジ ズ ゼ ゾ (z) | ダ ヂ ヅ デ ド (d) | バ ビ ブ ベ ボ (b)

**Semi-voiced (handakuten):**
パ ピ プ ペ ポ (p)

**Youon (combined):**
キャ kya | キュ kyu | キョ kyo | シャ sha | シュ shu | ショ sho | チャ cha | チュ chu | チョ cho
(Same combinations as hiragana — see [37.1 - Hiragana — Foundation & Practice](37.1---Hiragana-—-Foundation-&-Practice) §4)

## 📚 4. Long Vowels in Katakana

**Critical difference from hiragana:** In katakana, long vowels are written with the **long vowel mark ー** (called *chōonpu*), not by repeating the vowel.

*コーヒー* (koohii = coffee) — two long vowels
*テレビ* (terebi = television) — no long vowels
*スーパー* (suupaa = supermarket) — two long vowels
*コンピューター* (konpyuutaa = computer) — one long vowel

> **The ー mark always extends the vowel that precedes it.** It is one additional mora of duration.

## 📚 5. Extended Katakana — Foreign Sounds

Japanese has expanded its katakana system to represent sounds not native to Japanese. These combinations use small vowel kana after consonants that don't normally pair with them:

| Combination | Sound | Example |
|------------|-------|---------|
| ファ | fa | ファイル (fairu = file) |
| フィ | fi | フィンランド (Finrando = Finland) |
| フェ | fe | フェスティバル (fesutibaru = festival) |
| フォ | fo | フォーク (fooku = fork) |
| ウィ | wi | ウィキペディア (Wikipeedia = Wikipedia) |
| ウェ | we | ウェブ (webu = web) |
| ウォ | wo | ウォーター (wootaa = water) |
| ティ | ti | ティーム (tiimu = team) |
| ディ | di | ディスク (disuku = disk) |
| トゥ | tu | — |
| デュ | dyu | デュアル (dyuaru = dual) |
| ヴァ | va | ヴァイオリン (vaiorin = violin) |
| ヴィ | vi | — |
| ヴ | v | ヴェルディ (Verudi = Verdi) |

> Not all speakers or texts use these extended forms consistently. Many older texts or speakers use the closest native Japanese approximation instead (e.g., ビ bi for vi).

## 📚 6. Loanword Decoding — The Game

The most immediately fun skill in Japanese: reading katakana loanwords and recognizing the original word. Many are transformed significantly by Japanese phonology:

| Katakana | Romaji | Original word |
|---------|--------|--------------|
| コンピューター | konpyuutaa | computer |
| スマートフォン | sumaatofon | smartphone |
| アイスクリーム | aisukuriimu | ice cream |
| マクドナルド | Makudonarudo | McDonald's |
| アップル | Appuru | Apple |
| グーグル | Guuguru | Google |
| バスケットボール | basukettobooru | basketball |
| チョコレート | chokoreeto | chocolate |
| パスワード | pasuwaado | password |
| ソフトウェア | sofutouea | software |
| アルゴリズム | arugorizumu | algorithm |
| データベース | deetabeesu | database |
| インターネット | intaanetto | internet |
| プログラミング | puroguramingu | programming |
| エンジニア | enjinia | engineer |

> **The transformation rules:** Japanese has no consonant clusters (except when ending in ン). Every consonant must be followed by a vowel, so clusters get vowels inserted: *stream* → *sutoriimu*. Final consonants also get a vowel: *disk* → *disuku*.

## 📚 7. Writing Your Name in Katakana

Japanese names are written in kanji (and sometimes hiragana). Foreign names are written in katakana. Find the closest phonetic approximation:

**Examples:**
- Bill → ビル (bi-ru)
- Sarah → サラ (sa-ra)
- Chris → クリス (ku-ri-su)
- Michael → マイケル (ma-i-ke-ru)
- Jennifer → ジェニファー (je-ni-faa)
- Robert → ロバート (ro-baa-to)

**Exercise:** Look up your name on a name-to-katakana converter and memorize your katakana name. You'll use it every time you introduce yourself in Japanese.

## ⚠️ 9. Commonly Confused Pairs

| Pair | Difference |
|------|-----------|
| ソ (so) vs ン (n) | ソ has a slanting bottom stroke going right; ン goes left. Critical — these are extremely common and easily mixed up. |
| シ (shi) vs ツ (tsu) | シ has two short strokes on the left going right-then-down; ツ has two going down-then-right. Orientation matters. |
| ア (a) vs マ (ma) | ア has a vertical left stroke; マ has a curved left stroke. |
| ウ (u) vs ワ (wa) | ウ has a small horizontal stroke at top; ワ's top extends to the right. |
| ヲ (wo) vs ヲ | ヲ is rare in modern katakana (only as grammatical particle, essentially never used). |

> **ソ/ン and シ/ツ are the most common source of reading errors among beginners.** Drill these pairs separately until instant.
