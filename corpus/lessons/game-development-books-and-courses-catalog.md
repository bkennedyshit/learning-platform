### 📖 Core Book Curriculum

| Title                                        | Author            | Focus                                  | Notes                                                   |
| -------------------------------------------- | ----------------- | -------------------------------------- | ------------------------------------------------------- |
| **C# 8.0 and .NET Core 3.0**                 | Mark Price        | Backend, Desktop Apps, Unity Scripting | Get a free preview via Packt or GitHub sample repos     |
| **Python Crash Course**                      | Eric Matthews     | Python Foundations                     | Pair with Automate the Boring Stuff videos on YouTube   |
| **Unity in Action**                          | Joe Hocking       | Unity Engine Game Dev                  | Check Unity Learn for free course pairing               |
| **The Art of Game Design**                   | Jesse Schell      | Game Design Theory                     | Combine with GDC talks by Jesse on YouTube              |
| **Blender For Dummies**                      | Jason van Gumster | 3D Modeling / Animation                | Use YouTube Blender Guru & CG Cookie for practice       |
| **3D Math Primer for Graphics and Game Dev** | Fletcher Dunn     | Linear Algebra, Vectors                | MIT OpenCourseWare Math courses for reinforcement       |
| **Designing VR Systems**                     | Gerald J. Kim     | VR Interaction & Systems               | Pair with Meta Learn and Stanford VR lectures (YouTube) |
| **Networking for Game Programmers**          | Andrew Mulholland | Netcode, Sockets, Latency              | Search for Unity Mirror or Photon tutorials on YT       |
