# 37.5 — Verb Conjugation: Polite vs Plain Forms

> *"Japanese verbs carry the entire grammatical weight of a sentence. The て-form alone unlocks twenty grammar patterns. Learn it cold."*

Japanese verbs conjugate to express tense, politeness level, potential, passive, causative, conditional, and more — all by changing the verb ending. This chapter covers the classification system (ichidan vs. godan), the full set of core forms in both polite and plain speech, and the all-important て-form.

---

## 🎯 Learning Objectives

By the end of this chapter you will be able to:

1. Classify any verb as ichidan (る-verb) or godan (う-verb) and explain the difference.
2. Conjugate verbs in polite present, polite past, polite negative, and polite past negative.
3. Conjugate verbs in plain (dictionary) present, plain past, plain negative, plain past negative.
4. Form the て-form for both verb classes and all irregular verbs.
5. Use the て-form in 5 core grammar patterns: て + ください, ている, てから, てもいい, てはいけない.
6. Form and use the potential form (can do), volitional form (let's / I'll), and conditional forms (たら, ば).

## 📚 1. Verb Classification

Japanese verbs fall into three groups:

| Group | Name | Dictionary form | How to identify |
|-------|------|----------------|----------------|
| **Group 1** | Godan verbs (五段) / u-verbs | Ends in any う-row sound: く,ぐ,す,つ,ぬ,ぶ,む,る,う | Includes most verbs ending in る where the preceding vowel is a/u/o |
| **Group 2** | Ichidan verbs (一段) / ru-verbs | Ends in **いる** or **える** (i-sound or e-sound + る) | The る follows an i or e sound |
| **Group 3** | Irregular | する (to do), くる (to come) | Just two — memorize completely |

> **The る ambiguity:** Some verbs end in る but are godan, not ichidan. The safest test: remove る and look at the preceding sound. If it's an i or e sound → likely ichidan. But exceptions exist: *帰る* (kaeru = to return) ends in える sound but is godan. When in doubt, look it up.

**Common ichidan (ru-verb) examples:**
*食べる* (taberu = eat), *見る* (miru = see), *起きる* (okiru = wake up), *寝る* (neru = sleep), *いる* (iru = exist/be), *着る* (kiru = wear), *できる* (dekiru = can/be able)

**Common godan (u-verb) examples:**
*飲む* (nomu = drink), *書く* (kaku = write), *話す* (hanasu = speak), *読む* (yomu = read), *行く* (iku = go), *来る* — wait, this is irregular! *買う* (kau = buy), *帰る* (kaeru = return — godan despite える)

## 📚 2. Polite Forms (ます-form)

The polite form is built from the **ます-stem** (also called the i-form or masu-stem).

### Getting the ます-stem
- **Ichidan:** Remove る → stem
  - *食べる* → *食べ* → *食べます*
- **Godan:** Change final う-row sound to い-row → stem
  - *飲む* → *飲み* → *飲みます*
  - *書く* → *書き* → *書きます*
  - *話す* → *話し* → *話します*
  - *帰る* → *帰り* → *帰ります*
- **Irregular:**
  - *する* → *し* → *します*
  - *くる* → *き* → *きます*

### Polite conjugation table

| Form | Ending | Example (食べる) | Example (飲む) |
|------|--------|----------------|--------------|
| Present affirmative | ～ます | 食べます | 飲みます |
| Present negative | ～ません | 食べません | 飲みません |
| Past affirmative | ～ました | 食べました | 飲みました |
| Past negative | ～ませんでした | 食べませんでした | 飲みませんでした |
| Volitional ("let's") | ～ましょう | 食べましょう | 飲みましょう |
| Invitation | ～ませんか | 食べませんか | 飲みませんか |

## 📚 3. Plain Forms (dictionary, casual speech)

Plain forms are used in: casual speech between friends/family, subordinate clauses (most grammar patterns require plain form before conjunctions), and writing.

### Plain present (= dictionary form)
This is the form you find in dictionaries — no conjugation needed.
*食べる, 飲む, 話す, 行く, する, くる*

### Plain negative
- **Ichidan:** Remove る, add ない
  - *食べる* → *食べない*
- **Godan:** Change う-row to あ-row, add ない (exception: う-ending verbs → わ, not ああ)
  - *飲む* → *飲まない*
  - *書く* → *書かない*
  - *話す* → *話さない*
  - *買う* → *買わない* (not *買ない*)
- **Irregular:**
  - *する* → *しない*
  - *くる* → *こない*
  - *いる* (exist) → *いない*
  - *ある* (exist, inanimate) → *ない* (completely irregular!)

### Plain past (た-form)
The plain past is formed very similarly to the て-form (see §4) — same consonant changes, just た instead of て:

| Verb type | て-form ending | た-form ending |
|-----------|--------------|--------------|
| Ichidan | て | た |
| く → いて | いて | いた |
| ぐ → いで | いで | いだ |
| す → して | して | した |
| む/ぬ/ぶ → んで | んで | んだ |
| る/う/つ → って | って | った |
| Irregular: いく | いって | いった |

### Plain past negative
Negative plain form + かった: *食べなかった, 飲まなかった, しなかった*

## 📚 4. The て-Form — The Gateway

The て-form is the most important conjugation in Japanese. Once you have it, 20+ grammar patterns open up.

### て-form formation rules

**Ichidan verbs:** Remove る, add て
*食べる → 食べて | 見る → 見て | 起きる → 起きて*

**Godan verbs (the consonant-change rules):**

| Verb ending | て-form change | Example |
|------------|--------------|---------|
| く | いて | 書く → 書いて |
| ぐ | いで | 泳ぐ → 泳いで |
| す | して | 話す → 話して |
| む | んで | 飲む → 飲んで |
| ぬ | んで | 死ぬ → 死んで |
| ぶ | んで | 遊ぶ → 遊んで |
| る | って | 帰る → 帰って |
| う | って | 買う → 買って |
| つ | って | 待つ → 待って |

**Exception:** 行く (iku = go) → 行って (itte), NOT *いいて*

**Irregular verbs:**
*する → して | くる → きて*

### Core て-form grammar patterns

| Pattern | Meaning | Example |
|---------|---------|---------|
| **て + ください** | Please do ~ | 食べてください (Please eat.) |
| **て + います** | Is doing ~ / has done ~ (state) | 食べています (I am eating. / I have eaten [result].) |
| **て + から** | After doing ~ | 食べてから、寝ます (After eating, I'll sleep.) |
| **て + もいいです** | It's okay to ~ / May I ~? | 食べてもいいですか？ (May I eat?) |
| **て + はいけません** | Must not ~ | ここで食べてはいけません (You must not eat here.) |
| **て + みます** | Try doing ~ | 食べてみます (I'll try eating it.) |
| **て + おきます** | Do in advance / leave as is | 準備しておきます (I'll prepare in advance.) |
| **て + しまいます** | Do completely / accidentally | 食べてしまいました (I ate it all up / I accidentally ate it.) |
| **て + あげます/もらいます/くれます** | Giving/receiving favors | — |

## 📚 5. Potential Form — "Can do"

Express ability or possibility:

- **Ichidan:** Remove る → られる (*食べる → 食べられる* = can eat)
- **Godan:** Change え-row → える (*飲む → 飲める* = can drink; *書く → 書ける* = can write)
- **Irregular:** *する → できる | くる → こられる*

*日本語が話せます。* (I can speak Japanese.)
*この漢字が読めません。* (I can't read this kanji.)

> With potential verbs, the object often takes が instead of を: *日本語**が**話せる* (not *を*). Both are used in modern Japanese, but が is more traditional.

---

## 📚 6. Volitional Form — "Let's / I'll"

Expresses intention or invitation:

- **Ichidan:** Remove る → よう (*食べる → 食べよう*)
- **Godan:** Change to お-row + う (*飲む → 飲もう | 書く → 書こう*)
- **Irregular:** *する → しよう | くる → こよう*

*一緒に食べよう！* (Let's eat together!)
*今日は早く寝よう。* (I'll go to bed early today — intention.)

---

## 📚 7. Conditional Forms

**たら-form** (if/when — after completion): た-form + ら
*食べたら、 電話して。* (After you eat / When you've eaten, call me.)
*もし雨だったら、行きません。* (If it rains, I won't go.)

**ば-form** (if — hypothetical condition): varies by verb type
Godan: change to え-row + ば (*飲む → 飲めば | 書く → 書けば*)
Ichidan: Remove る + れば (*食べる → 食べれば*)
*もっと練習すれば、上手になる。* (If you practice more, you'll get better.)

---

## ⚠️ 8. Common Errors

| Error | Notes |
|-------|-------|
| Wrong verb class | Treating *帰る* (kaeru) as ichidan — it's godan. Always verify with dictionary. |
| て-form of 行く | *行いて* ❌ → *行って* ✅ (special exception) |
| Plain negative of ある | *あらない* ❌ → *ない* ✅ |
| Forgetting that ています can mean either ongoing or result state | *着ています* = "is wearing" (result state, not ongoing action). Context + verb type determines meaning. |
| Using ください without て-form | *食べください* ❌ → *食べて**ください*** ✅ |
