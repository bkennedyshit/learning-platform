### 🚧 Phase 0: Your Background

**Context**:

- 2-year degree in architecture design
    
- Multimedia design background (CAD, 3D modeling, pixel/vector editing)
    
- Self-taught in video editing
    
- Dreamweaver/web creation (HTML/CSS/JS — _not_ C#)
    
- Familiar with Autodesk software
    
- Mathematically inclined (may need refresher)
    
- Strong intuition for physical spatial design (great for UX/UI in VR)
    

---

### 📘 Phase 1: Learn Programming (C# for Unity)

**Books & Courses**:

- 📗 _C# 9.0 in a Nutshell_ by Joseph Albahari (reference/manual)
    
- 🎓 Codecademy C# Course ([https://www.codecademy.com/learn/learn-c-sharp](https://www.codecademy.com/learn/learn-c-sharp))
    
- 🎥 YouTube: [Programming with Mosh](https://www.youtube.com/user/programmingwithmosh) - Beginner C# series
    
- 🧠 Practice: Build simple console apps or mini tools (e.g. calculator, text RPG)
    

---

### 🧱 Phase 2: Intro to Unity

**Core Tools**:

- Unity (Download via Unity Hub)
    
- Visual Studio (installed via Unity setup)
    

**Courses & Resources**:

- 📚 Unity Learn ([https://learn.unity.com/](https://learn.unity.com/)) – Start with the “Junior Programmer” and “Creator Kit: FPS or Platformer”
    
- 🎥 YouTube: [Brackeys](https://www.youtube.com/user/Brackeys) (watch in order — GameDev for Beginners, Player Movement, Camera, etc.)
    

**Project**:  
✅ Build a basic 3D scene with movement + interaction (door opens, object collects)

---

### 🎨 Phase 3: 3D Modeling & Animation

**Primary Tool**: Blender (Free) or Maya (Autodesk)

**Resources**:

- 🧠 [BlenderGuru: Donut Tutorial](https://www.youtube.com/watch?v=TPrnSACiTJ4) – Start here, even if you're Maya-experienced
    
- 📘 _Blender 3D: Noob to Pro_ (Wikibook)
    
- 🎥 YouTube: Grant Abbitt for modeling characters/environment assets
    

**Goal**: Create assets you can import into Unity

---

### 🎮 Phase 4: Game Design Principles

**Book**:

- 📘 _The Art of Game Design: A Book of Lenses_ by Jesse Schell
    
- 📘 _Level Up! The Guide to Great Video Game Design_ by Scott Rogers
    

**Extra Reading**:

- 🧾 Gamasutra Articles on Game Loops, Player Motivation, Core Mechanics
    
- 🗂️ GameDesignConcepts (gamedev.tutsplus.com/series/game-design-concepts)
    

---

### 📐 Phase 5: Physics & Math Refresh

**Resources**:

- 🎓 Khan Academy – Physics: Motion, Forces, Energy
    
- 📘 _3D Math Primer for Graphics and Game Dev_ by Fletcher Dunn
    
- 🎮 Practice: Apply concepts in Unity (gravity, jumping, collision forces)
    

---

### 🧠 Phase 6: UX/UI for VR & 3D

**Resources**:

- 📘 _Designing for Virtual Reality_ by Jason Jerald
    
- 🎥 YouTube: Oculus Developer Channel (especially UI/UX design considerations)
    
- 📘 _Don’t Make Me Think_ by Steve Krug (UX basics, web-focused but relevant)
    

**Principles to Master**:

- Player comfort (FOV, motion sickness)
    
- Ergonomic layout of menus/inventory
    
- Navigation design in 3D/VR space (gaze-based, hand-tracking)
    

---

### 🌐 Phase 7: Networking for Multiplayer

**Resources**:

- 🎓 Unity Multiplayer with Photon (Free tutorials via Photon website or Unity Asset Store)
    
- 🎥 YouTube: Dapper Dino’s multiplayer series
    
- 📘 _Multiplayer Game Programming_ by Josh Glazer
    
- Study client-server model, RPC calls, lag compensation
    

---

### 🥽 Phase 8: VR Dev Specialization

**Platform SDKs**:

- Meta Quest (formerly Oculus SDK)
    
- SteamVR or OpenXR
    

**Courses**:

- 📚 Unity VR Dev Path ([https://learn.unity.com/pathway/vr-development](https://learn.unity.com/pathway/vr-development))
    
- 🎓 Udacity VR Developer Nanodegree (if budget allows)
    

**Practice Project**: ✅ Build a room-scale VR experience (pick-up, throw, menu interaction)

---

### 🧳 Phase 9: Portfolio & Project Assembly

**Steps**:

- Use GitHub to version your projects
    
- Create a simple portfolio (WordPress, Framer, or Webflow)
    
- Include 2-3 polished games or prototypes (1 VR, 1 Unity 3D, 1 2D if interested in Stardew-style)
    
- Include video demos & downloadable builds
    
- Document process (showcase design, iteration, and problem-solving)
    

---

### 🔄 Phase 10: Keep Growing

**Communities**:

- Reddit: `r/gamedev`, `r/VRdev`, `r/Unity3D`
    
- Discord: Unity & Blender Servers
    
- Participate in Game Jams (Ludum Dare, itch.io)
    
- Follow devlogs on YouTube to learn from others
    

---

### ❓ Other Concepts You Asked About

|**Term**|**Explanation**|
|---|---|
|C#|Language for Unity & Windows dev|
|C++|Lower-level language for performance-critical applications (used in Unreal)|
|Lua|Scripting language used by Roblox|
|HTML/CSS/JS|Web development languages (used in Dreamweaver)|
|Dreamweaver|Not related to C# — web design only|
|Spatial UX|Very similar to architectural UX: guide user through space with intuitive flow|
|Physics Focus|Motion, gravity, collisions, friction, force equations|
|Math Focus|Vectors, matrices, linear algebra, trigonometry (for camera + 3D motion)|
|VR Optimization|Lower poly counts, baked lighting, reduced draw calls|

- Avoid overthinking by following one phase at a time
    
- You already have 70% of the creative tools — just build your logic + scripting muscle
    
- Keep this note updated as you progress (#milestones, #blockers)
