## 📚 1. Waveforms & Their Harmonic Content

A **waveform** is a visual representation of how air pressure varies over time. The **harmonic content** (which overtones are present) determines the timbre.

### 1.1 The Four Basic Waveforms

| Waveform | Harmonic content | Sound character |
|---------|----------------|----------------|
| **Sine** | Fundamental only (no overtones) | Pure, warm, smooth — good for sub bass |
| **Sawtooth** | All harmonics (decreasing amplitude) | Bright, harsh, buzzy — strings, leads |
| **Square** | Odd harmonics only | Hollow, woody — clarinets, retro synths |
| **Triangle** | Odd harmonics only (softer than square) | Mellow, flute-like |
| **Noise** | All frequencies equally | Percussion, SFX, wind, snare noise layer |

**DSP connection from Track 32:** The Fourier series shows that:
- Sawtooth = sum of all integer harmonics: sin(nωt)/n for n = 1, 2, 3, 4...
- Square = sum of odd harmonics: sin(nωt)/n for n = 1, 3, 5, 7...
- Triangle = sum of odd harmonics with alternating sign: amplitude drops as 1/n²

## 📚 2. The Subtractive Synthesis Signal Chain

**Subtractive synthesis:** Start with a harmonically rich waveform (saw, square) → filter out harmonics with a filter → shape amplitude with an envelope.

```
[OSC 1: Saw 440Hz] ─┐
                     ├─ [MIXER] ─ [FILTER] ─ [AMP ENV] ─ [FX] ─ Output
[OSC 2: Sub -12st] ─┘     │           │          │
                           │           │          └── ADSR 2 (amp)
                        detune/      ADSR 1
                        blend       (filter env)
                                        │
                                    [LFO] → filter cutoff (optional)
```

### 2.1 The Filter

A **filter** is the central tool of subtractive synthesis. It removes (or boosts) harmonics.

**Filter types:**

| Type | Effect | Use |
|------|--------|-----|
| Low-pass (LP) | Passes frequencies below cutoff | Warm bass, removing brightness |
| High-pass (HP) | Passes frequencies above cutoff | Remove mud, thin out sound |
| Band-pass (BP) | Passes frequencies around cutoff | Mid-focused, telephone effect |
| Notch | Attenuates around cutoff | Remove specific frequency |
| All-pass | Changes phase, not amplitude | Phaser effects |

**Key filter parameters:**
- **Cutoff frequency:** Where filtering begins (e.g. 1kHz LP cuts above 1kHz)
- **Resonance (Q):** Boosts frequencies around cutoff. High Q = sharp peak = 303 acid sound
- **Filter slope:** 12 dB/octave (2-pole, Moog-like softness) or 24 dB/octave (4-pole, aggressive)

### 2.2 Oscillator Detune

Two oscillators slightly detuned against each other (±5–15 cents) create a **chorus effect** from two sine waves beat-interfering. This is how a SuperSaw (Roland JP-8000) gets its wide, rich sound.

## 📚 3. ADSR Envelope Generator

The **ADSR envelope** shapes how a parameter (usually amplitude or filter cutoff) changes over time when a note is triggered.

```
Level
  │
Max│    /\
   │   /  \___________
   │  /               \
   │ /                 \
  0└──────────────────────Time
    A   D   S(hold)   R
    Attack  Sustain  Release
```

| Stage | What it controls |
|-------|----------------|
| **Attack** | How quickly level rises from 0 to peak after note-on |
| **Decay** | How quickly level falls from peak to sustain |
| **Sustain** | Level held while key is pressed |
| **Release** | How quickly level falls from sustain to 0 after note-off |

**Sound recipes using ADSR:**

| Sound | Attack | Decay | Sustain | Release |
|-------|--------|-------|---------|---------|
| Pluck | 0ms | 100ms | 0% | 200ms |
| Kick drum | 0ms | 80ms | 0% | 150ms |
| Snare | 2ms | 150ms | 10% | 300ms |
| Lead synth | 10ms | 200ms | 70% | 500ms |
| Pad | 800ms | 0ms | 80% | 1200ms |
| Organ | 0ms | 0ms | 100% | 10ms |

## 📚 4. LFO — Low Frequency Oscillator

An LFO is an oscillator running below audio rate (0.1–20 Hz) used to **modulate parameters over time**.

**LFO modulation targets:**
- Pitch → **Vibrato** (sine LFO on pitch, ±50 cents)
- Filter cutoff → **Auto-wah** or **wah effect** (sine/triangle on LP cutoff)
- Amplitude → **Tremolo** (sine on amp level)
- Pan → **Auto-pan** (sine on stereo position)
- Pitch at audio rate (FM!) → complex timbres

**LFO shapes:**
- Sine: smooth, natural-sounding modulation
- Square: hard on/off switching (strobe, trill)
- Sample & Hold: random stairstep (sci-fi computer sounds)
- Random: smooth random variation

**Sync to BPM:** Lock LFO rate to note values (1/4, 1/8, 1/16) → rhythmic modulation stays in time with the track.

## 📚 5. FM Synthesis

**Frequency Modulation synthesis** (Yamaha DX7, 1983) uses one oscillator (the **modulator**) to modulate the frequency of another (the **carrier**).

```
[Carrier at freq C] ← frequency modulated by → [Modulator at freq M]
```

**Key concept: Carrier:Modulator ratio (C:M)**
- C:M = 1:1 → harmonic spectrum (octave relationships)
- C:M = 1:2 → adds even harmonics, bright
- C:M = 1:3.5 → inharmonic (bells, metallic sounds)
- C:M = 1:7 → very bright, metallic

**Modulation index (β):** Controls the *amount* of frequency deviation. Higher β = more harmonics = brighter.
- Low β: subtle harmonic enrichment
- High β: rich, complex, harsh timbre

**FM bell sound recipe:**
- Carrier: sine, C4
- Modulator: sine, C4 (ratio 1:1) or 7× frequency (ratio 1:7 for metallic)
- Modulator envelope: very short attack, short decay, sustain 0
- Carrier envelope: short attack, long decay (bell ring-out)
- β = 3–8

## 📚 6. Wavetable Synthesis

Instead of a mathematical formula, wavetable synthesis stores **actual waveform tables** (typically 2048 samples) that it cycles through.

**How it works:**
1. Start position in the wavetable: e.g. slot 0 = basic sine
2. Scan through the table smoothly or with LFO
3. Each position in the wavetable has different harmonic content
4. Moving through the table changes the timbre continuously

**Examples:** Serum (paid), Surge XT (free, open-source), Vital (free)

**Advantage over subtractive:** Can produce complex, organic timbres that are difficult to achieve with simple oscillators + filters alone.

## 📚 7. Granular Synthesis

Sound is sliced into tiny "grains" (typically 10–200ms) and these grains are replayed with:
- **Density:** How many grains per second
- **Size:** Grain duration
- **Position:** Where in the source file the grain comes from
- **Pitch:** Each grain can be transposed independently

**Applications:**
- Extreme time-stretching without pitch change
- Spectral freeze (infinite sustain on any sound)
- Ambient pads from any source (voice, violin, etc.)
- Glitch/texture effects

## 🛠️ 8. Worked Example — Design a Classic 303 Acid Bass

The TB-303 bass line sound is the defining sound of acid house and techno.

**Architecture:** Subtractive, single oscillator

1. **OSC:** Square or saw wave, 75 Hz (D2 for a classic acid baseline note)
2. **Filter:** LP, 24 dB/octave (Moog-style), cutoff 300 Hz, resonance 80–90%
3. **Filter envelope:** ADSR = 0ms / 200ms / 0% / 0ms; envelope amount = HIGH (filter opens aggressively on each note)
4. **Amp envelope:** ADSR = 0ms / 200ms / 0% / 20ms (snappy, minimal release)
5. **Accent:** Some notes triggered at higher velocity → more filter envelope amount applied
6. **Glide (portamento):** 50ms between notes → characteristic sliding between pitches

**Pro tip:** The resonance on the 303-style filter is critically important. Too low = boring LP filter. Too high = screaming self-oscillation. 70–85% is the sweet spot.

## ⚠️ 9. Common Misconceptions

1. **"A 24 dB/oct filter is always better than 12 dB/oct."** Not better — different character. 12 dB (2-pole) is smoother and less aggressive. 24 dB (4-pole) is more dramatic, cuts harder. Many great synth sounds use 12 dB filters.

2. **"FM synthesis is only for metallic/digital sounds."** FM synthesis can produce warm, analog-sounding pads and basses when using low modulation index with simple ratios. The DX7 electric piano is FM.

3. **"High resonance = bad/harsh."** High resonance at a frequency with musical content = the acid bass sound, or a resonant sweep. High resonance on the wrong frequency = annoying. Context determines everything.

4. **"Velocity only controls volume."** Velocity maps to timbre, filter cutoff, reverb amount, and vibrato depth on most synthesisers. A pad that gets brighter as you play harder is more expressive than one that just gets louder.

5. **"Wavetable synthesis is just playback of samples."** Wavetables are single-cycle waveforms (2048 samples typically), not full audio samples. The synthesiser generates pitched audio from them at any pitch without artefacts — different from a sampler.

6. **"Detuning oscillators always sounds good."** Detuning creates beating, which sounds rich on pads but unfocused on bass. Bass frequencies below about 200Hz should generally be kept tight (or use a single oscillator) to avoid phase cancellation in mono.
