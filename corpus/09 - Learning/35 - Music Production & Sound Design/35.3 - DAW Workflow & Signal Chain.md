# 35.3 — DAW Workflow & Signal Chain

> *"The DAW is your studio. Knowing it deeply means you stop fighting the tool and start making music."*

4. Record and edit **MIDI automation** on any parameter.

## 📚 1. The Channel Strip Signal Chain

In any DAW, every track passes through a channel strip. The signal path is consistent across all major DAWs (LMMS, Ableton, FL Studio, Logic, Reaper):

```
Input Source (MIDI/Audio)
    ↓
Pre-fader Inserts (EQ, Comp, Saturation)
    ↓
Send 1 → [Reverb Return Bus]
Send 2 → [Delay Return Bus]
    ↓
Volume Fader (sets level in mix)
    ↓
Pan Control (L/C/R)
    ↓
Group/Bus Routing
    ↓
Master Bus
```

**Pre-fader vs Post-fader sends:**
- **Pre-fader send:** Independent of fader position — reverb amount doesn't change when you turn down the track. Use for monitor mixes.
- **Post-fader send:** Send amount scales with fader. Use for reverb/delay in mix — reverb fades with the dry signal.

## 📚 2. Bus/Group Routing Architecture

### 2.1 Why Use Buses?

Buses allow:
1. **Group processing:** Apply one compressor to all drums simultaneously (bus compression = "glue")
2. **Level management:** Control all drums with one fader
3. **Parallel processing:** NYC parallel compression, parallel saturation
4. **FX returns:** Shared reverb for consistent acoustic space

### 2.2 Typical Session Architecture

**Drum tracks → Drum Bus:**
- Kick, Snare, Hi-hats, Toms all route to "DRUM BUS"
- Drum Bus inserts: transient shaper, bus compressor (ratio 2:1, slow attack/release), EQ
- Goal: make kit "sit together," punch as a unit

**Synth tracks → Synth Bus:**
- Bass, Lead, Pad, Arps route to "SYNTH BUS"
- Synth Bus inserts: saturation (add harmonic richness), stereo imager

**All buses → Master Bus:**
- Master inserts: subtle EQ, glue comp, stereo imager, limiter (last in chain)

### 2.3 FX Return Setup (Reverb and Delay)

**Correct method:** Never put reverb directly on a channel insert — it's wasteful (CPU) and inflexible.

1. Create a new audio return channel named "REVERB ROOM"
2. Insert a reverb plugin on this return channel
3. Turn the return channel fader UP (not muted!)
4. On each track that needs reverb: increase Send amount to "REVERB ROOM"
5. The reverb return channel is the "wet" signal; each track remains dry

**Benefit:** All tracks share ONE reverb instance → cohesive space + CPU savings.

## 📚 3. Audio Engine Configuration

### 3.1 Sample Rate

| Rate | Use | Notes |
|------|-----|-------|
| 44.1 kHz | Distribution (CD, streaming) | Nyquist limit: 22.05 kHz (above human hearing) |
| 48 kHz | Video/broadcast | Standard for film/video sync |
| 96 kHz | Tracking only | Extra headroom; downsample for distribution |

**Rule:** Match sample rate to your project's output destination. Avoid unnecessary upsampling/downsampling.

### 3.2 Bit Depth

| Bit depth | Dynamic range | Use |
|-----------|--------------|-----|
| 16-bit | 96 dB | CD distribution (delivery format) |
| 24-bit | 144 dB | Tracking and mixing (headroom!) |
| 32-bit float | Theoretically unlimited | Internal DAW processing — no clipping on bus |

**Always track and mix at 24-bit.** Deliver at 16-bit or 24-bit depending on platform.

### 3.3 Buffer Size and Latency

**Buffer size** determines how many audio samples are processed before output:
- Small buffer (64–128 samples) → low latency (~3ms) → needed for live playing/recording
- Large buffer (512–1024 samples) → higher latency → better CPU stability for complex mixes

**Rule:** Use small buffer when recording. Increase buffer when just mixing (no latency sensitivity). With an audio interface and ASIO driver (Windows) or CoreAudio (Mac), 64–128 sample buffers are typically stable.

## 📚 4. MIDI Piano Roll Workflow

### 4.1 Piano Roll Basics

The piano roll is a grid showing **time (horizontal)** vs **MIDI note number (vertical)**.

**Drawing notes:**
1. Enable draw mode
2. Click and drag on the grid to create a note
3. Note length = drag distance
4. Move notes by drag (pointer mode)
5. Delete: right-click or eraser tool

**Velocity:** Each note has a velocity bar at the bottom. Vary velocities to humanise.

**Quantise:** Snap notes to a grid (1/16th, 1/8th etc). 100% quantise = robotic. Use 50–75% for human feel, or use Groove Quantise.

### 4.2 Automation

Automation records parameter changes over time.

**Types:**
- **Volume automation:** Fade intro, fade out, dynamic rides
- **Filter cutoff automation:** Build tension (slowly close filter into drop, then open)
- **Effect send automation:** More reverb in verses, dry in drop
- **Pitch automation:** Pitch rise into drop

**Drawing automation:** Switch to automation view → draw or record (move knob while playing) → edit curve handles.

## 📚 5. Song Structure (Arrangement View)

A typical electronic music arrangement:

| Section | Bars | What happens |
|---------|------|-------------|
| Intro | 8–16 | Minimal elements, set the key/tempo |
| Build 1 | 8–16 | Add elements, risers, tension increase |
| Drop 1 | 16–32 | Full energy, primary hook, bass drops |
| Breakdown | 8–16 | Strip back, melodic focus, breathe |
| Build 2 | 8–16 | Denser than build 1, different elements |
| Drop 2 | 16–32 | Variation of drop 1 (add/remove layer) |
| Outro | 8–16 | Reverse of intro — elements drop away |

**Key transition techniques:**
- **Riser:** Pitch/volume sweep rising into the drop
- **Reverse cymbal:** Reverse crash leading into downbeat
- **Stuttered loop:** Rapid repetition of last 1/8th or 1/16th beat
- **Breakdowns:** Silence the kick/bass, let melodic/harmonic elements breathe

## 🛠️ 6. Worked Example — Setting Up a Full Session in LMMS

1. **Create new project** → Set BPM (90 for lo-fi, 130 for house)
2. **Open Beat+Bassline editor** → program drum pattern: kick on 1 & 3, snare on 2 & 4, hi-hat 8th notes
3. **Add instrument track** → choose ZynAddSubFX preset (built-in) → draw chord progression in piano roll
4. **Add bass track** → program root note bassline in piano roll
5. **Open Song editor** → arrange clips: intro (no bass), verse, chorus, outro
6. **Add FX returns:** Mixer → create "REVERB" send channel → insert ZynReverb2 → set send from instruments
7. **Master bus:** Mixer → master channel → add Compressor (gentle) + Loudness Maximizer
8. **Export:** File → Export → WAV, 24-bit, 44100 Hz

## ⚠️ 7. Common Misconceptions

1. **"I should add reverb on every channel insert."** This is the #1 beginner mistake. Reverb on every channel creates a muddy wash. Use one or two shared return reverbs and send selectively.

2. **"Higher sample rate = better quality for listeners."** No listener can hear above 20kHz, and most lose it by age 30. 44.1kHz is sufficient for distribution. 96kHz is only beneficial if your signal processing benefits from it (some plugins have higher quality modes at high SR).

3. **"I need an expensive DAW to make professional music."** LMMS is free and has produced commercial-quality tracks. Bespoke Synth is free and can do things no commercial DAW can. Your ears and decision-making matter more than DAW choice.

4. **"The bus comp makes everything louder so it's better."** Bus compressors reduce dynamics (make loud quieter, quiet louder) AND reduce the peak level. You need to apply make-up gain. The goal is glue and punch, not just loudness.

5. **"Automation is only for volume fades."** Automation is one of the most powerful creative tools. Automate filter cutoff for movement, reverb sends for space, pitch for texture, any parameter for evolution.

6. **"I should set the buffer size and forget it."** Buffer size should change with workflow: small for recording (low latency), large for mixing complex sessions (stability). Getting this wrong causes dropout (crackling) when mixing or uncomfortable latency when playing.
