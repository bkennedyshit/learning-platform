# 24.7 — Multimodal Experiments: Vision-Language & Audio-Text Bridges

> *"The next frontier of AI is not just understanding text or images in isolation — it's understanding the world through all modalities simultaneously."*

Multimodal AI bridges the gap between vision, language, and audio. This chapter experiments with vision-language models (VLMs) that can describe images, answer visual questions, and reason about visual content — then extends to audio-text bridges and unified embedding spaces.

## 📚 1. Concepts & Definitions

| Concept | Definition |
|---------|-----------|
| **VLM** | Vision-Language Model — processes both images and text |
| **Visual Encoder** | CNN or ViT that extracts image features (CLIP ViT, SigLIP) |
| **Projection Layer** | Maps visual features into the LLM's embedding space |
| **Visual Tokens** | Image patches treated as tokens in the LLM's sequence |
| **Cross-Modal Retrieval** | Finding items in one modality using queries from another |
| **ImageBind** | Meta's unified embedding space for 6 modalities |
| **OCR-Free Document AI** | Understanding documents directly from pixel input |

### Vision-Language Model Landscape

| Model | Size | Architecture | Strengths | License |
|-------|------|-------------|-----------|---------|

## 🔬 2. Theory Briefing

> For transformer and attention theory, see [[23.5 - Transformer Architectures & LLMs]]. For CNN/ViT architectures, see [[23.3 - Computer Vision - CNNs & ViTs]].

### VLM Architecture Pattern

Most open VLMs follow this pattern:

```
Image → Visual Encoder (ViT) → Projection (MLP) → [Visual Tokens]
                                                         ↓
Text  → Tokenizer → [Text Tokens] → LLM Backbone → Response
                                         ↑
                              [Visual Tokens + Text Tokens]
```

The visual encoder produces patch embeddings (e.g., 576 tokens for a 384×384 image with 14×14 patches). A projection layer maps these to the LLM's hidden dimension. The LLM processes visual and text tokens together.

### Resolution & Token Count

```
Image resolution → Patches → Visual tokens → Context consumed

  224×224, patch=14:  16×16 = 256 tokens
  336×336, patch=14:  24×24 = 576 tokens
  448×448, patch=14:  32×32 = 1024 tokens
  672×672, patch=14:  48×48 = 2304 tokens

Dynamic resolution (Qwen2-VL):
  Splits image into tiles, each processed separately
  A 1920×1080 image → ~6 tiles × 256 tokens = 1536 tokens
```

### ImageBind: Unified Embedding Space

ImageBind maps 6 modalities into a shared embedding space:
- Images, Text, Audio, Depth, Thermal, IMU

Trained with image-paired data only (image-text, image-audio, etc.), but emergent cross-modal alignment occurs (audio-text works despite never being trained together).

```python
from transformers import Qwen2VLForConditionalGeneration, AutoProcessor
from qwen_vl_utils import process_vision_info
import torch

# Load model (2B fits easily on 24GB, 7B fits in 4-bit)
model = Qwen2VLForConditionalGeneration.from_pretrained(
    "Qwen/Qwen2-VL-7B-Instruct",
    torch_dtype=torch.bfloat16,
    device_map="auto",
    attn_implementation="flash_attention_2",
)
processor = AutoProcessor.from_pretrained("Qwen/Qwen2-VL-7B-Instruct")

# Single image understanding
messages = [
    {
        "role": "user",
        "content": [
            {"type": "image", "image": "architecture_diagram.png"},
            {"type": "text", "text": "Describe this architecture diagram in detail. What components are shown and how do they connect?"},
        ],
    }
]

# Process
text = processor.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
image_inputs, video_inputs = process_vision_info(messages)
inputs = processor(
    text=[text], images=image_inputs, videos=video_inputs,
    padding=True, return_tensors="pt"
).to("cuda")

# Generate
output_ids = model.generate(**inputs, max_new_tokens=512, temperature=0.1)
output_text = processor.batch_decode(
    output_ids[:, inputs.input_ids.shape[1]:], skip_special_tokens=True
)[0]
print(output_text)
```

### Experiment 4.2 — Visual Question Answering (Batch)

```python
from transformers import Qwen2VLForConditionalGeneration, AutoProcessor
from qwen_vl_utils import process_vision_info
from pathlib import Path
import torch

model = Qwen2VLForConditionalGeneration.from_pretrained(
    "Qwen/Qwen2-VL-7B-Instruct", torch_dtype=torch.bfloat16, device_map="auto"
)
processor = AutoProcessor.from_pretrained("Qwen/Qwen2-VL-7B-Instruct")

# Batch VQA over multiple images
image_dir = Path("./test_images")
questions = [
    ("photo1.jpg", "What objects are in this image?"),
    ("chart.png", "What trend does this chart show? Give specific numbers."),
    ("code_screenshot.png", "What programming language is this? What does the code do?"),
    ("receipt.jpg", "Extract the total amount and date from this receipt."),
]

results = []
for img_name, question in questions:
    messages = [{"role": "user", "content": [
        {"type": "image", "image": str(image_dir / img_name)},
        {"type": "text", "text": question},
    ]}]
    
    text = processor.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
    image_inputs, _ = process_vision_info(messages)
    inputs = processor(text=[text], images=image_inputs, padding=True, return_tensors="pt").to("cuda")
    
    output_ids = model.generate(**inputs, max_new_tokens=256)
    answer = processor.batch_decode(output_ids[:, inputs.input_ids.shape[1]:], skip_special_tokens=True)[0]
    
    results.append({"image": img_name, "question": question, "answer": answer})
    print(f"\n📷 {img_name}: {question}")
    print(f"   → {answer}")
```

### Experiment 4.4 — ImageBind Cross-Modal Retrieval

```python
"""Cross-modal retrieval: find images using text or audio queries."""
import torch
from imagebind import data as imagebind_data
from imagebind.models import imagebind_model
from imagebind.models.imagebind_model import ModalityType

# Load ImageBind
model = imagebind_model.imagebind_huge(pretrained=True).eval().to("cuda")

# Prepare inputs from different modalities
image_paths = ["cat.jpg", "dog.jpg", "car.jpg", "forest.jpg", "city.jpg"]
text_queries = ["a cute animal", "urban landscape", "nature scene"]
audio_paths = ["bird_chirping.wav", "traffic_noise.wav"]

# Encode all modalities
with torch.no_grad():
    # Images
    image_inputs = {ModalityType.VISION: imagebind_data.load_and_transform_vision_data(image_paths, "cuda")}
    image_embeddings = model(image_inputs)[ModalityType.VISION]
    
    # Text
    text_inputs = {ModalityType.TEXT: imagebind_data.load_and_transform_text(text_queries, "cuda")}
    text_embeddings = model(text_inputs)[ModalityType.TEXT]
    
    # Audio
    audio_inputs = {ModalityType.AUDIO: imagebind_data.load_and_transform_audio_data(audio_paths, "cuda")}
    audio_embeddings = model(audio_inputs)[ModalityType.AUDIO]

# Cross-modal similarity: Text → Image
text_image_sim = torch.softmax(text_embeddings @ image_embeddings.T * 10, dim=-1)
print("Text → Image retrieval:")
for i, query in enumerate(text_queries):
    best_idx = text_image_sim[i].argmax().item()
    print(f"  '{query}' → {image_paths[best_idx]} (score: {text_image_sim[i][best_idx]:.3f})")

# Cross-modal: Audio → Image (emergent alignment!)
audio_image_sim = torch.softmax(audio_embeddings @ image_embeddings.T * 10, dim=-1)
print("\nAudio → Image retrieval:")
for i, audio in enumerate(audio_paths):
    best_idx = audio_image_sim[i].argmax().item()
    print(f"  '{audio}' → {image_paths[best_idx]} (score: {audio_image_sim[i][best_idx]:.3f})")
```

### Experiment 4.5 — Image-to-Speech Pipeline

```python
"""See an image → Describe it → Speak the description."""
from transformers import Qwen2VLForConditionalGeneration, AutoProcessor
from qwen_vl_utils import process_vision_info
from TTS.api import TTS
import torch

# Load VLM
vlm = Qwen2VLForConditionalGeneration.from_pretrained(
    "Qwen/Qwen2-VL-2B-Instruct", torch_dtype=torch.bfloat16, device_map="auto"
)
vlm_processor = AutoProcessor.from_pretrained("Qwen/Qwen2-VL-2B-Instruct")

# Load TTS
tts = TTS("tts_models/multilingual/multi-dataset/xtts_v2").to("cuda")

def image_to_speech(image_path: str, output_wav: str, voice_ref: str = None):
    """Complete pipeline: image → description → speech."""
    
    # Step 1: Generate description
    messages = [{"role": "user", "content": [
        {"type": "image", "image": image_path},
        {"type": "text", "text": "Describe this image in 2-3 natural sentences, as if you're telling someone what you see."},
    ]}]
    
    text = vlm_processor.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
    image_inputs, _ = process_vision_info(messages)
    inputs = vlm_processor(text=[text], images=image_inputs, padding=True, return_tensors="pt").to("cuda")
    
    output_ids = vlm.generate(**inputs, max_new_tokens=150, temperature=0.7)
    description = vlm_processor.batch_decode(output_ids[:, inputs.input_ids.shape[1]:], skip_special_tokens=True)[0]
    
    print(f"📷 Image: {image_path}")
    print(f"📝 Description: {description}")
    
    # Step 2: Speak the description
    if voice_ref:
        tts.tts_to_file(text=description, speaker_wav=voice_ref, language="en", file_path=output_wav)
    else:
        tts.tts_to_file(text=description, speaker="Ana Florence", language="en", file_path=output_wav)
    
    print(f"🔊 Audio saved: {output_wav}")
    return description

# Run pipeline
description = image_to_speech("sunset_beach.jpg", "description.wav")
```

## ⚠️ 6. Gotchas & Debugging

| Issue | Cause | Fix |
|-------|-------|-----|
| OOM with high-res images | Too many visual tokens | Reduce `max_pixels` in processor config |
| Poor OCR results | Low image resolution | Ensure input ≥ 1024px for text-heavy images |
| Hallucinated content | Model confabulates details | Lower temperature, ask specific questions |
| Slow inference | Flash attention not enabled | Set `attn_implementation="flash_attention_2"` |
| ImageBind import errors | Version conflicts | Use separate conda env for ImageBind |
| VLM ignores image | Image not properly preprocessed | Check processor output, verify image loads |

### Memory Budget for VLMs

```
Qwen2-VL-7B (BF16):
  Model weights:     ~14 GB
  KV cache (2K ctx): ~2 GB
  Visual tokens:     ~1 GB (for 1024×1024 image)
  ─────────────────────────
  Total:             ~17 GB (fits on 24GB)

Qwen2-VL-7B (4-bit):
  Model weights:     ~4 GB
  KV cache:          ~2 GB
  Visual tokens:     ~1 GB
  ─────────────────────────
  Total:             ~7 GB (plenty of room)
```

### Experiment 9.1 — Florence-2 + GPT-4o Vision Pipeline for Structured Extraction

Build a two-stage pipeline: Florence-2 for fast visual grounding (detection, captioning, OCR) and a VLM for structured reasoning over the visual outputs. This is the production pattern for document understanding at scale.

```python
import torch
from transformers import AutoProcessor, AutoModelForCausalLM
from PIL import Image
import json
import time

class Florence2Pipeline:
    """Florence-2 for fast visual understanding tasks."""
    
    def __init__(self, model_name="microsoft/Florence-2-large", device="cuda"):
        self.processor = AutoProcessor.from_pretrained(model_name, trust_remote_code=True)
        self.model = AutoModelForCausalLM.from_pretrained(
            model_name, torch_dtype=torch.float16, trust_remote_code=True,
        ).to(device)
        self.device = device
    
    def run_task(self, image: Image.Image, task: str, text_input: str = "") -> dict:
        """Run a Florence-2 task on an image.
        
        Tasks: <CAPTION>, <DETAILED_CAPTION>, <MORE_DETAILED_CAPTION>,
               <OD>, <DENSE_REGION_CAPTION>, <REGION_PROPOSAL>,
               <OCR>, <OCR_WITH_REGION>, <CAPTION_TO_PHRASE_GROUNDING>
        """
        prompt = task if not text_input else f"{task} {text_input}"
        
        inputs = self.processor(text=prompt, images=image, return_tensors="pt").to(
            self.device, torch.float16
        )
        
        with torch.no_grad():
            generated_ids = self.model.generate(
                input_ids=inputs["input_ids"],
                pixel_values=inputs["pixel_values"],
                max_new_tokens=1024,
                num_beams=3,
            )
        
        generated_text = self.processor.batch_decode(generated_ids, skip_special_tokens=False)[0]
        result = self.processor.post_process_generation(
            generated_text, task=task, image_size=(image.width, image.height)
        )
        
        return result
    
    def extract_document_structure(self, image_path: str) -> dict:
        """Full document understanding pipeline."""
        image = Image.open(image_path).convert("RGB")
        
        results = {}
        
        # Step 1: Detailed caption
        t0 = time.perf_counter()
        results["caption"] = self.run_task(image, "<MORE_DETAILED_CAPTION>")
        
        # Step 2: OCR with regions
        results["ocr"] = self.run_task(image, "<OCR_WITH_REGION>")
        
        # Step 3: Object detection
        results["objects"] = self.run_task(image, "<OD>")
        
        # Step 4: Dense region captioning
        results["regions"] = self.run_task(image, "<DENSE_REGION_CAPTION>")
        
        results["total_time_s"] = time.perf_counter() - t0
        
        return results

class TwoStageVisionPipeline:
    """Florence-2 (fast extraction) → VLM (structured reasoning)."""
    
    def __init__(self, device="cuda"):
        self.florence = Florence2Pipeline(device=device)
        
        # Load a local VLM for reasoning (Qwen2-VL-7B)
        from transformers import Qwen2VLForConditionalGeneration, AutoProcessor as QwenProcessor
        
        self.vlm_processor = QwenProcessor.from_pretrained("Qwen/Qwen2-VL-7B-Instruct")
        self.vlm = Qwen2VLForConditionalGeneration.from_pretrained(
            "Qwen/Qwen2-VL-7B-Instruct",
            torch_dtype=torch.bfloat16,
            device_map="auto",
            load_in_4bit=True,  # Fit alongside Florence-2
        )
    
    def extract_invoice(self, image_path: str) -> dict:
        """Extract structured data from an invoice image."""
        image = Image.open(image_path).convert("RGB")
        
        # Stage 1: Florence-2 OCR (fast, ~200ms)
        ocr_result = self.florence.run_task(image, "<OCR_WITH_REGION>")
        ocr_text = ocr_result.get("<OCR_WITH_REGION>", {}).get("text", "")
        
        # Stage 2: VLM structured extraction (slower, ~3s)
        messages = [
            {"role": "system", "content": "Extract structured data from this invoice. "
             "Return valid JSON with: vendor, date, invoice_number, line_items (description, qty, price), total."},
            {"role": "user", "content": [
                {"type": "image", "image": image_path},
                {"type": "text", "text": f"OCR text detected: {ocr_text}\n\nExtract the invoice data as JSON."},
            ]},
        ]
        
        text = self.vlm_processor.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
        inputs = self.vlm_processor(text=[text], images=[image], return_tensors="pt").to(self.vlm.device)
        
        with torch.no_grad():
            output_ids = self.vlm.generate(**inputs, max_new_tokens=500, temperature=0.1)
        
        response = self.vlm_processor.batch_decode(
            output_ids[:, inputs.input_ids.shape[1]:], skip_special_tokens=True
        )[0]
        
        # Parse JSON from response
        try:
            json_str = response[response.find("{"):response.rfind("}")+1]
            structured_data = json.loads(json_str)
        except:
            structured_data = {"raw_response": response}
        
        return {
            "ocr_text": ocr_text,
            "structured_data": structured_data,
        }
    
    def visual_qa_with_grounding(self, image_path: str, question: str) -> dict:
        """Answer a question about an image with visual grounding."""
        image = Image.open(image_path).convert("RGB")
        
        # Stage 1: Get relevant regions via phrase grounding
        grounding = self.florence.run_task(
            image, "<CAPTION_TO_PHRASE_GROUNDING>", question
        )
        
        # Stage 2: VLM answers with context
        messages = [
            {"role": "user", "content": [
                {"type": "image", "image": image_path},
                {"type": "text", "text": f"Question: {question}\n\nDetected regions: {json.dumps(grounding)}\n\nAnswer the question based on what you see."},
            ]},
        ]
        
        text = self.vlm_processor.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
        inputs = self.vlm_processor(text=[text], images=[image], return_tensors="pt").to(self.vlm.device)
        
        with torch.no_grad():
            output_ids = self.vlm.generate(**inputs, max_new_tokens=300)
        
        answer = self.vlm_processor.batch_decode(
            output_ids[:, inputs.input_ids.shape[1]:], skip_special_tokens=True
        )[0]
        
        return {"answer": answer, "grounding": grounding}

# Usage

    "office_photo.jpg",
```

### Experiment 9.2 — LLaVA Fine-tuning for Domain-Specific Vision

Fine-tune a vision-language model on custom image-text pairs for domain-specific visual understanding (e.g., medical imaging, manufacturing defect detection, architectural plans).

```python
import torch
from transformers import (
    LlavaForConditionalGeneration, AutoProcessor,
    BitsAndBytesConfig, TrainingArguments
)
from peft import LoraConfig, get_peft_model, prepare_model_for_kbit_training
from datasets import Dataset
from PIL import Image
import json
from pathlib import Path

class LLaVAFineTuner:
    """Fine-tune LLaVA for domain-specific visual understanding."""
    
    def __init__(self, model_name="llava-hf/llava-v1.6-mistral-7b-hf", device="cuda"):
        # Load in 4-bit for training on 24GB GPU
        bnb_config = BitsAndBytesConfig(
            load_in_4bit=True,
            bnb_4bit_quant_type="nf4",
            bnb_4bit_compute_dtype=torch.bfloat16,
        )
        
        self.processor = AutoProcessor.from_pretrained(model_name)
        self.model = LlavaForConditionalGeneration.from_pretrained(
            model_name,
            quantization_config=bnb_config,
            device_map="auto",
        )
        
        # Prepare for LoRA training
        self.model = prepare_model_for_kbit_training(self.model)
        
        lora_config = LoraConfig(
            r=16,
            lora_alpha=32,
            target_modules=["q_proj", "k_proj", "v_proj", "o_proj",
                           "gate_proj", "up_proj", "down_proj"],
            lora_dropout=0.05,
            bias="none",
            task_type="CAUSAL_LM",
        )
        self.model = get_peft_model(self.model, lora_config)
        self.model.print_trainable_parameters()
    
    def prepare_dataset(self, data_dir: str) -> Dataset:
        """Prepare image-conversation dataset.
        
        Expected structure:
        data_dir/
          images/
            img_001.jpg
            img_002.jpg
          conversations.jsonl  # {"image": "img_001.jpg", "conversations": [...]}
        """
        data_path = Path(data_dir)
        conversations_file = data_path / "conversations.jsonl"
        
        examples = []
        with open(conversations_file) as f:
            for line in f:
                item = json.loads(line)
                image_path = str(data_path / "images" / item["image"])
                
                # Format as chat
                messages = []
                for conv in item["conversations"]:
                    if conv["from"] == "human":
                        messages.append({"role": "user", "content": conv["value"]})
                    else:
                        messages.append({"role": "assistant", "content": conv["value"]})
                
                examples.append({
                    "image_path": image_path,
                    "messages": messages,
                })
        
        return Dataset.from_list(examples)
    
    def train(self, dataset: Dataset, output_dir: str = "./llava_finetuned",
              num_epochs: int = 3, batch_size: int = 1):
        """Fine-tune LLaVA with LoRA."""
        training_args = TrainingArguments(
            output_dir=output_dir,
            num_train_epochs=num_epochs,
            per_device_train_batch_size=batch_size,
            gradient_accumulation_steps=8,
            learning_rate=2e-5,
            bf16=True,
            logging_steps=10,
            save_steps=100,
            gradient_checkpointing=True,
            remove_unused_columns=False,
            dataloader_pin_memory=False,
        )
        
        # Custom data collator for multimodal
        def collate_fn(examples):
            images = [Image.open(ex["image_path"]).convert("RGB") for ex in examples]
            texts = []
            for ex in examples:
                # Format conversation
                text = self.processor.apply_chat_template(ex["messages"], tokenize=False)
                texts.append(text)
            
            batch = self.processor(
                text=texts, images=images,
                return_tensors="pt", padding=True, truncation=True,
                max_length=2048,
            )
            batch["labels"] = batch["input_ids"].clone()
            return batch
        
        from transformers import Trainer
        
        trainer = Trainer(
            model=self.model,
            args=training_args,
            train_dataset=dataset,
            data_collator=collate_fn,
        )
        
        trainer.train()
        trainer.save_model(output_dir)
        print(f"Model saved to {output_dir}")
    
    def evaluate(self, test_images: list[str], questions: list[str]) -> list[str]:
        """Run inference on test images."""
        self.model.eval()
        answers = []
        
        for image_path, question in zip(test_images, questions):
            image = Image.open(image_path).convert("RGB")
            
            messages = [{"role": "user", "content": f"<image>\n{question}"}]
            text = self.processor.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
            
            inputs = self.processor(text=[text], images=[image], return_tensors="pt").to(self.model.device)
            
            with torch.no_grad():
                output_ids = self.model.generate(**inputs, max_new_tokens=256, temperature=0.1)
            
            answer = self.processor.batch_decode(
                output_ids[:, inputs.input_ids.shape[1]:], skip_special_tokens=True
            )[0]
            answers.append(answer)
        
        return answers
```

### Experiment 9.3 — ImageBind for Cross-Modal Retrieval

Use Meta's ImageBind to create a unified embedding space across images, text, audio, and video. This enables searching images with audio queries, or finding videos that match a text description.

```python
import torch
from imagebind import data as imagebind_data
from imagebind.models import imagebind_model
from imagebind.models.imagebind_model import ModalityType
import numpy as np
from pathlib import Path
import json

class CrossModalRetriever:
    """Cross-modal retrieval using ImageBind's unified embedding space."""
    
    def __init__(self, device="cuda"):
        self.model = imagebind_model.imagebind_huge(pretrained=True)
        self.model.eval()
        self.model.to(device)
        self.device = device
        
        # Storage for indexed embeddings
        self.index = {}  # {modality: {"embeddings": np.array, "metadata": [...]}}
    
    def encode(self, modality: str, inputs: list) -> np.ndarray:
        """Encode inputs of a given modality into ImageBind embeddings."""
        if modality == "vision":
            input_data = {ModalityType.VISION: imagebind_data.load_and_transform_vision_data(
                inputs, self.device
            )}
        elif modality == "text":
            input_data = {ModalityType.TEXT: imagebind_data.load_and_transform_text(
                inputs, self.device
            )}
        elif modality == "audio":
            input_data = {ModalityType.AUDIO: imagebind_data.load_and_transform_audio_data(
                inputs, self.device
            )}
        else:
            raise ValueError(f"Unsupported modality: {modality}")
        
        with torch.no_grad():
            embeddings = self.model(input_data)
        
        # Get the embedding for our modality
        modality_key = {
            "vision": ModalityType.VISION,
            "text": ModalityType.TEXT,
            "audio": ModalityType.AUDIO,
        }[modality]
        
        return embeddings[modality_key].cpu().numpy()
    
    def index_collection(self, modality: str, items: list, metadata: list = None):
        """Index a collection of items for retrieval."""
        # Batch encode
        batch_size = 32
        all_embeddings = []
        
        for i in range(0, len(items), batch_size):
            batch = items[i:i + batch_size]
            embs = self.encode(modality, batch)
            all_embeddings.append(embs)
        
        embeddings = np.vstack(all_embeddings)
        # Normalize for cosine similarity
        embeddings = embeddings / np.linalg.norm(embeddings, axis=1, keepdims=True)
        
        self.index[modality] = {
            "embeddings": embeddings,
            "metadata": metadata or items,
        }
        
        print(f"Indexed {len(items)} {modality} items. Embedding dim: {embeddings.shape[1]}")
    
    def cross_modal_search(self, query_modality: str, query: str,
                           target_modality: str, k: int = 5) -> list[dict]:
        """Search across modalities (e.g., text query → image results)."""
        # Encode query
        query_emb = self.encode(query_modality, [query])
        query_emb = query_emb / np.linalg.norm(query_emb)
        
        # Search in target modality index
        target_embs = self.index[target_modality]["embeddings"]
        target_meta = self.index[target_modality]["metadata"]
        
        # Cosine similarity
        scores = np.dot(target_embs, query_emb.T).squeeze()
        top_k = np.argsort(scores)[::-1][:k]
        
        results = []
        for idx in top_k:
            results.append({
                "item": target_meta[idx],
                "score": float(scores[idx]),
                "rank": len(results) + 1,
            })
        
        return results
    
    def demo_cross_modal(self):
        """Demonstrate cross-modal retrieval capabilities."""
        # Index images
        image_paths = list(Path("./image_gallery").glob("*.jpg"))[:100]
        self.index_collection("vision", [str(p) for p in image_paths])
        
        # Text → Image search
        print("\n=== Text → Image Search ===")
        results = self.cross_modal_search("text", "a dog playing in the snow", "vision", k=3)
        for r in results:
            print(f"  [{r['score']:.3f}] {r['item']}")
        
        # Audio → Image search (find images matching a sound)
        print("\n=== Audio → Image Search ===")
        audio_files = list(Path("./audio_clips").glob("*.wav"))[:50]
        if audio_files:
            self.index_collection("audio", [str(p) for p in audio_files])
            results = self.cross_modal_search("text", "ocean waves crashing", "audio", k=3)
            for r in results:
                print(f"  [{r['score']:.3f}] {r['item']}")

# Usage
retriever = CrossModalRetriever()
retriever.demo_cross_modal()
```

**Expected output:**
- Embedding dimension: 1024 (shared across all modalities)
- Encoding speed: ~50 images/sec, ~200 text/sec on RTX 4090
- Cross-modal retrieval accuracy: 60-75% top-5 (text→image), 50-65% (audio→image)

## 📘 10. Appendix: Production Considerations & Theory Bridges

### 10.1 Late vs Early Fusion Architectures

Multimodal models must combine information from different modalities (vision, language, audio). The fusion strategy determines model capability, efficiency, and training complexity.

**Early Fusion (Input-level):**

Concatenate raw modality representations before the main model processes them:

$$
h = f_{\text{transformer}}(\text{concat}(E_{\text{text}}(x_t), E_{\text{vision}}(x_v)))
$$

- **Examples:** Flamingo, LLaVA, Qwen2-VL
- **How it works:** Visual tokens are projected into the same embedding space as text tokens and concatenated into a single sequence. The Transformer processes all tokens jointly.
- **Pros:** Rich cross-modal attention from the first layer; the model can learn complex vision-language interactions.
- **Cons:** Quadratic attention cost over combined sequence length; visual tokens are expensive (a 1024×1024 image = 256-1024 tokens).

**Late Fusion (Decision-level):**

Process each modality independently, then combine at the output:

$$
h_t = f_{\text{text}}(x_t), \quad h_v = f_{\text{vision}}(x_v), \quad y = g(h_t, h_v)
$$

- **Examples:** CLIP (contrastive), ImageBind
- **How it works:** Separate encoders produce fixed-size embeddings per modality. Fusion happens via dot product, concatenation, or a small fusion network.
- **Pros:** Modality encoders can be pretrained independently; efficient retrieval (precompute embeddings).
- **Cons:** Limited cross-modal reasoning; can't attend to specific image regions based on text.

**Middle Fusion (Cross-attention):**

Insert cross-attention layers between modality-specific streams:

$$
h_t^{(l)} = \text{SelfAttn}(h_t^{(l-1)}) + \text{CrossAttn}(h_t^{(l-1)}, h_v)
$$

- **Examples:** Flamingo (gated cross-attention), BLIP-2 (Q-Former)
- **How it works:** The language model has frozen self-attention layers with inserted cross-attention layers that attend to visual features.
- **Pros:** Efficient (visual features computed once, reused across text tokens); can leverage frozen LLMs.
- **Cons:** Cross-attention adds parameters; visual grounding is less precise than early fusion.

**Comparison:**

| Architecture | Cross-Modal Reasoning | Efficiency | Training Data Needed | Retrieval |
|-------------|----------------------|-----------|---------------------|-----------|
| Early Fusion | Excellent | Low (O(n²) on combined) | High (10M+ pairs) | Poor |
| Late Fusion | Limited | High (precompute) | Medium (1M+ pairs) | Excellent |
| Middle Fusion | Good | Medium | Medium | Moderate |

**Production recommendation:**
- **Retrieval systems:** Late fusion (CLIP/ImageBind) — precompute embeddings, fast search.
- **Visual QA/reasoning:** Early fusion (LLaVA/Qwen2-VL) — best understanding.
- **Efficient VLMs:** Middle fusion (BLIP-2/Flamingo) — leverage frozen LLMs.

### 10.2 CLIP Contrastive Learning — Mathematical Foundation

> **Cross-reference:** [[23.5 - Transformer Architectures & LLMs]] for the Transformer encoders used in CLIP, and [[23.1 - Statistical Learning & Optimization]] for the softmax and cross-entropy foundations.

CLIP (Contrastive Language-Image Pre-training) learns aligned vision-language representations through contrastive learning on 400M image-text pairs.

**The CLIP objective:**

Given a batch of $N$ image-text pairs $(I_1, T_1), \ldots, (I_N, T_N)$:

1. Encode images: $\mathbf{v}_i = f_{\text{vision}}(I_i) / \|f_{\text{vision}}(I_i)\|$
2. Encode texts: $\mathbf{t}_i = f_{\text{text}}(T_i) / \|f_{\text{text}}(T_i)\|$
3. Compute similarity matrix: $S_{ij} = \tau \cdot \mathbf{v}_i^T \mathbf{t}_j$

where $\tau$ is a learned temperature parameter.

**The loss (symmetric cross-entropy):**

$$
\mathcal{L}_{\text{image}} = -\frac{1}{N} \sum_{i=1}^N \log \frac{\exp(S_{ii})}{\sum_{j=1}^N \exp(S_{ij})}
$$

$$
\mathcal{L}_{\text{text}} = -\frac{1}{N} \sum_{i=1}^N \log \frac{\exp(S_{ii})}{\sum_{j=1}^N \exp(S_{ji})}
$$

$$
\mathcal{L}_{\text{CLIP}} = \frac{1}{2}(\mathcal{L}_{\text{image}} + \mathcal{L}_{\text{text}})
$$

**Interpretation:** Each image should be most similar to its paired text (and vice versa). The other $N-1$ pairs in the batch serve as negative examples. Larger batch sizes provide harder negatives and better training signal.

**Why temperature $\tau$ matters:**

$$
\text{softmax}(\tau \cdot \mathbf{v}_i^T \mathbf{t}_j)
$$

- High $\tau$ (e.g., 100): sharp distribution, model must be very confident → harder training, better final quality.
- Low $\tau$ (e.g., 1): soft distribution, easier to satisfy → faster convergence but weaker representations.
- CLIP learns $\tau$ as a parameter, typically converging to $\tau \approx 100$ (logit scale = $\log(\tau) \approx 4.6$).

**Batch size requirements:**

CLIP was trained with batch size 32,768. Why so large?

With $N$ pairs, there are $N-1$ negatives per positive. The probability of a "hard negative" (semantically similar but not paired) increases with $N$. Empirically:
- Batch 256: CLIP works but weak zero-shot performance
- Batch 4096: Competitive results
- Batch 32768: State-of-the-art (original CLIP)

For fine-tuning on 24GB GPU, use gradient accumulation to simulate large batches:

```python
# Effective batch size = batch_per_gpu × gradient_accumulation × num_gpus
# Target: 1024+ effective batch size for contrastive learning
# With 1 GPU: batch=16, grad_accum=64 → effective=1024
```

### 10.3 Multimodal Scaling Laws

Recent research (Aghajanyan et al., 2023) shows that multimodal models follow modified scaling laws:

$$
L(N, D_t, D_v) = \frac{A}{N^{\alpha}} + \frac{B}{D_t^{\beta}} + \frac{C}{D_v^{\gamma}} + L_\infty
$$

where $N$ = parameters, $D_t$ = text tokens, $D_v$ = image tokens, and $\alpha, \beta, \gamma$ are modality-specific scaling exponents.

**Key findings:**
- Vision data has diminishing returns faster than text ($\gamma < \beta$)
- Optimal compute allocation: ~70% text, ~30% vision for general VLMs
- Interleaved image-text data is 2-3× more efficient than separate image and text corpora
- The vision encoder can be smaller than the language model (ViT-L sufficient for 7B LLM)
