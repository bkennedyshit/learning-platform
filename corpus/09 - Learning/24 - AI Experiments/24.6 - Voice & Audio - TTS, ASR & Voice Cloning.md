## 📚 1. Concepts & Definitions

| Concept | Definition |
|---------|-----------|
| **ASR** | Automatic Speech Recognition — audio → text |
| **TTS** | Text-to-Speech — text → audio waveform |
| **Voice Cloning** | Generating speech in a specific person's voice |
| **VAD** | Voice Activity Detection — detecting speech vs silence |
| **Mel Spectrogram** | Time-frequency representation of audio (input to models) |
| **Vocoder** | Converts mel spectrograms to audio waveforms (HiFi-GAN, etc.) |
| **Prosody** | Rhythm, stress, and intonation patterns in speech |

## 🔬 2. Theory Briefing

> For transformer architecture underlying Whisper, see [[23.5 - Transformer Architectures & LLMs]].

### Whisper Architecture

Whisper is an encoder-decoder transformer trained on 680K hours of multilingual audio:

```
Audio → Mel Spectrogram (80 bins, 30s chunks) → Encoder → Cross-Attention → Decoder → Text
```

Key features:
- Multitask: transcription, translation, language ID, timestamps
- Robust to noise, accents, and domain shifts
- 30-second processing windows with overlap

### Modern TTS Pipeline

```
Text → Phonemes → Acoustic Model → Mel Spectrogram → Vocoder → Waveform
         (G2P)     (Transformer)                      (HiFi-GAN)
```

Modern end-to-end models (XTTS, F5-TTS) skip explicit phoneme conversion:
```
Text + Speaker Embedding → Transformer/Flow → Waveform
```

### Voice Cloning Approaches

1. **Speaker Embedding:** Extract a fixed-size vector from reference audio, condition TTS on it
2. **In-Context Learning:** Feed reference audio as prefix, model continues in that voice
3. **Fine-tuning:** Train adapter layers on target speaker data (highest quality, most effort)

### Experiment 4.5 — Real-Time Voice Assistant

```python
"""End-to-end voice assistant: Microphone → Whisper → LLM → TTS → Speaker"""
import numpy as np
import sounddevice as sd
import queue
import threading
from faster_whisper import WhisperModel
from TTS.api import TTS
from openai import OpenAI

class VoiceAssistant:
    def __init__(self):
        # ASR
        self.whisper = WhisperModel("medium", device="cuda", compute_type="float16")
        # TTS
        self.tts = TTS("tts_models/multilingual/multi-dataset/xtts_v2").to("cuda")
        # LLM
        self.llm = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")
        
        self.sample_rate = 16000
        self.audio_queue = queue.Queue()
        self.is_listening = False
    
    def record_until_silence(self, silence_threshold=0.01, silence_duration=1.5):
        """Record audio until silence is detected."""
        audio_chunks = []
        silent_chunks = 0
        chunk_duration = 0.1  # 100ms chunks
        samples_per_chunk = int(self.sample_rate * chunk_duration)
        silence_chunks_needed = int(silence_duration / chunk_duration)
        
        print("🎤 Listening...")
        with sd.InputStream(samplerate=self.sample_rate, channels=1, dtype='float32') as stream:
            while True:
                chunk, _ = stream.read(samples_per_chunk)
                audio_chunks.append(chunk)
                
                # Check for silence
                rms = np.sqrt(np.mean(chunk**2))
                if rms < silence_threshold:
                    silent_chunks += 1
                else:
                    silent_chunks = 0
                
                if silent_chunks >= silence_chunks_needed and len(audio_chunks) > 10:
                    break
        
        return np.concatenate(audio_chunks).flatten()
    
    def transcribe(self, audio: np.ndarray) -> str:
        """Transcribe audio to text."""
        # Save temp file (faster-whisper needs file path)
        import tempfile, soundfile as sf
        with tempfile.NamedTemporaryFile(suffix=".wav", delete=False) as f:
            sf.write(f.name, audio, self.sample_rate)
            segments, _ = self.whisper.transcribe(f.name, beam_size=3)
            return " ".join(s.text for s in segments).strip()
    
    def think(self, user_text: str, history: list) -> str:
        """Get LLM response."""
        messages = [{"role": "system", "content": "You are a helpful voice assistant. Keep responses concise (1-3 sentences)."}]
        messages.extend(history)
        messages.append({"role": "user", "content": user_text})
        
        response = self.llm.chat.completions.create(
            model="llama3.1:8b", messages=messages, temperature=0.7, max_tokens=150
        )
        return response.choices[0].message.content
    
    def speak(self, text: str):
        """Convert text to speech and play."""
        import tempfile
        with tempfile.NamedTemporaryFile(suffix=".wav", delete=False) as f:
            self.tts.tts_to_file(text=text, speaker="Ana Florence", language="en", file_path=f.name)
            import soundfile as sf
            audio, sr = sf.read(f.name)
            sd.play(audio, sr)
            sd.wait()
    
    def run(self):
        """Main conversation loop."""
        history = []
        print("Voice Assistant Ready. Speak to begin (Ctrl+C to exit).")
        
        while True:
            try:
                audio = self.record_until_silence()
                user_text = self.transcribe(audio)
                
                if not user_text.strip():
                    continue
                
                print(f"👤 You: {user_text}")
                
                response = self.think(user_text, history)
                print(f"🤖 Assistant: {response}")
                
                history.append({"role": "user", "content": user_text})
                history.append({"role": "assistant", "content": response})
                
                self.speak(response)
                
            except KeyboardInterrupt:
                print("\nGoodbye!")
                break

# Run
assistant = VoiceAssistant()
assistant.run()
```

### Experiment 4.6 — Batch Transcription with Speaker Diarization

```python
from faster_whisper import WhisperModel
import torch

# For speaker diarization, combine Whisper with pyannote
# pip install pyannote.audio

from pyannote.audio import Pipeline as DiarizationPipeline

# Load models
whisper_model = WhisperModel("large-v3", device="cuda", compute_type="float16")
diarization = DiarizationPipeline.from_pretrained(
    "pyannote/speaker-diarization-3.1",
    use_auth_token="YOUR_HF_TOKEN"
).to(torch.device("cuda"))

# Step 1: Diarize (who speaks when)
diarization_result = diarization("meeting_recording.wav")

# Step 2: Transcribe
segments, info = whisper_model.transcribe("meeting_recording.wav", word_timestamps=True)
whisper_segments = list(segments)

# Step 3: Assign speakers to transcription segments
def assign_speakers(whisper_segs, diarization_result):
    """Match whisper segments to diarization speakers."""
    output = []
    for seg in whisper_segs:
        mid_time = (seg.start + seg.end) / 2
        speaker = "UNKNOWN"
        for turn, _, spk in diarization_result.itertracks(yield_label=True):
            if turn.start <= mid_time <= turn.end:
                speaker = spk
                break
        output.append({"speaker": speaker, "start": seg.start, "end": seg.end, "text": seg.text})
    return output

transcript = assign_speakers(whisper_segments, diarization_result)

# Print formatted transcript
current_speaker = None
for entry in transcript:
    if entry["speaker"] != current_speaker:
        current_speaker = entry["speaker"]
        print(f"\n[{current_speaker}] ({entry['start']:.1f}s)")
    print(f"  {entry['text']}")
```

## ⚠️ 6. Gotchas & Debugging

| Issue | Cause | Fix |
|-------|-------|-----|
| Whisper hallucinations | Silence or noise input | Enable VAD filter, check audio quality |
| Whisper repeating text | Long silence segments | Use `no_repeat_ngram_size=3`, VAD |
| TTS robotic quality | Wrong model or sample rate | Use XTTS-v2, ensure 24kHz output |
| Voice clone sounds wrong | Reference too short/noisy | Use 10-30s clean reference, single speaker |
| Audio playback issues | Sample rate mismatch | Resample to match output device |
| CUDA OOM with large-v3 | Model + audio in VRAM | Use faster-whisper (CTranslate2, less VRAM) |

### Audio Quality Checklist

```
Reference audio for voice cloning:
  ✓ 10-30 seconds of clean speech
  ✓ Single speaker only
  ✓ No background music or noise
  ✓ Natural speaking pace (not reading)
  ✓ WAV format, 16-48kHz, mono
  ✗ Compressed formats (MP3 at low bitrate)
  ✗ Multiple speakers
  ✗ Heavy reverb or echo
```

### Experiment 9.1 — Whisper Streaming with Voice Activity Detection (VAD)

Build a real-time transcription pipeline that uses VAD to detect speech segments, then transcribes only active speech. This eliminates Whisper hallucinations on silence and enables low-latency streaming.

```python
import torch
import numpy as np
import time
import threading
import queue
from faster_whisper import WhisperModel
import sounddevice as sd

class StreamingWhisperVAD:
    """Real-time speech transcription with VAD-gated Whisper."""
    
    def __init__(self, 
                 whisper_model="large-v3",
                 vad_threshold=0.5,
                 sample_rate=16000,
                 chunk_duration=0.5,  # 500ms chunks for VAD
                 min_speech_duration=0.5,
                 max_speech_duration=30.0):
        
        # Load Whisper (CTranslate2 backend for speed)
        self.whisper = WhisperModel(whisper_model, device="cuda", compute_type="float16")
        
        # Load Silero VAD
        self.vad_model, self.vad_utils = torch.hub.load(
            'snakers4/silero-vad', 'silero_vad', force_reload=False
        )
        (self.get_speech_timestamps, _, self.read_audio, _, _) = self.vad_utils
        
        self.sample_rate = sample_rate
        self.chunk_size = int(sample_rate * chunk_duration)
        self.vad_threshold = vad_threshold
        self.min_speech_duration = min_speech_duration
        self.max_speech_duration = max_speech_duration
        
        # State
        self.audio_buffer = np.array([], dtype=np.float32)
        self.is_speaking = False
        self.speech_start_time = 0
        self.transcript_queue = queue.Queue()
    
    def vad_check(self, audio_chunk: np.ndarray) -> float:
        """Run VAD on a single chunk, return speech probability."""
        tensor = torch.from_numpy(audio_chunk).float()
        speech_prob = self.vad_model(tensor, self.sample_rate).item()
        return speech_prob
    
    def transcribe_segment(self, audio: np.ndarray) -> str:
        """Transcribe a complete speech segment."""
        # Write to temp file (faster-whisper requires file or array)
        segments, info = self.whisper.transcribe(
            audio, 
            language="en",
            beam_size=5,
            vad_filter=False,  # We handle VAD ourselves
            word_timestamps=True,
        )
        
        text = " ".join(seg.text.strip() for seg in segments)
        return text
    
    def process_chunk(self, audio_chunk: np.ndarray):
        """Process a single audio chunk through VAD + transcription pipeline."""
        speech_prob = self.vad_check(audio_chunk)
        
        if speech_prob >= self.vad_threshold:
            if not self.is_speaking:
                # Speech started
                self.is_speaking = True
                self.speech_start_time = time.perf_counter()
                self.audio_buffer = np.array([], dtype=np.float32)
            
            # Accumulate speech audio
            self.audio_buffer = np.concatenate([self.audio_buffer, audio_chunk])
            
            # Check max duration
            duration = len(self.audio_buffer) / self.sample_rate
            if duration >= self.max_speech_duration:
                self._finalize_segment()
        
        else:
            if self.is_speaking:
                # Speech ended
                duration = len(self.audio_buffer) / self.sample_rate
                if duration >= self.min_speech_duration:
                    self._finalize_segment()
                else:
                    # Too short, discard (likely noise)
                    self.audio_buffer = np.array([], dtype=np.float32)
                self.is_speaking = False
    
    def _finalize_segment(self):
        """Transcribe accumulated speech segment."""
        if len(self.audio_buffer) > 0:
            text = self.transcribe_segment(self.audio_buffer)
            if text.strip():
                latency = time.perf_counter() - self.speech_start_time
                self.transcript_queue.put({
                    "text": text,
                    "duration_s": len(self.audio_buffer) / self.sample_rate,
                    "latency_s": latency,
                })
            self.audio_buffer = np.array([], dtype=np.float32)
    
    def start_streaming(self, duration=60):
        """Start real-time microphone transcription."""
        print(f"🎤 Listening for {duration}s... (Ctrl+C to stop)")
        
        def audio_callback(indata, frames, time_info, status):
            audio_chunk = indata[:, 0].astype(np.float32)
            self.process_chunk(audio_chunk)
        
        with sd.InputStream(
            samplerate=self.sample_rate,
            channels=1,
            blocksize=self.chunk_size,
            callback=audio_callback,
        ):
            start = time.perf_counter()
            while time.perf_counter() - start < duration:
                try:
                    result = self.transcript_queue.get(timeout=0.1)
                    print(f"  [{result['duration_s']:.1f}s, latency={result['latency_s']:.2f}s] "
                          f"{result['text']}")
                except queue.Empty:
                    pass

# Run streaming transcription
streamer = StreamingWhisperVAD(whisper_model="large-v3")
streamer.start_streaming(duration=120)
```

**Expected output:**
- VAD latency: <10ms per chunk (Silero VAD is tiny)
- Transcription latency: 200-500ms after speech ends (faster-whisper large-v3)
- WER: ~2-3% on clear speech (matches offline Whisper quality)
- Hallucination rate: <1% (vs ~5-10% without VAD on silent segments)

**Gotchas:**
- Silero VAD has a 512-sample minimum chunk size at 16kHz (32ms). Smaller chunks produce unreliable results.
- Whisper hallucinates on silence ("Thank you for watching", "Subscribe", etc.) — VAD eliminates this.
- Set `min_speech_duration=0.5s` to avoid transcribing coughs, clicks, and brief noises.
- For multi-speaker scenarios, combine with speaker diarization (see Experiment 9.4).

### Experiment 9.2 — XTTS-v2 Voice Cloning & Fine-tuning

Clone a voice from a short reference clip and fine-tune XTTS-v2 for higher quality on a specific speaker.

```python
import torch
import torchaudio
from TTS.api import TTS
from TTS.tts.configs.xtts_config import XttsConfig
from TTS.tts.models.xtts import Xtts
import time
import os

class VoiceCloner:
    """Voice cloning with XTTS-v2: zero-shot and fine-tuned."""
    
    def __init__(self, device="cuda"):
        self.device = device
        # Load XTTS-v2
        self.tts = TTS("tts_models/multilingual/multi-dataset/xtts_v2").to(device)
    
    def clone_zero_shot(self, text: str, reference_audio: str, 
                        output_path: str = "cloned_output.wav",
                        language: str = "en") -> dict:
        """Zero-shot voice cloning from a single reference clip."""
        start = time.perf_counter()
        
        self.tts.tts_to_file(
            text=text,
            speaker_wav=reference_audio,
            language=language,
            file_path=output_path,
        )
        
        elapsed = time.perf_counter() - start
        
        # Compute real-time factor
        audio_info = torchaudio.info(output_path)
        audio_duration = audio_info.num_frames / audio_info.sample_rate
        rtf = elapsed / audio_duration
        
        return {
            "output_path": output_path,
            "generation_time_s": elapsed,
            "audio_duration_s": audio_duration,
            "real_time_factor": rtf,
        }
    
    def prepare_finetune_dataset(self, audio_dir: str, output_dir: str,
                                  min_duration=3.0, max_duration=15.0):
        """Prepare audio dataset for XTTS fine-tuning."""
        os.makedirs(output_dir, exist_ok=True)
        
        metadata = []
        for audio_file in sorted(os.listdir(audio_dir)):
            if not audio_file.endswith(('.wav', '.mp3', '.flac')):
                continue
            
            filepath = os.path.join(audio_dir, audio_file)
            info = torchaudio.info(filepath)
            duration = info.num_frames / info.sample_rate
            
            if min_duration <= duration <= max_duration:
                # Resample to 22050 Hz (XTTS requirement)
                waveform, sr = torchaudio.load(filepath)
                if sr != 22050:
                    resampler = torchaudio.transforms.Resample(sr, 22050)
                    waveform = resampler(waveform)
                
                # Mono
                if waveform.shape[0] > 1:
                    waveform = waveform.mean(dim=0, keepdim=True)
                
                out_path = os.path.join(output_dir, audio_file.replace('.mp3', '.wav'))
                torchaudio.save(out_path, waveform, 22050)
                
                metadata.append({
                    "audio_file": out_path,
                    "text": "",  # Will be filled by Whisper transcription
                    "duration": duration,
                })
        
        print(f"Prepared {len(metadata)} clips for fine-tuning")
        return metadata

    def evaluate_similarity(self, reference_audio: str, generated_audio: str) -> float:

        from speechbrain.inference.speaker import EncoderClassifier

        )
        
        similarity = torch.nn.functional.cosine_similarity(ref_emb, gen_emb).item()
```

### Experiment 9.3 — Speaker Diarization with Pyannote

Identify who speaks when in multi-speaker audio. Combine with Whisper for speaker-attributed transcription.

```python
import torch
from pyannote.audio import Pipeline
from pyannote.audio.pipelines.utils.hook import ProgressHook
from faster_whisper import WhisperModel
import json
import time

class SpeakerDiarizer:
    """Speaker diarization + transcription pipeline."""
    
    def __init__(self, hf_token: str, device="cuda"):
        # Load pyannote diarization pipeline
        self.diarization = Pipeline.from_pretrained(
            "pyannote/speaker-diarization-3.1",
            use_auth_token=hf_token,
        ).to(torch.device(device))
        
        # Load Whisper for transcription
        self.whisper = WhisperModel("large-v3", device=device, compute_type="float16")
        
        self.device = device
    
    def diarize(self, audio_path: str, num_speakers: int = None) -> list[dict]:
        """Run speaker diarization on audio file."""
        start = time.perf_counter()
        
        # Run diarization
        diarization_kwargs = {}
        if num_speakers:
            diarization_kwargs["num_speakers"] = num_speakers
        
        with ProgressHook() as hook:
            diarization_result = self.diarization(
                audio_path, hook=hook, **diarization_kwargs
            )
        
        # Extract speaker segments
        segments = []
        for turn, _, speaker in diarization_result.itertracks(yield_label=True):
            segments.append({
                "speaker": speaker,
                "start": round(turn.start, 2),
                "end": round(turn.end, 2),
                "duration": round(turn.end - turn.start, 2),
            })
        
        elapsed = time.perf_counter() - start
        print(f"Diarization completed in {elapsed:.1f}s")
        print(f"Found {len(set(s['speaker'] for s in segments))} speakers, "
              f"{len(segments)} segments")
        
        return segments
    
    def transcribe_with_speakers(self, audio_path: str, 
                                  num_speakers: int = None) -> list[dict]:
        """Full pipeline: diarize + transcribe + assign speakers."""
        # Step 1: Diarize
        speaker_segments = self.diarize(audio_path, num_speakers)
        
        # Step 2: Transcribe with word timestamps
        segments, info = self.whisper.transcribe(
            audio_path, word_timestamps=True, language="en"
        )
        whisper_segments = list(segments)
        
        # Step 3: Assign speakers to transcription
        transcript = []
        for seg in whisper_segments:
            # Find speaker at segment midpoint
            mid_time = (seg.start + seg.end) / 2
            speaker = "UNKNOWN"
            
            for spk_seg in speaker_segments:
                if spk_seg["start"] <= mid_time <= spk_seg["end"]:
                    speaker = spk_seg["speaker"]
                    break
            
            transcript.append({
                "speaker": speaker,
                "start": round(seg.start, 2),
                "end": round(seg.end, 2),
                "text": seg.text.strip(),
                "words": [
                    {"word": w.word, "start": w.start, "end": w.end, "probability": w.probability}
                    for w in (seg.words or [])
                ],
            })
        
        return transcript
    
    def format_transcript(self, transcript: list[dict]) -> str:
        """Format transcript as readable text with speaker labels."""
        output = []
        current_speaker = None
        
        for entry in transcript:
            if entry["speaker"] != current_speaker:
                current_speaker = entry["speaker"]
                output.append(f"\n[{current_speaker}] ({entry['start']:.1f}s)")
            output.append(f"  {entry['text']}")
        
        return "\n".join(output)
    
    def export_srt(self, transcript: list[dict], output_path: str):
        """Export as SRT subtitle file with speaker labels."""
        with open(output_path, "w") as f:
            for i, entry in enumerate(transcript, 1):
                start_time = self._seconds_to_srt_time(entry["start"])
                end_time = self._seconds_to_srt_time(entry["end"])
                f.write(f"{i}\n")
                f.write(f"{start_time} --> {end_time}\n")
                f.write(f"[{entry['speaker']}] {entry['text']}\n\n")
    
    @staticmethod
    def _seconds_to_srt_time(seconds: float) -> str:
        h = int(seconds // 3600)
        m = int((seconds % 3600) // 60)
        s = int(seconds % 60)
        ms = int((seconds % 1) * 1000)
        return f"{h:02d}:{m:02d}:{s:02d},{ms:03d}"

# Usage
diarizer = SpeakerDiarizer(hf_token="your_hf_token")

# Full pipeline
transcript = diarizer.transcribe_with_speakers(
    "meeting_recording.wav", num_speakers=3
)

# Print formatted
print(diarizer.format_transcript(transcript))

# Export SRT
diarizer.export_srt(transcript, "meeting_subtitles.srt")

# Save JSON
with open("meeting_transcript.json", "w") as f:
    json.dump(transcript, f, indent=2)
```

**Expected output:**
- Diarization accuracy (DER): 5-10% on clean audio, 15-20% on noisy
- Processing speed: ~0.3× real-time (10 min audio → 3 min processing)
- Speaker identification: correctly separates 2-5 speakers in most cases
- VRAM: ~3 GB for diarization + 5 GB for Whisper = ~8 GB total

**Gotchas:**
- Pyannote requires a HuggingFace token with accepted model terms (gated model).
- Diarization struggles with overlapping speech — it assigns the segment to the louder speaker.
- If you know the number of speakers, always pass `num_speakers` — it significantly improves accuracy.
- Short utterances (<1s) are often misattributed. Post-process by merging adjacent segments from the same speaker.

### 10.1 Mel Spectrogram Math — From Waveform to Model Input

> **Cross-reference:** [[23.5 - Transformer Architectures & LLMs]] for the Transformer architecture that Whisper uses internally.

Every modern ASR and TTS system converts raw audio waveforms into mel spectrograms before processing. Understanding this transform is essential for debugging audio quality issues.

**Step 1: Short-Time Fourier Transform (STFT)**

The raw waveform $x[n]$ is windowed into overlapping frames and transformed:

$$
X[m, k] = \sum_{n=0}^{N-1} x[n + mH] \cdot w[n] \cdot e^{-j2\pi kn/N}
$$

where:
- $m$ = frame index (time)
- $k$ = frequency bin (0 to $N/2$)
- $N$ = FFT size (typically 1024 or 2048)
- $H$ = hop length (typically $N/4$ = 256)
- $w[n]$ = window function (Hann window)

**Step 2: Power Spectrogram**

$$
S[m, k] = |X[m, k]|^2
$$

This gives us energy at each time-frequency point.

**Step 3: Mel Filterbank**

The mel scale approximates human pitch perception (logarithmic above 1kHz):

$$
\text{mel}(f) = 2595 \cdot \log_{10}\left(1 + \frac{f}{700}\right)
$$

We create $M$ triangular filters (typically 80 or 128) spaced linearly on the mel scale:

$$
\text{MelSpec}[m, i] = \sum_{k=0}^{N/2} S[m, k] \cdot H_i[k]
$$

where $H_i[k]$ is the $i$-th triangular mel filter.

**Step 4: Log compression**

$$
\text{LogMelSpec}[m, i] = \log(\text{MelSpec}[m, i] + \epsilon)
$$

The log compression matches human loudness perception (Weber-Fechner law).

**Whisper's specific parameters:**
- Sample rate: 16,000 Hz
- FFT size: 400 (25ms window)
- Hop length: 160 (10ms stride)
- Mel bins: 80
- Input: 30 seconds of audio → 3000 time frames × 80 mel bins

```python
import torch
import torchaudio

def compute_mel_spectrogram(audio_path, n_mels=80, n_fft=400, hop_length=160):
    """Compute mel spectrogram matching Whisper's preprocessing."""
    waveform, sr = torchaudio.load(audio_path)
    
    # Resample to 16kHz if needed
    if sr != 16000:
        resampler = torchaudio.transforms.Resample(sr, 16000)
        waveform = resampler(waveform)
    
    # Compute mel spectrogram
    mel_transform = torchaudio.transforms.MelSpectrogram(
        sample_rate=16000,
        n_fft=n_fft,
        hop_length=hop_length,
        n_mels=n_mels,
        power=2.0,
    )
    
    mel_spec = mel_transform(waveform)
    log_mel_spec = torch.log(mel_spec + 1e-6)
    
    print(f"Waveform shape: {waveform.shape}")
    print(f"Mel spectrogram shape: {log_mel_spec.shape}")
    print(f"Time frames: {log_mel_spec.shape[-1]} ({log_mel_spec.shape[-1] * hop_length / 16000:.1f}s)")
    
    return log_mel_spec
```

**Why mel spectrograms work better than raw waveforms:**
1. **Dimensionality reduction:** 16kHz audio = 16,000 values/sec. Mel spec = 100 frames/sec × 80 bins = 8,000 values/sec (2× compression).
2. **Perceptual alignment:** Mel scale emphasizes frequencies humans distinguish (speech formants at 300-3000 Hz).
3. **Translation invariance:** Pitch shifts become vertical translations in mel space, making them easier for CNNs/Transformers to handle.

### 10.2 Vocoder Comparison — HiFi-GAN vs BigVGAN

Vocoders convert mel spectrograms back to audio waveforms. The choice of vocoder determines the final audio quality of any TTS system.

**HiFi-GAN (Kong et al., 2020):**
- Architecture: Multi-scale discriminator + multi-period discriminator
- Generator: Transposed convolutions with multi-receptive field fusion
- Quality: MOS 4.0-4.2 (near human)
- Speed: 13× real-time on CPU, 1000× on GPU
- Size: 14M parameters

**BigVGAN (Lee et al., 2023):**
- Architecture: HiFi-GAN backbone + anti-aliased activations + snake activations
- Key innovation: Periodic activations ($\text{snake}(x) = x + \frac{1}{\alpha}\sin^2(\alpha x)$) capture harmonic structure
- Quality: MOS 4.3-4.5 (exceeds HiFi-GAN on all metrics)
- Speed: 5× real-time on CPU, 500× on GPU
- Size: 112M parameters (BigVGAN-v2)

**Comparison on speech quality:**

| Vocoder | MOS (↑) | PESQ (↑) | STOI (↑) | RTF (GPU) | Params |
|---------|---------|----------|----------|-----------|--------|
| Griffin-Lim | 2.8 | 2.1 | 0.85 | 0.01× | 0 |
| WaveGlow | 3.8 | 3.5 | 0.92 | 50× | 88M |
| HiFi-GAN (V1) | 4.0 | 3.8 | 0.94 | 1000× | 14M |
| HiFi-GAN (V2) | 4.1 | 3.9 | 0.95 | 1500× | 1M |
| BigVGAN | 4.3 | 4.1 | 0.96 | 500× | 112M |
| BigVGAN-v2 (24kHz) | 4.4 | 4.2 | 0.97 | 400× | 112M |

**When to use which:**
- **HiFi-GAN V2:** Real-time applications, edge devices (tiny model, fast)
- **HiFi-GAN V1:** Standard TTS pipelines (good quality/speed balance)
- **BigVGAN:** Maximum quality (podcast production, audiobook narration)
- **Griffin-Lim:** Only for quick prototyping (no neural network needed)
