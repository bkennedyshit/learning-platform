# 36.3 — Pronouns & Object Placement

> *"In Spanish, pronouns don't just replace nouns — they attach to the verb system and move around according to strict rules that English completely lacks."*

Pronouns in Spanish behave fundamentally differently from English pronouns in one crucial way: **direct and indirect object pronouns are clitics** — short forms that attach to or precede the verb with fixed placement rules. This chapter covers all pronoun types and, most importantly, the clitic placement system that trips up English speakers at every level.

---

## 🎯 Learning Objectives

By the end of this chapter you will be able to:

1. Use all subject pronouns and know when to omit them (Spanish is pro-drop).
2. Identify and use direct object pronouns (lo, la, los, las, me, te, nos, os).
3. Identify and use indirect object pronouns (le, les, me, te, nos, os).
4. Apply the **clitic placement rules** for all verb forms.
5. Handle the *le → se* substitution rule when two clitics appear together.
6. Use reflexive pronouns correctly.
7. Use prepositional (stressed) pronouns correctly after prepositions.

---

## 📚 1. Subject Pronouns

| Person | Singular | Plural |
|--------|---------|--------|
| 1st | *yo* (I) | *nosotros/nosotras* (we) |
| 2nd informal | *tú* (you) | *vosotros/vosotras* (you all — Spain only) |
| 2nd formal | *usted* (you, formal) | *ustedes* (you all — all of Latin America; Spain formal) |
| 3rd M | *él* (he) | *ellos* (they M) |
| 3rd F | *ella* (she) | *ellas* (they F) |

> **Pro-drop:** Spanish is a **pro-drop language** — subject pronouns are usually omitted because the verb ending already identifies the person. *Hablo español* = "I speak Spanish" (no *yo* needed). Pronouns ARE used for: **emphasis** (*Yo sí lo hice* = "I did do it"), **contrast** (*Él estudia pero ella trabaja* = "He studies but she works"), and **clarity** when the form is ambiguous (usted/él/ella share verb forms).

---

## 📚 2. Direct Object Pronouns (DOP)

The direct object answers "whom?" or "what?" after the verb.

| Person | DOP |
|--------|-----|
| me (1st sg) | *me* |
| you informal (2nd sg) | *te* |
| him / it M (3rd sg M) | *lo* |
| her / it F (3rd sg F) | *la* |
| us (1st pl) | *nos* |
| you all Spain (2nd pl) | *os* |
| them M / you all formal M (3rd pl M) | *los* |
| them F / you all formal F (3rd pl F) | *las* |

*¿Ves el libro?* → *¿**Lo** ves?* (Do you see it?)
*Llamo a María.* → *La llamo.* (I'll call her.)
*Ella me ayuda.* (She helps me.)

---

## 📚 3. Indirect Object Pronouns (IOP)

The indirect object answers "to/for whom?" — the beneficiary of the action.

| Person | IOP |
|--------|-----|
| me | *me* |
| you | *te* |
| him/her/you formal | *le* |
| us | *nos* |
| you all Spain | *os* |
| them/you all formal pl | *les* |

*Le doy el libro.* (I give him/her the book.)
*Te mando el correo.* (I send you the email.)
*Nos explicaron la solución.* (They explained the solution to us.)

> **The redundant IOP with a+noun:** When the indirect object is a noun, Spanish commonly uses **both** the noun AND the clitic: *Le doy el libro **a Juan**.* (I give the book to Juan.) This redundancy is grammatical and common — the clitic is not optional when the noun is present.

---

## 📚 4. The Le → Se Rule

When a direct object pronoun (lo/la/los/las) immediately follows an indirect object pronoun (le/les), the **le/les changes to SE** to avoid the *le lo* / *les las* sound clash.

**le + lo → se lo**
**le + la → se la**
**les + los → se los**
*etc.*

*¿Le das el libro a María?* → *¿**Se lo** das (a ella)?* (Do you give it to her?)
*Les expliqué los problemas.* → *Se los expliqué.* (I explained them to them.)

> **Critical note:** This *se* is NOT the reflexive *se* — it is purely a euphonic substitution. Context determines meaning.

---

## 📚 5. Clitic Placement Rules — The Core System

This is the most rule-governed feature in this chapter. The rules are strict and consistent.

### Rule 1 — Before a conjugated verb (one-verb sentence)
*Lo veo.* (I see it.) ← lo before *veo*
*Te llamo mañana.* (I'll call you tomorrow.)
*Me dijeron la verdad.* (They told me the truth.)

### Rule 2 — Infinitive constructions: EITHER position
When a conjugated verb is followed by an **infinitive**, the clitic can go **before the conjugated verb** OR **attached to the end of the infinitive**. Both are equally correct.

*Quiero verlo.* = ***Lo** quiero ver.* (I want to see it.)
*Voy a llamarte.* = **Te** voy a llamar.* (I'm going to call you.)
*Necesito comprarlo.* = ***Lo** necesito comprar.* (I need to buy it.)

### Rule 3 — With gerund (present participle): EITHER position
*Estoy leyéndolo.* = ***Lo** estoy leyendo.* (I'm reading it.)

> **Accent rule:** When attaching a clitic to a gerund, add a written accent if needed to maintain original stress: *leyendo → leyéndolo* (stress stays on the *é*).

### Rule 4 — Attach to affirmative imperatives (commands)
*¡Dímelo!* (Tell it to me! — *di* + *me* + *lo*)
*¡Cómpralo!* (Buy it!)
*¡Escúchame!* (Listen to me!)

> **Accent rule again:** Written accent often needed: *compra → cómpralo*, *di → dímelo*.

### Rule 5 — Before negative imperatives
*No **lo** compres.* (Don't buy it.)
*No **me** digas.* (Don't tell me. / No way!)

### Order when two clitics appear
Indirect always before Direct: **IO + DO**
*me lo, te lo, se lo, nos los, os las*

## 📚 6. Reflexive Pronouns

Used when the subject and object are the same entity (the action reflects back on the subject).

| Person | Reflexive pronoun |
|--------|-----------------|
| yo | *me* |
| tú | *te* |
| él/ella/usted | *se* |
| nosotros | *nos* |
| vosotros | *os* |
| ellos/ellas/ustedes | *se* |

*Me lavo las manos.* (I wash my hands.)
*Ella se despierta a las seis.* (She wakes up at six.)
*Nos llamamos Pedro y María.* (We call ourselves Pedro and María. / Our names are Pedro and María.)

**Reflexive verbs with inherent reflexivity (no English equivalent):**
*irse* (to leave/go away), *dormirse* (to fall asleep), *levantarse* (to get up), *sentarse* (to sit down), *quejarse* (to complain), *darse cuenta* (to realize), *atreverse* (to dare)

**Reciprocal reflexive** ("each other"):
*Nos vemos mañana.* (We'll see each other tomorrow.)
*Se quieren.* (They love each other.)

---

## 📚 7. Prepositional (Stressed) Pronouns

Used after prepositions. These are different from subject and object pronouns.

| Person | Prepositional pronoun |
|--------|---------------------|
| yo | *mí* |
| tú | *ti* |
| él/ella/usted | *él/ella/usted* |
| nosotros | *nosotros/nosotras* |
| vosotros | *vosotros/vosotras* |
| ellos/ellas/ustedes | *ellos/ellas/ustedes* |

*Es para **mí**.* (It's for me.)
*Vengo contigo.* (I come with you.) ← *con + ti* → *contigo* (special form)
*Hablan de **él**.* (They talk about him.)
*Entre **tú** y **yo**.* (Between you and me — note: *yo* not *mí* after *entre*)

**Special combined forms with *con*:**
*conmigo* (with me), *contigo* (with you), *consigo* (with himself/herself/themselves)

---

## 📚 8. Demonstrative Pronouns

| | M sg | F sg | M pl | F pl | Neuter |
|--|------|------|------|------|-------|
| **This/these** | *este* | *esta* | *estos* | *estas* | *esto* |
| **That/those** | *ese* | *esa* | *esos* | *esas* | *eso* |
| **That over there** | *aquel* | *aquella* | *aquellos* | *aquellas* | *aquello* |

When used as adjectives (before a noun): *este libro, esa mesa, aquellos estudiantes*
When used as pronouns (replacing a noun): can be written the same (*éste*, *ése*, *aquél* — accents now optional per RAE).
Neuter forms (*esto, eso, aquello*) refer to ideas or unidentified things: *¿Qué es **esto**?* (What is this?)

## ⚠️ 9. Common Errors

| Error | Wrong | Right |
|-------|-------|-------|
| Placing DOP after conjugated verb | *Veo lo.* | ***Lo** veo.* |
| Forgetting le → se | *Le lo di.* | ***Se lo** di.* |
| Wrong order (DO before IO) | *Lo me das.* | ***Me lo** das.* |
| Separating clitic from imperative | *¡Compra lo!* | *¡**Cómpralo!*** |
| Using subject pronoun after preposition | *Para yo…* | *Para **mí**…* |
