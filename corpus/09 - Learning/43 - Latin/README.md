# 🏛️ 43 - Latin

*Part of [[00 - 09 - Learning Index|Learning Index]]*

Adult-learner Latin track — zero to reading classical prose (Caesar, Cicero) and poetry (Virgil, Ovid) — treating Latin as a logical inflected system where grammar is the architecture, not a set of rules to memorize. Latin is the foundation of all Romance languages and ~30% of English vocabulary.
