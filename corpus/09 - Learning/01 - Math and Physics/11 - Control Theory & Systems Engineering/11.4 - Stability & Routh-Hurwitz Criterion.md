# 11.4 — Stability & Routh-Hurwitz Criterion

> *"A feedback system is stable if and only if all roots of the characteristic equation have negative real parts — but finding those roots for high-order polynomials is the challenge that Routh and Hurwitz elegantly circumvented."*
> — Karl Johan Åström

Stability is the most fundamental requirement of any control system. An unstable system's output grows without bound — no amount of performance tuning matters if the system is unstable. The Routh-Hurwitz criterion provides an algebraic test that determines stability (and counts unstable poles) without ever solving for the roots of the characteristic polynomial.

---

By the end of this chapter you will be able to:

4. Handle special cases: zero in first column, row of zeros.
5. Determine ranges of gain $K$ for stability using Routh-Hurwitz.
6. Apply necessary conditions for stability (all coefficients positive and present).

## 📚 1. Definitions

### Definition 11.4.1 — BIBO Stability

A system is **Bounded-Input Bounded-Output (BIBO) stable** if every bounded input produces a bounded output. For an LTI system with transfer function $G(s)$, BIBO stability requires all poles of $G(s)$ to have strictly negative real parts.

### Definition 11.4.2 — Asymptotic Stability

A system is **asymptotically stable** if its impulse response decays to zero: $\lim_{t\to\infty} g(t) = 0$. Equivalent to all poles in the open left half-plane.

### Definition 11.4.3 — Marginal Stability

A system is **marginally stable** if it has simple (non-repeated) poles on the imaginary axis and no poles in the RHP. The impulse response neither grows nor decays — it sustains oscillation.

### Definition 11.4.4 — Characteristic Polynomial

For a closed-loop system with open-loop transfer function $L(s)$, the characteristic polynomial is:

$$
\Delta(s) = 1 + L(s) \quad \text{(set to polynomial form by clearing denominators)}
$$

If $L(s) = N(s)/D(s)$, then $\Delta(s) = D(s) + N(s)$.

### Definition 11.4.5 — Hurwitz Polynomial

A polynomial $p(s) = a_n s^n + a_{n-1}s^{n-1} + \cdots + a_1 s + a_0$ is **Hurwitz** (or **stable**) if all its roots have negative real parts.

### Definition 11.4.6 — The Routh Array

For polynomial $p(s) = a_n s^n + a_{n-1}s^{n-1} + \cdots + a_0$, the Routh array is a triangular table with $n+1$ rows:

| Row | $s^n$ | | | |
|:---:|:---:|:---:|:---:|:---:|
| $s^n$ | $a_n$ | $a_{n-2}$ | $a_{n-4}$ | $\cdots$ |
| $s^{n-1}$ | $a_{n-1}$ | $a_{n-3}$ | $a_{n-5}$ | $\cdots$ |
| $s^{n-2}$ | $b_1$ | $b_2$ | $b_3$ | $\cdots$ |
| $s^{n-3}$ | $c_1$ | $c_2$ | $c_3$ | $\cdots$ |
| $\vdots$ | | | | |
| $s^0$ | | | | |

where:

$$
b_1 = \frac{a_{n-1} \cdot a_{n-2} - a_n \cdot a_{n-3}}{a_{n-1}}, \quad b_2 = \frac{a_{n-1} \cdot a_{n-4} - a_n \cdot a_{n-5}}{a_{n-1}}
$$

$$
c_1 = \frac{b_1 \cdot a_{n-3} - a_{n-1} \cdot b_2}{b_1}, \quad \text{etc.}
$$

## 📐 2. Axioms / Postulates

### Axiom 11.4.A1 — Necessary Condition for Stability

For a polynomial with real coefficients to be Hurwitz, **all coefficients must be positive** (assuming $a_n > 0$) and **no coefficient may be zero**. If any coefficient is missing or negative, the polynomial has at least one root with non-negative real part.

### Axiom 11.4.A2 — Sufficient Condition Requires Routh Test

The necessary condition (all positive coefficients) is sufficient only for polynomials of degree $\leq 2$. For degree $\geq 3$, the Routh-Hurwitz criterion provides the complete test.

## 🛡️ 3. Lemmas

### Lemma 11.4.1 — Sign Changes Count RHP Roots

The number of roots of $p(s)$ with positive real parts equals the number of **sign changes** in the first column of the Routh array.

### Lemma 11.4.2 — Special Case: Zero in First Column

If a zero appears in the first column (but the row is not all zeros), replace it with a small positive number $\epsilon$ and continue. After completing the array, take $\lim_{\epsilon \to 0^+}$ to determine signs.

### Lemma 11.4.3 — Special Case: Row of Zeros

A row of all zeros indicates:
1. The polynomial has roots that are symmetric about the origin (e.g., $\pm j\omega$, $\pm\sigma$, or $\pm\sigma \pm j\omega$).
2. **Procedure**: Form the **auxiliary polynomial** $A(s)$ from the row above the zero row. Replace the zero row with $dA/ds$ and continue.

### Lemma 11.4.4 — Auxiliary Polynomial

The auxiliary polynomial's roots are the symmetric root pairs. These roots are also roots of the original polynomial. If they lie on the $j\omega$-axis, the system is marginally stable.

## 👑 4. Theorems

### Theorem 11.4.1 — The Routh-Hurwitz Stability Criterion

A polynomial $p(s) = a_n s^n + a_{n-1}s^{n-1} + \cdots + a_0$ with $a_n > 0$ has all roots in the open left half-plane if and only if **all entries in the first column of the Routh array are positive**.

The number of sign changes in the first column equals the number of roots with positive real parts.

### Theorem 11.4.2 — Hurwitz Determinant Criterion (Equivalent Form)

The polynomial $p(s)$ is Hurwitz if and only if all leading principal minors of the Hurwitz matrix are positive:

$$
H = \begin{pmatrix} a_{n-1} & a_n & 0 & 0 & \cdots \\ a_{n-3} & a_{n-2} & a_{n-1} & a_n & \cdots \\ a_{n-5} & a_{n-4} & a_{n-3} & a_{n-2} & \cdots \\ \vdots & & & & \ddots \end{pmatrix}
$$

$\Delta_1 = a_{n-1} > 0$, $\Delta_2 = a_{n-1}a_{n-2} - a_n a_{n-3} > 0$, etc.

### Theorem 11.4.3 — Gain Margin from Routh Array

For a system with characteristic polynomial containing parameter $K$, the Routh array entries are functions of $K$. The range of $K$ for stability is found by requiring all first-column entries to be positive simultaneously.

## ✍️ 5. Proofs / Derivations

### 5.1 — Complete Routh Array Construction for a 4th-Order Polynomial

**Given:** $p(s) = s^4 + 2s^3 + 3s^2 + 4s + 5$

**Step 1 — First two rows** (from coefficients):

| Row | Col 1 | Col 2 | Col 3 |
|:---:|:---:|:---:|:---:|
| $s^4$ | 1 | 3 | 5 |
| $s^3$ | 2 | 4 | 0 |

**Step 2 — Compute $s^2$ row:**

$$
b_1 = \frac{(2)(3) - (1)(4)}{2} = \frac{6-4}{2} = 1
$$

$$
b_2 = \frac{(2)(5) - (1)(0)}{2} = \frac{10}{2} = 5
$$

| $s^2$ | 1 | 5 | |

**Step 3 — Compute $s^1$ row:**

$$
c_1 = \frac{(1)(4) - (2)(5)}{1} = \frac{4-10}{1} = -6
$$

| $s^1$ | $-6$ | 0 | |

**Step 4 — Compute $s^0$ row:**

$$
d_1 = \frac{(-6)(5) - (1)(0)}{-6} = \frac{-30}{-6} = 5
$$

| $s^0$ | 5 | | |

**Complete Routh Array:**

| Row | Col 1 | Col 2 | Col 3 |
|:---:|:---:|:---:|:---:|
| $s^4$ | 1 | 3 | 5 |
| $s^3$ | 2 | 4 | 0 |
| $s^2$ | 1 | 5 | |
| $s^1$ | **−6** | 0 | |
| $s^0$ | 5 | | |

**Step 5 — Count sign changes in first column:** $1, 2, 1, -6, 5$

- $1 \to 2$: no change
- $2 \to 1$: no change
- $1 \to -6$: **sign change** (+ to −)
- $-6 \to 5$: **sign change** (− to +)

**Result:** 2 sign changes → **2 roots in the RHP**. System is **unstable**.

### 5.2 — Routh Array with Parameter K: Finding Stability Range

**Given:** Characteristic polynomial $p(s) = s^3 + 3s^2 + (2+K)s + 4K$ where $K > 0$.

**Step 1 — Necessary condition:** All coefficients positive.
- $a_3 = 1 > 0$ ✓
- $a_2 = 3 > 0$ ✓
- $a_1 = 2 + K > 0$ for $K > -2$ (satisfied since $K > 0$) ✓
- $a_0 = 4K > 0$ for $K > 0$ ✓

**Step 2 — Routh array:**

| Row | Col 1 | Col 2 |
|:---:|:---:|:---:|
| $s^3$ | 1 | $2+K$ |
| $s^2$ | 3 | $4K$ |
| $s^1$ | $b_1$ | 0 |
| $s^0$ | $4K$ | |

$$
b_1 = \frac{3(2+K) - 1(4K)}{3} = \frac{6 + 3K - 4K}{3} = \frac{6 - K}{3}
$$

**Step 3 — Stability requires all first-column entries positive:**
- $1 > 0$ ✓
- $3 > 0$ ✓
- $\dfrac{6-K}{3} > 0 \implies K < 6$
- $4K > 0 \implies K > 0$

**Result:** System is stable for $\boxed{0 < K < 6}$.

**At $K = 6$:** The $s^1$ row becomes zero → auxiliary polynomial from $s^2$ row: $A(s) = 3s^2 + 24 = 0 \implies s = \pm 2j\sqrt{2}$. System has sustained oscillations (marginally stable) at frequency $\omega = 2\sqrt{2}$ rad/s.

### 5.3 — Special Case: Zero in First Column

**Given:** $p(s) = s^5 + 2s^4 + 3s^3 + 6s^2 + 5s + 3$

| Row | Col 1 | Col 2 | Col 3 |
|:---:|:---:|:---:|:---:|
| $s^5$ | 1 | 3 | 5 |
| $s^4$ | 2 | 6 | 3 |
| $s^3$ | $\frac{2(3)-1(6)}{2} = 0 → \epsilon$ | $\frac{2(5)-1(3)}{2} = 3.5$ | |
| $s^2$ | $\frac{\epsilon(6) - 2(3.5)}{\epsilon} = \frac{6\epsilon - 7}{\epsilon}$ | $\frac{\epsilon(3)-2(0)}{\epsilon} = 3$ | |
| $s^1$ | ... | | |
| $s^0$ | 3 | | |

As $\epsilon \to 0^+$: the $s^2$ entry → $\dfrac{-7}{\epsilon} \to -\infty$ (negative).

First column signs: $+, +, +, -, ..., +$ → at least 2 sign changes → **unstable** (2 RHP roots).

### 5.4 — Special Case: Row of Zeros

**Given:** $p(s) = s^4 + s^3 + 3s^2 + 2s + 2$

| Row | Col 1 | Col 2 | Col 3 |
|:---:|:---:|:---:|:---:|
| $s^4$ | 1 | 3 | 2 |
| $s^3$ | 1 | 2 | 0 |
| $s^2$ | $\frac{1(3)-1(2)}{1} = 1$ | $\frac{1(2)-1(0)}{1} = 2$ | |
| $s^1$ | $\frac{1(2)-1(2)}{1} = 0$ | **← Row of zeros!** | |

**Procedure:** Form auxiliary polynomial from $s^2$ row:

$$
A(s) = 1 \cdot s^2 + 2 \cdot s^0 = s^2 + 2
$$

Differentiate: $\dfrac{dA}{ds} = 2s$

Replace $s^1$ row with coefficients of $2s$: $[2, 0]$

Continue:

| $s^1$ | 2 | 0 | |
| $s^0$ | 2 | | |

First column: $1, 1, 1, 2, 2$ — **no sign changes** → no RHP roots.

The auxiliary polynomial $s^2 + 2 = 0$ gives $s = \pm j\sqrt{2}$ — poles on the imaginary axis.

**Conclusion:** System is **marginally stable** with sustained oscillation at $\omega = \sqrt{2}$ rad/s.

## 🧮 6. Worked Examples

### Example 11.4.1 — Full Routh-Hurwitz for a 5th-Order System

Determine stability of: $p(s) = 2s^5 + 3s^4 + 2s^3 + 3s^2 + 2s + 1$

**Necessary condition:** All coefficients positive ✓

**Routh Array:**

| Row | Col 1 | Col 2 | Col 3 |
|:---:|:---:|:---:|:---:|
| $s^5$ | 2 | 2 | 2 |
| $s^4$ | 3 | 3 | 1 |
| $s^3$ | $\frac{3(2)-2(3)}{3} = 0 → \epsilon$ | $\frac{3(2)-2(1)}{3} = \frac{4}{3}$ | |
| $s^2$ | $\frac{\epsilon(3)-3(4/3)}{\epsilon} = \frac{3\epsilon - 4}{\epsilon}$ | $\frac{\epsilon(1)-3(0)}{\epsilon} = 1$ | |
| $s^1$ | ... | | |
| $s^0$ | 1 | | |

As $\epsilon \to 0^+$: $s^2$ entry → $-4/\epsilon \to -\infty$ (negative).

For $s^1$: $\dfrac{(-4/\epsilon)(4/3) - \epsilon(1)}{-4/\epsilon} \approx \dfrac{-16/(3\epsilon)}{-4/\epsilon} = \dfrac{4}{3}$ (positive).

First column signs: $+, +, +, -, +, +$ → **2 sign changes** → 2 RHP roots. **Unstable.**

---

### Example 11.4.2 — Gain Range for a Feedback System

Unity feedback system with $G(s) = \dfrac{K}{s(s+1)(s+4)}$.

Characteristic equation: $s^3 + 5s^2 + 4s + K = 0$

**Routh Array:**

| Row | Col 1 | Col 2 |
|:---:|:---:|:---:|
| $s^3$ | 1 | 4 |
| $s^2$ | 5 | $K$ |
| $s^1$ | $\frac{5(4)-1(K)}{5} = \frac{20-K}{5}$ | |
| $s^0$ | $K$ | |

**Stability conditions:**
- $\dfrac{20-K}{5} > 0 \implies K < 20$
- $K > 0$

**Stable range:** $\boxed{0 < K < 20}$

**At $K = 20$:** Auxiliary polynomial from $s^2$ row: $5s^2 + 20 = 0 \implies s = \pm 2j$. Oscillation frequency = 2 rad/s.

---

### Example 11.4.3 — System with Two Parameters

Characteristic polynomial: $s^3 + as^2 + bs + 6 = 0$ where $a, b > 0$.

**Routh Array:**

| Row | Col 1 | Col 2 |
|:---:|:---:|:---:|
| $s^3$ | 1 | $b$ |
| $s^2$ | $a$ | 6 |
| $s^1$ | $\frac{ab-6}{a}$ | |
| $s^0$ | 6 | |

**Stability requires:** $\dfrac{ab-6}{a} > 0 \implies ab > 6$ (since $a > 0$).

**Stability region in $(a,b)$ space:** The hyperbola $ab = 6$ is the stability boundary. System is stable for $ab > 6$ with $a > 0$, $b > 0$.

---

### Example 11.4.4 — Relative Stability (Shifted Axis Test)

Determine if all roots of $p(s) = s^3 + 6s^2 + 11s + 6$ have real parts less than $-1$.

**Method:** Substitute $s = \hat{s} - 1$ (shift the test axis to $\sigma = -1$):

$$
(\hat{s}-1)^3 + 6(\hat{s}-1)^2 + 11(\hat{s}-1) + 6
$$

Expand:
- $(\hat{s}-1)^3 = \hat{s}^3 - 3\hat{s}^2 + 3\hat{s} - 1$
- $6(\hat{s}-1)^2 = 6\hat{s}^2 - 12\hat{s} + 6$
- $11(\hat{s}-1) = 11\hat{s} - 11$

Sum: $\hat{s}^3 + 3\hat{s}^2 + 2\hat{s} + 0$

$$
\hat{p}(\hat{s}) = \hat{s}^3 + 3\hat{s}^2 + 2\hat{s}
$$

**Problem:** $a_0 = 0$ (missing constant term) → necessary condition fails → at least one root has $\text{Re}(s) \geq -1$.

Indeed, the original polynomial factors as $(s+1)(s+2)(s+3)$, so $s = -1$ is a root with $\text{Re}(s) = -1$ (not strictly less than $-1$).

## 📚 Appendix — Extended Routh-Hurwitz Examples

### A.1 — Complete 5th-Order System Analysis

**Given:** $p(s) = s^5 + 4s^4 + 8s^3 + 12s^2 + 10s + 4$

**Step 1 — Necessary condition:** All coefficients positive ✓ (1, 4, 8, 12, 10, 4)

**Step 2 — Routh Array Construction:**

| Row | Col 1 | Col 2 | Col 3 |
|:---:|:---:|:---:|:---:|
| $s^5$ | 1 | 8 | 10 |
| $s^4$ | 4 | 12 | 4 |
| $s^3$ | $\frac{4(8)-1(12)}{4} = \frac{20}{4} = 5$ | $\frac{4(10)-1(4)}{4} = \frac{36}{4} = 9$ | 0 |
| $s^2$ | $\frac{5(12)-4(9)}{5} = \frac{24}{5} = 4.8$ | $\frac{5(4)-4(0)}{5} = 4$ | 0 |
| $s^1$ | $\frac{4.8(9)-5(4)}{4.8} = \frac{23.2}{4.8} = 4.833$ | 0 | 0 |
| $s^0$ | 4 | | |

**Step 3 — First column:** $1, 4, 5, 4.8, 4.833, 4$ — all positive.

**Result:** No sign changes → **all 5 roots in LHP → STABLE** ✓

**Verification:** The polynomial factors as $(s+2)(s^2+s+1)(s^2+s+2)$. Roots: $s = -2$, $s = -0.5 \pm j0.866$, $s = -0.5 \pm j1.323$. All have negative real parts.

### A.2 — Routh-Hurwitz with Symbolic Parameters (Two Parameters)

**Given:** Characteristic equation $s^4 + 2s^3 + (1+K)s^2 + (2+K)s + 2K = 0$

**Routh Array:**

| Row | Col 1 | Col 2 | Col 3 |
|:---:|:---:|:---:|:---:|
| $s^4$ | 1 | $1+K$ | $2K$ |
| $s^3$ | 2 | $2+K$ | 0 |
| $s^2$ | $\frac{2(1+K)-1(2+K)}{2} = \frac{K}{2}$ | $\frac{2(2K)-0}{2} = 2K$ | |
| $s^1$ | $\frac{(K/2)(2+K) - 2(2K)}{K/2} = \frac{K(2+K)/2 - 4K}{K/2}$ | | |
| $s^0$ | $2K$ | | |

Simplify $s^1$ entry:

$$
\frac{K(2+K)/2 - 4K}{K/2} = \frac{(2K+K^2-8K)/2}{K/2} = \frac{K^2-6K}{K} = K - 6
$$

**Stability conditions** (all first-column entries positive):
1. $K/2 > 0 \implies K > 0$
2. $K - 6 > 0 \implies K > 6$
3. $2K > 0 \implies K > 0$

**Stable range:** $\boxed{K > 6}$

**At $K = 6$:** $s^1$ row is zero. Auxiliary polynomial from $s^2$ row: $(K/2)s^2 + 2K = 3s^2 + 12 = 0 \implies s = \pm 2j$. Sustained oscillation at $\omega = 2$ rad/s.

### A.3 — Relative Stability Analysis

**Problem:** For $p(s) = s^3 + 8s^2 + 25s + 26$, determine if all roots have $\text{Re}(s) < -2$.

**Method:** Substitute $s = \hat{s} - 2$:

$$
(\hat{s}-2)^3 + 8(\hat{s}-2)^2 + 25(\hat{s}-2) + 26
$$

Expand each term:
- $(\hat{s}-2)^3 = \hat{s}^3 - 6\hat{s}^2 + 12\hat{s} - 8$
- $8(\hat{s}-2)^2 = 8\hat{s}^2 - 32\hat{s} + 32$
- $25(\hat{s}-2) = 25\hat{s} - 50$

Sum: $\hat{s}^3 + 2\hat{s}^2 + 5\hat{s} + 0$

$$
\hat{p}(\hat{s}) = \hat{s}^3 + 2\hat{s}^2 + 5\hat{s}
$$

**Problem:** $a_0 = 0$ → necessary condition fails. Factor: $\hat{s}(\hat{s}^2 + 2\hat{s} + 5) = 0$

Root $\hat{s} = 0$ means $s = -2$ (on the boundary, not strictly less than $-2$).

Other roots: $\hat{s} = -1 \pm 2j$ → $s = -3 \pm 2j$ (these satisfy $\text{Re}(s) < -2$).

**Conclusion:** Not all roots have $\text{Re}(s) < -2$; one root is exactly at $s = -2$.

### A.4 — Stability of a Feedback System with Transport Delay (Padé Approximation)

A system with delay $e^{-0.5s}$ is approximated by first-order Padé: $e^{-0.5s} \approx \dfrac{1 - 0.25s}{1 + 0.25s}$

Open-loop: $L(s) = \dfrac{K(1-0.25s)}{s(s+2)(1+0.25s)}$

Characteristic equation (unity feedback): $s(s+2)(1+0.25s) + K(1-0.25s) = 0$

Expand: $0.25s^3 + 1.5s^2 + 2s + K - 0.25Ks = 0$

Multiply by 4: $s^3 + 6s^2 + (8-K)s + 4K = 0$

**Routh Array:**

| $s^3$ | 1 | $8-K$ |
| $s^2$ | 6 | $4K$ |
| $s^1$ | $\frac{6(8-K)-4K}{6} = \frac{48-10K}{6}$ | |
| $s^0$ | $4K$ | |

**Stability:** $48 - 10K > 0 \implies K < 4.8$ and $K > 0$.

**Stable range with delay:** $0 < K < 4.8$ (much more restrictive than without delay!).

### A.5 — Hurwitz Determinant Method (Alternative to Routh)

For $p(s) = s^3 + 6s^2 + 11s + 6$, verify stability using Hurwitz determinants.

**Hurwitz matrix:**

$$
H = \begin{pmatrix} a_2 & a_3 & 0 \\ a_0 & a_1 & a_2 \\ 0 & 0 & a_0 \end{pmatrix} = \begin{pmatrix} 6 & 1 & 0 \\ 6 & 11 & 6 \\ 0 & 0 & 6 \end{pmatrix}
$$

**Leading principal minors:**

$$
\Delta_1 = 6 > 0 \quad \checkmark
$$

$$
\Delta_2 = \det\begin{pmatrix} 6 & 1 \\ 6 & 11 \end{pmatrix} = 66 - 6 = 60 > 0 \quad \checkmark
$$

$$
\Delta_3 = \det(H) = 6(11 \cdot 6 - 6 \cdot 0) - 1(6 \cdot 6 - 6 \cdot 0) + 0 = 6(66) - 36 = 360 > 0 \quad \checkmark
$$

All Hurwitz determinants positive → **STABLE**.

(Indeed: $p(s) = (s+1)(s+2)(s+3)$, all roots negative real.)

## 🧠 8. Extended Worked Examples & Deep Dives

### Problem 11.4.E1 — Full Routh Array for a 5th-Order Polynomial with Parameter $K$

> **Problem:** A unity feedback system has open-loop transfer function:
>
> $$G(s) = \frac{K}{s(s+1)(s+2)(s+3)(s+4)}$$
>
> (a) Write the characteristic equation.
> (b) Construct the complete Routh array.
> (c) Find the range of $K$ for closed-loop stability.
> (d) Find the frequency of oscillation at the stability boundary.

<details>
<summary>🔍 View Step-by-Step Solution</summary>

#### Part (a): Characteristic Equation

$$
1 + G(s) = 0 \implies s(s+1)(s+2)(s+3)(s+4) + K = 0
$$

Expand the polynomial step by step:

$$
s(s+1) = s^2 + s
$$

$$
(s^2+s)(s+2) = s^3 + 3s^2 + 2s
$$

$$
(s^3+3s^2+2s)(s+3) = s^4 + 6s^3 + 11s^2 + 6s
$$

$$
(s^4+6s^3+11s^2+6s)(s+4) = s^5 + 10s^4 + 35s^3 + 50s^2 + 24s
$$

Characteristic equation:

$$
s^5 + 10s^4 + 35s^3 + 50s^2 + 24s + K = 0
$$

#### Part (b): Routh Array

| Row | $c_1$ | $c_2$ | $c_3$ |
|:---:|:---:|:---:|:---:|
| $s^5$ | 1 | 35 | 24 |
| $s^4$ | 10 | 50 | $K$ |
| $s^3$ | $\frac{10(35)-1(50)}{10} = \frac{300}{10} = 30$ | $\frac{10(24)-1(K)}{10} = \frac{240-K}{10}$ | 0 |
| $s^2$ | $\frac{30(50)-10\cdot\frac{240-K}{10}}{30} = \frac{1500-(240-K)}{30} = \frac{1260+K}{30}$ | $\frac{30(K)-10(0)}{30} = K$ | 0 |
| $s^1$ | $\frac{\frac{1260+K}{30}\cdot\frac{240-K}{10} - 30 \cdot K}{\frac{1260+K}{30}}$ | 0 | 0 |
| $s^0$ | $K$ | | |

Let me compute the $s^1$ entry more carefully. Denote $R_3 = 30$, $R_3' = \dfrac{240-K}{10}$, $R_2 = \dfrac{1260+K}{30}$, $R_2' = K$.

$$
s^1 \text{ entry} = \frac{R_2 \cdot R_3' - R_3 \cdot R_2'}{R_2} = R_3' - \frac{R_3 \cdot R_2'}{R_2}
$$

$$
= \frac{240-K}{10} - \frac{30K}{\frac{1260+K}{30}} = \frac{240-K}{10} - \frac{900K}{1260+K}
$$

$$
= \frac{(240-K)(1260+K) - 9000K}{10(1260+K)}
$$

Expand the numerator:

$$
(240-K)(1260+K) = 302400 + 240K - 1260K - K^2 = 302400 - 1020K - K^2
$$

$$
302400 - 1020K - K^2 - 9000K = 302400 - 10020K - K^2
$$

So:

$$
s^1 \text{ entry} = \frac{-K^2 - 10020K + 302400}{10(1260+K)}
$$

$$
= \frac{-(K^2 + 10020K - 302400)}{10(1260+K)}
$$

#### Part (c): Stability Conditions

All first-column entries must be positive. Since $K \gt  0$ is required (from $s^0$ row):

1. $s^3$ row: $30 \gt  0$ ✓ (always)
2. $s^3$ row, col 2: $\dfrac{240-K}{10} \gt  0 \implies K \lt  240$
3. $s^2$ row: $\dfrac{1260+K}{30} \gt  0$ ✓ (always for $K \gt  0$)
4. $s^1$ row: $-(K^2 + 10020K - 302400) \gt  0$ (since denominator is positive for $K \gt  0$)

$$
K^2 + 10020K - 302400 \lt  0
$$

Solve the quadratic: $K = \dfrac{-10020 \pm \sqrt{10020^2 + 4(302400)}}{2}$

$$
= \frac{-10020 \pm \sqrt{100400400 + 1209600}}{2} = \frac{-10020 \pm \sqrt{101610000}}{2}
$$

$$
= \frac{-10020 \pm 10080.2}{2}
$$

Positive root: $K = \dfrac{-10020 + 10080.2}{2} = \dfrac{60.2}{2} \approx 30.1$

So the $s^1$ condition gives $K \lt  30.1$.

Combined with $K \lt  240$ and $K \gt  0$:

$$
\boxed{0 \lt  K \lt  30.1}
$$

(The binding constraint is the $s^1$ row, not the $K \lt  240$ condition.)

#### Part (d): Frequency of Oscillation at $K = 30.1$

At the stability boundary, the $s^1$ row becomes zero. The auxiliary polynomial comes from the $s^2$ row:

$$
\frac{1260 + 30.1}{30}s^2 + 30.1 = 0
$$

$$
43.0\,s^2 + 30.1 = 0 \implies s^2 = -0.700 \implies s = \pm j0.836
$$

$$
\boxed{\omega_{osc} = 0.836 \text{ rad/s}}
$$

> **Problem:** Determine the stability of the polynomial:
>
> $$p(s) = s^5 + 2s^4 + 4s^3 + 8s^2 + 3s + 6$$
>
> Handle any special cases that arise in the Routh array construction.

<details>
<summary>🔍 View Step-by-Step Solution</summary>

#### Step 1: Construct the Routh Array

| Row | $c_1$ | $c_2$ | $c_3$ |
|:---:|:---:|:---:|:---:|
| $s^5$ | 1 | 4 | 3 |
| $s^4$ | 2 | 8 | 6 |
| $s^3$ | $\frac{2(4)-1(8)}{2} = \frac{0}{2} = 0$ | $\frac{2(3)-1(6)}{2} = \frac{0}{2} = 0$ | |

**The entire $s^3$ row is zero!** This is the "row of zeros" special case.

#### Step 2: Interpret the Row of Zeros

A row of zeros indicates that the polynomial has a factor that is an even polynomial (containing only even powers of $s$). This means there are roots that are symmetric about the origin (e.g., $\pm j\omega$ pairs, or $\pm\sigma$ pairs).

#### Step 3: Form the Auxiliary Polynomial

The auxiliary polynomial is formed from the row ABOVE the zero row (the $s^4$ row), using the entries as coefficients of descending even powers:

$$
A(s) = 2s^4 + 8s^2 + 6
$$

Simplify: $A(s) = 2(s^4 + 4s^2 + 3) = 2(s^2+1)(s^2+3)$

#### Step 4: Replace the Zero Row with $dA/ds$

$$
\frac{dA}{ds} = 8s^3 + 16s
$$

Divide by common factor for simplicity: use $8$ and $16$ as the new $s^3$ row entries.

| Row | $c_1$ | $c_2$ | $c_3$ |
|:---:|:---:|:---:|:---:|
| $s^5$ | 1 | 4 | 3 |
| $s^4$ | 2 | 8 | 6 |
| $s^3$ | 8 | 16 | 0 |
| $s^2$ | $\frac{8(8)-2(16)}{8} = \frac{32}{8} = 4$ | $\frac{8(6)-2(0)}{8} = 6$ | |
| $s^1$ | $\frac{4(16)-8(6)}{4} = \frac{16}{4} = 4$ | 0 | |
| $s^0$ | 6 | | |

#### Step 5: Check First Column for Sign Changes

First column: $1, 2, 8, 4, 4, 6$ — **all positive, no sign changes**.

#### Step 6: Analyze the Auxiliary Polynomial Roots

The auxiliary polynomial $A(s) = 2(s^2+1)(s^2+3) = 0$ gives:

$$
s^2 = -1 \implies s = \pm j1
$$

$$
s^2 = -3 \implies s = \pm j\sqrt{3}
$$

These are four roots on the imaginary axis.

#### Step 7: Find the Remaining Root

The original polynomial is degree 5, and the auxiliary polynomial accounts for 4 roots. Factor:

$$
p(s) = (s^4 + 4s^2 + 3)(s + a)
$$

Expand: $(s^4+4s^2+3)(s+a) = s^5 + as^4 + 4s^3 + 4as^2 + 3s + 3a$

Compare with $s^5 + 2s^4 + 4s^3 + 8s^2 + 3s + 6$:

- $s^4$: $a = 2$
- $s^2$: $4a = 8$ ✓
- $s^0$: $3a = 6$ ✓

So $p(s) = (s+2)(s^2+1)(s^2+3)$

#### Step 8: Conclusion

Roots: $s = -2$, $s = \pm j$, $s = \pm j\sqrt{3}$

- One root in LHP ($s = -2$): stable mode
- Four roots on the imaginary axis: **marginally stable** modes

**The system is marginally stable** — it will exhibit sustained oscillations at $\omega = 1$ and $\omega = \sqrt{3}$ rad/s that neither grow nor decay.

$$

## 📘 9. Appendix: Extended Derivations & Special Cases

### 9.1 — The Routh-Hurwitz Criterion: Proof via Continued-Fraction Expansion

The Routh-Hurwitz criterion is not merely an algorithm — it has a deep mathematical foundation rooted in the theory of continued fractions and Sturm sequences. Here we outline the proof.

#### The Setup

Given a polynomial $p(s) = a_0 s^n + a_1 s^{n-1} + \cdots + a_n$ with $a_0 > 0$, we want to determine how many roots lie in the right half-plane without explicitly finding the roots.

#### Step 1: Decompose into Even and Odd Parts

Write $p(s) = p_e(s^2) + s \cdot p_o(s^2)$ where:
- $p_e$ contains all even-power terms
- $p_o$ contains all odd-power terms (with one factor of $s$ removed)

For example, $p(s) = s^3 + 6s^2 + 11s + 6$:
- Even part: $6s^2 + 6 = 6(s^2 + 1)$
- Odd part: $s^3 + 11s = s(s^2 + 11)$, so $p_o = s^2 + 11$

#### Step 2: Form the Continued Fraction

Compute the continued-fraction expansion of $p_e(s^2)/[s \cdot p_o(s^2)]$ (or vice versa, depending on the degree):

$$
\frac{p(s)}{q(s)} = q_1 s + \cfrac{1}{q_2 s + \cfrac{1}{q_3 s + \cfrac{1}{\ddots}}}
$$

where $q(s)$ is the "auxiliary" polynomial formed from the other parity.

The quotients $q_1, q_2, \ldots, q_n$ obtained during this Euclidean-algorithm-like division are precisely the **first-column entries of the Routh array** (up to positive scaling).

#### Step 3: The Cauchy Index Theorem

The number of right half-plane roots equals the number of sign changes in the sequence $\{q_1, q_2, \ldots, q_n\}$.

This follows from the **Cauchy index theorem**: the number of RHP roots of $p(s)$ equals the Cauchy index of the rational function $p_e/p_o$ evaluated along the imaginary axis, which in turn equals the number of sign changes in the continued-fraction quotients.

#### Step 4: Connection to the Routh Array

The Routh array construction is computationally equivalent to performing polynomial long division repeatedly (the Euclidean algorithm on polynomials). Each row of the array corresponds to one step of the division. The first-column entries are proportional to the continued-fraction quotients $q_k$.

Therefore: **the number of sign changes in the first column of the Routh array equals the number of RHP roots.** $\blacksquare$

#### Historical Note

Routh published his criterion in 1877; Hurwitz independently derived the determinant form in 1895. The continued-fraction proof was clarified by Gantmacher (1959) in *The Theory of Matrices*. The connection to Sturm's theorem (1829) for counting real roots of a polynomial in an interval is not coincidental — both rely on the same Euclidean algorithm structure.

### 9.2 — The Hurwitz Determinant Criterion (Alternative Formulation)

#### Statement

The polynomial $p(s) = a_0 s^n + a_1 s^{n-1} + \cdots + a_n$ (with $a_0 > 0$) has all roots in the open left half-plane if and only if all $n$ leading principal minors of the **Hurwitz matrix** are positive.

#### Construction of the Hurwitz Matrix

The $n \times n$ Hurwitz matrix $H$ is constructed as follows:

$$
H_{ij} = a_{2i-j} \quad \text{where } a_k = 0 \text{ if } k < 0 \text{ or } k > n
$$

Explicitly for $n = 4$ ($p(s) = a_0 s^4 + a_1 s^3 + a_2 s^2 + a_3 s + a_4$):

$$
H = \begin{pmatrix} a_1 & a_3 & 0 & 0 \\ a_0 & a_2 & a_4 & 0 \\ 0 & a_1 & a_3 & 0 \\ 0 & a_0 & a_2 & a_4 \end{pmatrix}
$$

#### The Stability Conditions (Hurwitz Determinants)

$$
\Delta_1 = a_1 > 0
$$

$$
\Delta_2 = \det\begin{pmatrix} a_1 & a_3 \\ a_0 & a_2 \end{pmatrix} = a_1 a_2 - a_0 a_3 > 0
$$

$$
\Delta_3 = \det\begin{pmatrix} a_1 & a_3 & 0 \\ a_0 & a_2 & a_4 \\ 0 & a_1 & a_3 \end{pmatrix} > 0
$$

$$
\Delta_4 = a_4 \cdot \Delta_3 > 0
$$

#### Equivalence to Routh's Criterion

The Hurwitz determinants and the Routh first-column entries are related by:

$$
\Delta_k = a_0^{k-1} \cdot \prod_{i=1}^{k} r_i
$$

where $r_i$ is the $i$-th first-column entry of the Routh array (appropriately normalized). Since $a_0 > 0$, the positivity of all $\Delta_k$ is equivalent to the positivity of all $r_i$, confirming that both criteria give identical results.

#### When to Use Which

- **Routh array:** Better for hand computation, especially with symbolic parameters. The recursive structure makes it easy to track how parameters affect stability.
- **Hurwitz determinants:** Better for theoretical proofs and for computer implementation (determinant computation is a standard linear algebra operation).

### 9.3 — Kharitonov's Theorem: Stability Under Interval Uncertainty

#### The Problem

In practice, system parameters are never known exactly. Suppose the characteristic polynomial has coefficients that lie in known intervals:

$$
p(s) = \sum_{k=0}^n a_k s^k, \quad a_k \in [\underline{a}_k, \overline{a}_k]
$$

**Question:** Is the system stable for ALL possible coefficient combinations within these intervals?

Checking every combination is impossible (uncountably many). Kharitonov's remarkable theorem reduces this to checking just **four** specific polynomials.

#### Kharitonov's Theorem (1978)

The entire family of interval polynomials is stable if and only if the following four **Kharitonov polynomials** are all stable:

$$
K_1(s) = \underline{a}_0 + \underline{a}_1 s + \overline{a}_2 s^2 + \overline{a}_3 s^3 + \underline{a}_4 s^4 + \underline{a}_5 s^5 + \cdots
$$

$$
K_2(s) = \underline{a}_0 + \overline{a}_1 s + \overline{a}_2 s^2 + \underline{a}_3 s^3 + \underline{a}_4 s^4 + \overline{a}_5 s^5 + \cdots
$$

$$
K_3(s) = \overline{a}_0 + \underline{a}_1 s + \underline{a}_2 s^2 + \overline{a}_3 s^3 + \overline{a}_4 s^4 + \underline{a}_5 s^5 + \cdots
$$

$$
K_4(s) = \overline{a}_0 + \overline{a}_1 s + \underline{a}_2 s^2 + \underline{a}_3 s^3 + \overline{a}_4 s^4 + \overline{a}_5 s^5 + \cdots
$$

The pattern of $\underline{a}$ (min) and $\overline{a}$ (max) follows a specific alternating scheme with period 4.

#### Example Application

For $p(s) = s^3 + a_2 s^2 + a_1 s + a_0$ with $a_2 \in [5,7]$, $a_1 \in [8,12]$, $a_0 \in [10,20]$:

The four Kharitonov polynomials are:
- $K_1 = 10 + 8s + 7s^2 + s^3$
- $K_2 = 10 + 12s + 7s^2 + s^3$  (note: leading coeff fixed at 1)
- $K_3 = 20 + 8s + 5s^2 + s^3$
- $K_4 = 20 + 12s + 5s^2 + s^3$

Apply Routh to each. If all four are stable, the entire interval family is stable.

**References:** Kharitonov, V.L. (1978), "Asymptotic stability of an equilibrium position of a family of systems of linear differential equations," *Differential Equations*; Bhattacharyya, Chapellat & Keel, *Robust Control: The Parametric Approach* (1995).
