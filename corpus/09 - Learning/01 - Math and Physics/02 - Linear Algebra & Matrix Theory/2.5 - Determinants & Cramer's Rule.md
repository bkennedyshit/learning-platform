# 2.5 — Determinants & Cramer's Rule

> *"The determinant is the shadow that a matrix casts onto the number line — a single number that captures the signed volume scaling of the transformation."*

The determinant is not primarily a computational device. It is a **geometric quantity**: for an $n\times n$ matrix $A$, $|\det A|$ equals the factor by which $A$ scales $n$-dimensional volumes, and $\operatorname{sgn}(\det A)$ encodes whether the transformation preserves or reverses orientation. Every computational formula — cofactor expansion, Leibniz sum — flows from three elegant axioms.

---

## 🎯 Learning Objectives

By the end of this chapter you will be able to:

1. State the three axiomatic properties of the determinant and derive all computational formulas from them.
2. Compute $\det A$ by cofactor expansion along any row or column.
3. Prove and apply $\det(AB) = \det(A)\det(B)$ and $\det(A^T) = \det(A)$.
4. Determine invertibility using the criterion $\det A \neq 0$.
5. Apply **Cramer's Rule** to solve $A\mathbf{x} = \mathbf{b}$ via determinant ratios.
6. Compute the **adjugate** matrix and use $A^{-1} = \operatorname{adj}(A)/\det(A)$.

## 📚 1. Definitions

### Definition 2.5.1 — Determinant (Axiomatic)

The **determinant** is the unique function $\det: M_{n\times n}(\mathbb{F}) \to \mathbb{F}$ satisfying:



**Axiom D1 — Multilinearity in Rows:** $\det$ is linear in each row separately. If $A$ has rows $\mathbf{r}_1, \ldots, \mathbf{r}_n$, then:

$$
\det(\ldots, c\mathbf{r}_i + d\mathbf{s}, \ldots) = c\,\det(\ldots, \mathbf{r}_i, \ldots) + d\,\det(\ldots, \mathbf{s}, \ldots).
$$

**Axiom D2 — Alternating (Sign Reversal on Row Swap):** Interchanging any two rows reverses the sign:

$$
\det(\ldots, \mathbf{r}_i, \ldots, \mathbf{r}_j, \ldots) = -\det(\ldots, \mathbf{r}_j, \ldots, \mathbf{r}_i, \ldots).
$$

**Axiom D3 — Normalization:** $\det(I_n) = 1$.

**Why these axioms?** D1 says det is a multilinear form. D2 says it vanishes when two rows are equal (set $\mathbf{r}_i = \mathbf{r}_j$ in D2 to get $\det = -\det$, hence $\det = 0$). D3 fixes the scale. These three properties uniquely determine $\det$.

### Definition 2.5.2 — Minor and Cofactor

Let $M_{ij}$ be the $(n-1)\times(n-1)$ **minor** matrix obtained by deleting row $i$ and column $j$ from $A$. The **$(i,j)$-cofactor** is:

$$
C_{ij} = (-1)^{i+j} \det(M_{ij}).
$$

The checkerboard sign pattern is: $+$ if $i+j$ is even, $-$ if odd.

### Definition 2.5.3 — Leibniz Formula

For an $n\times n$ matrix $A = (a_{ij})$:

$$
\det A = \sum_{\sigma \in S_n} \operatorname{sgn}(\sigma) \prod_{i=1}^n a_{i,\,\sigma(i)},
$$

where $S_n$ is the symmetric group of all $n!$ permutations of $\{1,\ldots,n\}$, and $\operatorname{sgn}(\sigma) = +1$ if $\sigma$ is an even permutation, $-1$ if odd.

**For $n=2$:** Only two permutations — identity ($++$) and swap ($-$):

$$
\det\begin{pmatrix}a&b\\c&d\end{pmatrix} = a_{1,1}a_{2,2} - a_{1,2}a_{2,1} = ad - bc.
$$

### Definition 2.5.4 — Adjugate (Classical Adjoint)

The **adjugate** of $A$ is the transpose of the cofactor matrix:

$$
\operatorname{adj}(A)_{ij} = C_{ji} = (-1)^{i+j}\det(M_{ji}).
$$

Note the index swap: the $(i,j)$ entry of $\operatorname{adj}(A)$ is the $(j,i)$ cofactor of $A$.

### Definition 2.5.5 — Cramer's Rule Setup

For the linear system $A\mathbf{x} = \mathbf{b}$ with $A \in M_{n\times n}(\mathbb{F})$, $\det A \neq 0$, define $A_i(\mathbf{b})$ as the matrix $A$ with its $i$-th column replaced by $\mathbf{b}$:

$$
A_i(\mathbf{b}) = \bigl[\mathbf{a}_1 \mid \cdots \mid \mathbf{a}_{i-1} \mid \mathbf{b} \mid \mathbf{a}_{i+1} \mid \cdots \mid \mathbf{a}_n\bigr].
$$

---

## 📐 2. Axioms / Postulates

The three axioms D1, D2, D3 above are the foundational postulates. Everything else — Leibniz formula, cofactor expansion, multiplicativity — can be derived from them. This axiomatic approach (due to Weierstrass) is more conceptually clean than starting with a formula.

**Derived fact from D1+D2:** If $A$ has a zero row or two identical rows, then $\det A = 0$.

**Derived fact from D1+D2+D3:** Adding a multiple of one row to another does not change $\det A$. This underpins Gaussian elimination.

---

## 🛡️ 3. Lemmas

### Lemma 2.5.1 — Cofactor Expansion Along Any Row

For any fixed row $i$:

$$
\det A = \sum_{j=1}^n a_{ij} C_{ij} = \sum_{j=1}^n (-1)^{i+j} a_{ij} \det(M_{ij}).
$$

**Proof sketch.** Write each row as a linear combination of standard basis vectors. Apply multilinearity D1 repeatedly to expand $\det A$ into $n^n$ terms. Apply D2 to show all terms where any two row-indices repeat are zero. The surviving terms are exactly the Leibniz sum, which reorganizes into cofactor expansion along any row.

### Lemma 2.5.2 — Cofactor Expansion Along Any Column

$$
\det A = \sum_{i=1}^n a_{ij} C_{ij} = \sum_{i=1}^n (-1)^{i+j} a_{ij} \det(M_{ij})
$$

for any fixed column $j$. This follows from $\det(A^T) = \det(A)$ (Theorem 2.5.2).

### Lemma 2.5.3 — Effect of Row Operations on $\det$

| Row operation | Effect on $\det$ |
|---|---|
| Swap rows $i$ and $j$ | $\det \to -\det$ |
| Scale row $i$ by $c$ | $\det \to c \cdot \det$ |
| Add $c$ times row $j$ to row $i$ | $\det$ unchanged |

## 👑 4. Major Theorems

### Theorem 2.5.1 — Multiplicativity: $\det(AB) = \det(A)\det(B)$

For any $A, B \in M_{n\times n}(\mathbb{F})$:

$$
\det(AB) = \det(A)\,\det(B).
$$

### Theorem 2.5.2 — Transpose Invariance: $\det(A^T) = \det(A)$

The determinant of the transpose equals the determinant of the original matrix. This implies all row results hold equally for columns.

### Theorem 2.5.3 — Invertibility Criterion

$A$ is invertible if and only if $\det(A) \neq 0$.

### Theorem 2.5.4 — Cramer's Rule

Let $A\mathbf{x} = \mathbf{b}$ with $\det(A) \neq 0$. Then the unique solution satisfies:

$$
x_i = \frac{\det(A_i(\mathbf{b}))}{\det(A)}, \quad i = 1, 2, \ldots, n.
$$

### Theorem 2.5.5 — Adjugate Inverse Formula

For any invertible $A$:

$$
A^{-1} = \frac{1}{\det(A)}\,\operatorname{adj}(A).
$$

## ✍️ 5. Proofs

### 5.1 Proof of $\det(AB) = \det(A)\det(B)$ (Theorem 2.5.1)

**Strategy:** Fix $B$ and think of $f(A) = \det(AB)$ as a function of the rows of $A$. We show $f$ satisfies axioms D1, D2, D3 with a proportionality constant of $\det(B)$.

**D1 — Multilinearity:** The $i$-th row of $AB$ is $\mathbf{r}_i B$ (the $i$-th row of $A$ times $B$). If we scale or add the $i$-th row of $A$ by a scalar $c$, the $i$-th row of $AB$ scales by $c$. Since $\det$ is multilinear in rows of $AB$, $f(A) = \det(AB)$ is multilinear in rows of $A$. ✓

**D2 — Alternating:** Swapping rows $i$ and $j$ of $A$ swaps rows $i$ and $j$ of $AB$, which negates $\det(AB)$. So $f$ changes sign under row swaps of $A$. ✓

**D3 — Normalization at $A = I$:** $f(I) = \det(IB) = \det(B)$.

**Conclusion:** $f(A) = \det(AB)$ satisfies D1, D2, and $f(I) = \det(B)$. By uniqueness of the determinant (uniqueness of the multilinear alternating form normalized by its value at $I$), $f(A) = \det(A) \cdot \det(B)$.

$$
\boxed{\det(AB) = \det(A)\det(B).} \quad \blacksquare
$$

**Corollary:** If $A$ is invertible, $\det(A)\det(A^{-1}) = \det(I) = 1$, so $\det(A^{-1}) = 1/\det(A)$.

**Corollary:** $\det(P^{-1}AP) = \det(P^{-1})\det(A)\det(P) = \det(A)$ — similar matrices have equal determinants.

### 5.2 Proof of $\det(A^T) = \det(A)$ (Theorem 2.5.2)

The Leibniz formula is symmetric under transposition: the Leibniz sum over permutations $\sigma$ applied to $A^T$ (whose $(i,j)$ entry is $a_{ji}$) gives:

$$
\det(A^T) = \sum_\sigma \operatorname{sgn}(\sigma) \prod_i (A^T)_{i,\sigma(i)} = \sum_\sigma \operatorname{sgn}(\sigma) \prod_i a_{\sigma(i), i}.
$$

Substitute $\tau = \sigma^{-1}$ (also a permutation with the same sign since $\operatorname{sgn}(\sigma^{-1}) = \operatorname{sgn}(\sigma)$):

$$
= \sum_\tau \operatorname{sgn}(\tau) \prod_i a_{i, \tau(i)} = \det(A). \quad \blacksquare
$$

### 5.3 Proof of Cramer's Rule (Theorem 2.5.4)

**Setup.** Let $\mathbf{x} = A^{-1}\mathbf{b}$ be the unique solution to $A\mathbf{x} = \mathbf{b}$.

**Key observation.** Note that $A \cdot A_i(\mathbf{e}_i) = $ (matrix $A$ multiplied into the matrix that has standard basis $\mathbf{e}_i$ in column $i$). Instead, consider the matrix equation:

$$
A \cdot X_i = A_i(\mathbf{b}),
$$

where $X_i$ is the identity matrix with column $i$ replaced by $\mathbf{x}$. Check: $(AX_i)$'s $k$-th column for $k \neq i$ is $A\mathbf{e}_k = \mathbf{a}_k$ (the $k$-th column of $A$), and the $i$-th column is $A\mathbf{x} = \mathbf{b}$. So $AX_i = A_i(\mathbf{b})$.

Take determinants:

$$
\det(A)\det(X_i) = \det(A_i(\mathbf{b})).
$$

Now $X_i$ is upper triangular with 1s on the diagonal except column $i$ contains $\mathbf{x}$; expanding along column $i$, $\det(X_i) = x_i$ (the $i$-th component of $\mathbf{x}$, since the only non-zero contribution in cofactor expansion along column $i$ is the diagonal entry $x_i$ in row $i$, with sign $(-1)^{i+i} = 1$, times the minor which is the identity block = 1).

Therefore:

$$
x_i = \frac{\det(A_i(\mathbf{b}))}{\det(A)}. \quad \blacksquare
$$


### 5.4 Proof of Adjugate Inverse Formula (Theorem 2.5.5)

**Claim:** $A \cdot \operatorname{adj}(A) = \det(A) \cdot I$.

The $(i,k)$ entry of $A \cdot \operatorname{adj}(A)$ is $\sum_j a_{ij} (\operatorname{adj}(A))_{jk} = \sum_j a_{ij} C_{kj}$.

**Case $i = k$:** This is $\sum_j a_{ij} C_{ij}$ — exactly the cofactor expansion of $\det A$ along row $i$. So the diagonal entries equal $\det A$. ✓

**Case $i \neq k$:** The sum $\sum_j a_{ij} C_{kj}$ is the expansion of $\det B$ where $B$ equals $A$ but with row $k$ replaced by row $i$ (i.e., two identical rows). By D2, $\det B = 0$.

Therefore $A \cdot \operatorname{adj}(A) = \det(A) \cdot I$. Dividing by $\det(A) \neq 0$:

$$
A^{-1} = \frac{1}{\det A}\operatorname{adj}(A). \quad \blacksquare
$$

## 🎯 6. Worked Examples

### Example 2.5.E1 — 2×2 Determinant

$$
\det\begin{pmatrix}5 & 3 \\ 2 & 7\end{pmatrix} = 5 \cdot 7 - 3 \cdot 2 = 35 - 6 = 29.
$$

**Geometric meaning:** The linear map stretches areas by a factor of 29 and preserves orientation.

### Example 2.5.E2 — 3×3 Cofactor Expansion

Compute $\det A$ where $A = \begin{pmatrix}1&2&0\\3&1&4\\0&-1&2\end{pmatrix}$ expanding along row 1.

$$
\det A = 1 \cdot C_{11} + 2 \cdot C_{12} + 0 \cdot C_{13}.
$$

**$C_{11}$:** Delete row 1, col 1: $M_{11} = \begin{pmatrix}1&4\\-1&2\end{pmatrix}$, $\det M_{11} = 2-(-4) = 6$. $C_{11} = (+1)(6) = 6$.

**$C_{12}$:** Delete row 1, col 2: $M_{12} = \begin{pmatrix}3&4\\0&2\end{pmatrix}$, $\det M_{12} = 6-0 = 6$. $C_{12} = (-1)(6) = -6$.

$$
\det A = 1(6) + 2(-6) + 0 = 6 - 12 = -6.
$$

**Verify by expanding along column 3** (has a zero): $0 \cdot C_{13} + 4 \cdot C_{23} + 2 \cdot C_{33}$.

$C_{23}$: $M_{23} = \begin{pmatrix}1&2\\0&-1\end{pmatrix}$, $\det = -1$, $C_{23} = (-1)(-1) = 1$.

$C_{33}$: $M_{33} = \begin{pmatrix}1&2\\3&1\end{pmatrix}$, $\det = 1-6 = -5$, $C_{33} = (+1)(-5) = -5$.

$$
\det A = 0 + 4(1) + 2(-5) = 4 - 10 = -6. \quad \checkmark
$$


### Example 2.5.E3 — Verifying $\det(AB) = \det(A)\det(B)$

Let $A = \begin{pmatrix}1&2\\3&4\end{pmatrix}$, $B = \begin{pmatrix}0&1\\1&0\end{pmatrix}$.

$\det A = 4 - 6 = -2$. $\det B = 0 - 1 = -1$.

$AB = \begin{pmatrix}1\cdot0+2\cdot1 & 1\cdot1+2\cdot0 \\ 3\cdot0+4\cdot1 & 3\cdot1+4\cdot0\end{pmatrix} = \begin{pmatrix}2&1\\4&3\end{pmatrix}$.

$\det(AB) = 6 - 4 = 2$.

Check: $\det(A)\det(B) = (-2)(-1) = 2$. ✓

### Example 2.5.E4 — Cramer's Rule for a 2×2 System

Solve $\begin{cases}3x + y = 7 \\ x + 2y = 4\end{cases}$.

$$
A = \begin{pmatrix}3&1\\1&2\end{pmatrix}, \quad \det A = 6 - 1 = 5. \quad \mathbf{b} = \begin{pmatrix}7\\4\end{pmatrix}.
$$

$$
x_1 = \frac{\det\begin{pmatrix}7&1\\4&2\end{pmatrix}}{\det A} = \frac{14-4}{5} = \frac{10}{5} = 2.
$$

$$
x_2 = \frac{\det\begin{pmatrix}3&7\\1&4\end{pmatrix}}{\det A} = \frac{12-7}{5} = \frac{5}{5} = 1.
$$

Solution: $(x_1, x_2) = (2, 1)$. Verify: $3(2)+1(1) = 7$ ✓, $2+2(1) = 4$ ✓.

### Example 2.5.E5 — Inverse via Adjugate

Find $A^{-1}$ for $A = \begin{pmatrix}2&1\\5&3\end{pmatrix}$.

$\det A = 6 - 5 = 1$.

Cofactors: $C_{11} = 3$, $C_{12} = -5$, $C_{21} = -1$, $C_{22} = 2$.

Adjugate (transpose cofactor matrix):

$$
\operatorname{adj}(A) = \begin{pmatrix}C_{11}&C_{21}\\C_{12}&C_{22}\end{pmatrix} = \begin{pmatrix}3&-1\\-5&2\end{pmatrix}.
$$

$$
A^{-1} = \frac{1}{1}\begin{pmatrix}3&-1\\-5&2\end{pmatrix} = \begin{pmatrix}3&-1\\-5&2\end{pmatrix}.
$$

Check: $AA^{-1} = \begin{pmatrix}2&1\\5&3\end{pmatrix}\begin{pmatrix}3&-1\\-5&2\end{pmatrix} = \begin{pmatrix}1&0\\0&1\end{pmatrix}$. ✓

### Example 2.5.E6 — Leibniz Formula Spot-Check ($3\times3$)

For $A = \begin{pmatrix}1&2&3\\0&4&5\\1&0&6\end{pmatrix}$, the Leibniz sum has $3! = 6$ terms:

| $\sigma$ | $\operatorname{sgn}$ | Product $a_{1\sigma(1)}a_{2\sigma(2)}a_{3\sigma(3)}$ | Value |
|---|---|---|---|
| $(1,2,3)$ | $+1$ | $1\cdot4\cdot6$ | $24$ |
| $(1,3,2)$ | $-1$ | $1\cdot5\cdot0$ | $0$ |
| $(2,1,3)$ | $-1$ | $2\cdot0\cdot6$ | $0$ |
| $(2,3,1)$ | $+1$ | $2\cdot5\cdot1$ | $10$ |
| $(3,1,2)$ | $+1$ | $3\cdot0\cdot0$ | $0$ |
| $(3,2,1)$ | $-1$ | $3\cdot4\cdot1$ | $-12$ |

$$
\det A = 24 + 0 + 0 + 10 + 0 - 12 = 22.
$$

Cofactor expansion along row 1 confirms: $1(24-0) - 2(0-5) + 3(0-4) = 24 + 10 - 12 = 22$. ✓

### Example 2.5.E7 — Determinant Under Row Operations

$A = \begin{pmatrix}1&2\\3&4\end{pmatrix}$, $\det A = -2$. Apply $R_2 \leftarrow R_2 - 3R_1$:

$A' = \begin{pmatrix}1&2\\0&-2\end{pmatrix}$, $\det A' = -2 = \det A$. ✓ (Type-III operation doesn't change det.)

Now scale $R_1 \leftarrow 5R_1$: $A'' = \begin{pmatrix}5&10\\0&-2\end{pmatrix}$, $\det A'' = -10 = 5 \cdot(-2) = 5\det A'$. ✓

### Example 2.5.E8 — Geometric Interpretation (Area Scaling)

The map $T: \mathbf{v} \mapsto A\mathbf{v}$ with $A = \begin{pmatrix}3&1\\1&2\end{pmatrix}$ ($\det A = 5$) maps the unit square (vertices $(0,0),(1,0),(0,1),(1,1)$) to a parallelogram. The image parallelogram has vertices:

$$
A(0,0) = (0,0), \quad A(1,0) = (3,1), \quad A(0,1) = (1,2), \quad A(1,1) = (4,3).
$$

Area of image = $|\det A| \times$ area of unit square $= 5 \times 1 = 5$.

## ⚠️ 7. Common Pitfalls

### Pitfall 1 — Sign Pattern in Cofactor Expansion

The checkerboard signs $(-1)^{i+j}$ are easy to forget. The $(1,1)$ entry is $+$, $(1,2)$ is $-$, $(1,3)$ is $+$, etc. A common error is forgetting the minus sign on $C_{12}$ when expanding along row 1.

### Pitfall 2 — $\det(A+B) \neq \det(A) + \det(B)$

Determinant is **not** additive in matrices. It's multilinear in *rows*, not in the whole matrix at once. Counterexample: $A = B = I_2$, $\det(A+B) = \det(2I) = 4 \neq 1+1 = 2$.

### Pitfall 3 — $\det(kA) = k^n \det(A)$, Not $k \cdot \det(A)$

Scaling the entire $n\times n$ matrix $A$ by $k$ scales each of $n$ rows by $k$, contributing a factor of $k$ per row:

$$
\det(kA) = k^n \det(A).
$$

For $n=3$: $\det(2A) = 8\det(A)$. Students routinely write $2\det(A)$ — wrong by a factor of $2^{n-1}$.

## 📝 8. Challenge Problems

### Problem 2.5.P1

Prove that $\det(A) = 0$ if $A$ has two identical rows.

<details>
<summary>🔍 View Step-by-Step Solution</summary>

Let rows $i$ and $j$ of $A$ be identical, $i \neq j$. Swap rows $i$ and $j$ — but $A$ is unchanged (they're identical). By Axiom D2, $\det(A) = -\det(A)$. Therefore $2\det(A) = 0$, so $\det(A) = 0$ (in any field with $\text{char} \neq 2$). $\blacksquare$

</details>

### Problem 2.5.P2

Compute $\det A$ for $A = \begin{pmatrix}2&-1&3\\0&4&-2\\5&1&0\end{pmatrix}$.

<details>
<summary>🔍 View Step-by-Step Solution</summary>

Expand along row 1:

$C_{11} = (+1)\det\begin{pmatrix}4&-2\\1&0\end{pmatrix} = 0+2 = 2$.

$C_{12} = (-1)\det\begin{pmatrix}0&-2\\5&0\end{pmatrix} = (-1)(0+10) = -10$.

$C_{13} = (+1)\det\begin{pmatrix}0&4\\5&1\end{pmatrix} = 0-20 = -20$.

$$
\det A = 2(2) + (-1)(-10) + 3(-20) = 4 + 10 - 60 = -46.
$$

</details>

### Problem 2.5.P3

Use Cramer's Rule to solve $\begin{cases}x + 2y + z = 6 \\ 2x + y + 3z = 9 \\ x - y + z = 2\end{cases}$.

<details>
<summary>🔍 View Step-by-Step Solution</summary>

$A = \begin{pmatrix}1&2&1\\2&1&3\\1&-1&1\end{pmatrix}$, $\mathbf{b} = (6,9,2)^T$.

$\det A$: expand along row 1: $1(1+3) - 2(2-3) + 1(-2-1) = 4+2-3 = 3$.

$A_1(\mathbf{b})$: replace col 1 by $\mathbf{b}$: $\begin{pmatrix}6&2&1\\9&1&3\\2&-1&1\end{pmatrix}$. $\det = 6(1+3)-2(9-6)+1(-9-2) = 24-6-11 = 7$.

$A_2(\mathbf{b})$: replace col 2: $\begin{pmatrix}1&6&1\\2&9&3\\1&2&1\end{pmatrix}$. $\det = 1(9-6)-6(2-3)+1(4-9) = 3+6-5 = 4$.

Wait — let me redo: $\det(A_2) = 1(9-6) - 6(2-3) + 1(4-9) = 3+6-5 = 4$.

$A_3(\mathbf{b})$: $\begin{pmatrix}1&2&6\\2&1&9\\1&-1&2\end{pmatrix}$. $\det = 1(2+9)-2(4-9)+6(-2-1) = 11+10-18 = 3$.

$$
x = 7/3, \quad y = 4/3, \quad z = 3/3 = 1.
$$

</details>

### Problem 2.5.P4

Prove $\det(A^T) = \det(A)$ using the Leibniz formula directly.

<details>
<summary>🔍 View Step-by-Step Solution</summary>

Already done in §5.2 above. Key step: $(A^T)_{i,\sigma(i)} = A_{\sigma(i),i}$. Substituting $\tau = \sigma^{-1}$ with $\operatorname{sgn}(\tau) = \operatorname{sgn}(\sigma)$ gives $\det(A^T) = \sum_\tau \operatorname{sgn}(\tau)\prod_i A_{i,\tau(i)} = \det A$. $\blacksquare$

</details>

### Problem 2.5.P5

Find the inverse of $A = \begin{pmatrix}1&2&3\\0&1&4\\0&0&1\end{pmatrix}$ using the adjugate.

<details>
<summary>🔍 View Step-by-Step Solution</summary>

$\det A = 1$ (upper triangular, product of diagonal).

Cofactors (non-zero ones): $C_{11}=1, C_{12}=0, C_{13}=0, C_{21}=-2, C_{22}=1, C_{23}=0, C_{31}=5, C_{32}=-4, C_{33}=1$.

$\operatorname{adj}(A) = \begin{pmatrix}1&-2&5\\0&1&-4\\0&0&1\end{pmatrix}$.

$A^{-1} = \begin{pmatrix}1&-2&5\\0&1&-4\\0&0&1\end{pmatrix}$. Check $AA^{-1} = I$. ✓

</details>

### Problem 2.5.P6

Show that for any $n\times n$ matrix $A$ and scalar $k$: $\det(kA) = k^n \det(A)$.

<details>
<summary>🔍 View Step-by-Step Solution</summary>

$kA$ has each of its $n$ rows scaled by $k$. By Axiom D1 (multilinearity), scaling row $i$ by $k$ multiplies $\det$ by $k$. Doing this for all $n$ rows: $\det(kA) = k^n \det(A)$. $\blacksquare$

</details>

### Problem 2.5.P7

Prove that if $A$ is invertible, $\det(A^{-1}) = 1/\det(A)$.

<details>
<summary>🔍 View Step-by-Step Solution</summary>

$AA^{-1} = I$. Take determinants both sides: $\det(A)\det(A^{-1}) = \det(I) = 1$. Dividing: $\det(A^{-1}) = 1/\det(A)$. (Division is valid since $A$ invertible $\Rightarrow \det(A) \neq 0$.) $\blacksquare$

</details>

### Problem 2.5.P8

For a block triangular matrix $M = \begin{pmatrix}A & C \\ 0 & B\end{pmatrix}$ with $A\in M_{p\times p}$, $B \in M_{q\times q}$, show $\det M = \det A \cdot \det B$.

<details>
<summary>🔍 View Step-by-Step Solution</summary>

Expand cofactors along the last $q$ rows (which have the zero block). Inductively, the expansion isolates $\det B$ from the lower-right block and $\det A$ from the upper-left block. Formally, row-reduce $M$ using the $A$-block: the row operations only affect the upper block and $C$, leaving $\det M$ scaled by the determinant of $A$ relative to its own block. Full formal proof by induction on $p$: base $p=1$ is direct cofactor expansion; inductive step uses the block structure. $\det M = \det A \cdot \det B$. $\blacksquare$

</details>
