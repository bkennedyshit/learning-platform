# 2.1 — Vectors & Linear Combinations

> *"The purpose of abstracting the concept of a vector space is that we can then prove theorems about all of its instances simultaneously."* — Sergei Treil, *Linear Algebra Done Wrong*

Vectors are the atoms of linear algebra. Before we can multiply matrices, solve systems, or understand eigenvectors, we need a precise vocabulary for what a vector **is**, how to combine vectors, and what structure those combinations carve out. This chapter builds that vocabulary from the ground up — definitions first, then axioms, then theorems with full proofs — before connecting it to quantum state vectors and differential forms.

---

## 🎯 Learning Objectives

By the end of this chapter you will be able to:

1. Define vectors in ℝⁿ and perform vector addition and scalar multiplication precisely.
2. State all 8 vector space axioms and verify whether a given set satisfies them.
3. Define linear combination, span, linear independence, basis, and dimension.
4. Prove that the span of any set of vectors is a subspace.
5. Test linear independence via row reduction.
6. Prove that every basis of a finite-dimensional space has the same cardinality.
7. Construct a basis for a subspace from a spanning set.

## 📚 1. Definitions

### Definition 2.1.1 — Vectors in ℝⁿ

A **vector** in $\mathbb{R}^n$ is an ordered $n$-tuple of real numbers:

$$
\mathbf{v} = \begin{pmatrix} v_1 \\ v_2 \\ \vdots \\ v_n \end{pmatrix}, \quad v_i \in \mathbb{R}.
$$

We identify $\mathbb{R}^n$ with the set of all such $n$-tuples. The number $n$ is the **dimension** of the ambient space. We write $\mathbf{0}$ for the zero vector $(0, 0, \ldots, 0)^T$.

**Geometric interpretation.** In $\mathbb{R}^2$ and $\mathbb{R}^3$, a vector is a directed arrow from the origin to the point $(v_1, \ldots, v_n)$. The *direction* and *magnitude* are intrinsic; the *starting point* (for a free vector) is irrelevant.

### Definition 2.1.2 — Vector Addition

Given $\mathbf{u}, \mathbf{v} \in \mathbb{R}^n$, their **sum** is defined component-wise:

$$
\mathbf{u} + \mathbf{v} = \begin{pmatrix} u_1 + v_1 \\ u_2 + v_2 \\ \vdots \\ u_n + v_n \end{pmatrix}.
$$

Geometrically in $\mathbb{R}^2$ or $\mathbb{R}^3$, this is the **parallelogram law**: place $\mathbf{v}$ at the tip of $\mathbf{u}$; the resultant is the diagonal (see SVG above).

### Definition 2.1.3 — Scalar Multiplication

For $c \in \mathbb{R}$ and $\mathbf{v} \in \mathbb{R}^n$, the **scalar multiple** is:

$$
c\mathbf{v} = \begin{pmatrix} cv_1 \\ cv_2 \\ \vdots \\ cv_n \end{pmatrix}.
$$


Scalar multiplication stretches ($|c|>1$), shrinks ($|c|<1$), or reverses ($c<0$) the vector.

![[math-02__2.1-fig2.svg|500]]

### Definition 2.1.4 — Linear Combination

A **linear combination** of vectors $\mathbf{v}_1, \ldots, \mathbf{v}_k \in \mathbb{R}^n$ with scalars $c_1, \ldots, c_k \in \mathbb{R}$ is:

$$
c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + \cdots + c_k \mathbf{v}_k = \sum_{i=1}^{k} c_i \mathbf{v}_i.
$$

The scalars $c_i$ are called **coefficients**. Every vector in $\mathbb{R}^n$ can be expressed as a linear combination of the standard basis vectors $\mathbf{e}_1, \ldots, \mathbf{e}_n$.

### Definition 2.1.5 — Span

The **span** of a set $S = \{\mathbf{v}_1, \ldots, \mathbf{v}_k\} \subseteq \mathbb{R}^n$ is the set of all linear combinations:

$$
\operatorname{span}(S) = \left\{ \sum_{i=1}^{k} c_i \mathbf{v}_i \;\middle|\; c_i \in \mathbb{R} \right\}.
$$

We say $S$ **spans** $\mathbb{R}^n$ if $\operatorname{span}(S) = \mathbb{R}^n$. Geometrically, the span of one non-zero vector is a line; the span of two non-collinear vectors is a plane through the origin.

### Definition 2.1.6 — Linear Independence

The set $\{\mathbf{v}_1, \ldots, \mathbf{v}_k\}$ is **linearly independent** if the only solution to

$$
c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + \cdots + c_k \mathbf{v}_k = \mathbf{0}
$$

is $c_1 = c_2 = \cdots = c_k = 0$ (the **trivial solution**). If a non-trivial solution exists (some $c_i \neq 0$), the set is **linearly dependent**.


**Intuition.** Linearly independent vectors point in genuinely different directions — no one of them can be "reached" by combining the others. Dependent vectors lie in a lower-dimensional subspace than they appear to span.

![[math-02__2.1-fig3.svg|500]]

### Definition 2.1.7 — Basis

A **basis** of a vector space $V$ is a set $\mathcal{B} = \{\mathbf{b}_1, \ldots, \mathbf{b}_n\}$ that is:
1. **Linearly independent**, and
2. **Spanning**: $\operatorname{span}(\mathcal{B}) = V$.

Every vector in $V$ can be written as a **unique** linear combination of basis vectors. The coefficients are the **coordinates** of the vector in the basis $\mathcal{B}$.

**Standard basis of $\mathbb{R}^n$.** The vectors $\mathbf{e}_1 = (1,0,\ldots,0)^T$, $\mathbf{e}_2 = (0,1,0,\ldots)^T$, …, $\mathbf{e}_n = (0,\ldots,0,1)^T$ form the standard basis.

![[math-02__2.1-fig4.svg|280]]

### Definition 2.1.8 — Dimension

The **dimension** of a vector space $V$, written $\dim(V)$, is the number of vectors in any basis of $V$. (Theorem 2.1.4 below guarantees this is well-defined — all bases have the same cardinality.) We set $\dim\{\mathbf{0}\} = 0$.

## 📐 2. The Eight Vector Space Axioms

A **vector space** over $\mathbb{R}$ is a set $V$ equipped with two operations — vector addition $(+)$ and scalar multiplication $(\cdot)$ — satisfying the following eight axioms for all $\mathbf{u}, \mathbf{v}, \mathbf{w} \in V$ and all $c, d \in \mathbb{R}$:

| # | Axiom | Statement |
|---|---|---|
| **VS1** | **Closure under addition** | $\mathbf{u} + \mathbf{v} \in V$ |
| **VS2** | **Commutativity** | $\mathbf{u} + \mathbf{v} = \mathbf{v} + \mathbf{u}$ |
| **VS3** | **Associativity of addition** | $(\mathbf{u} + \mathbf{v}) + \mathbf{w} = \mathbf{u} + (\mathbf{v} + \mathbf{w})$ |
| **VS4** | **Additive identity** | $\exists\, \mathbf{0} \in V : \mathbf{v} + \mathbf{0} = \mathbf{v}$ |
| **VS5** | **Additive inverse** | $\forall\, \mathbf{v},\, \exists\, {-\mathbf{v}} \in V : \mathbf{v} + (-\mathbf{v}) = \mathbf{0}$ |
| **VS6** | **Closure under scalar mult.** | $c\mathbf{v} \in V$ |
| **VS7** | **Distributivity (vector sum)** | $c(\mathbf{u} + \mathbf{v}) = c\mathbf{u} + c\mathbf{v}$ |
| **VS8** | **Distributivity (scalar sum)** | $(c + d)\mathbf{v} = c\mathbf{v} + d\mathbf{v}$ |

Two additional properties follow from the axioms (they are not independent):
- **Scalar identity**: $1 \cdot \mathbf{v} = \mathbf{v}$.
- **Associativity of scalar mult.**: $(cd)\mathbf{v} = c(d\mathbf{v})$.

**Why abstract?** These 8 axioms hold not just for $\mathbb{R}^n$ but for spaces of functions, polynomials, matrices, and solutions to differential equations. Every theorem we prove from these axioms applies to all of them simultaneously.

## 🛡️ 3. Lemmas

### Lemma 2.1.1 — Uniqueness of the Zero Vector

In any vector space $V$, the additive identity $\mathbf{0}$ is unique.

**Proof.** Suppose both $\mathbf{0}$ and $\mathbf{0}'$ satisfy the additive identity axiom VS4. Then:

$$
\mathbf{0} = \mathbf{0} + \mathbf{0}' = \mathbf{0}' + \mathbf{0} = \mathbf{0}'.
$$

The first equality uses the property of $\mathbf{0}'$; the second uses commutativity (VS2); the third uses the property of $\mathbf{0}$. Hence $\mathbf{0} = \mathbf{0}'$. $\blacksquare$

### Lemma 2.1.2 — $0 \cdot \mathbf{v} = \mathbf{0}$

For any $\mathbf{v} \in V$, multiplying by the scalar $0 \in \mathbb{R}$ gives the zero vector.

**Proof.** By VS8 (distributivity over scalar sum):

$$
0 \cdot \mathbf{v} = (0 + 0)\mathbf{v} = 0 \cdot \mathbf{v} + 0 \cdot \mathbf{v}.
$$

Add the additive inverse of $0 \cdot \mathbf{v}$ to both sides:

$$
\mathbf{0} = 0 \cdot \mathbf{v} + \mathbf{0} = 0 \cdot \mathbf{v} + (0 \cdot \mathbf{v} - 0 \cdot \mathbf{v}) = 0 \cdot \mathbf{v}.
$$

Hence $0 \cdot \mathbf{v} = \mathbf{0}$. $\blacksquare$

### Lemma 2.1.3 — The Zero Vector is Always Linearly Dependent

Any set containing the zero vector $\mathbf{0}$ is linearly dependent.

**Proof.** Let $S = \{\mathbf{0}, \mathbf{v}_2, \ldots, \mathbf{v}_k\}$. Consider the combination $1 \cdot \mathbf{0} + 0 \cdot \mathbf{v}_2 + \cdots + 0 \cdot \mathbf{v}_k$. By Lemma 2.1.2, $1 \cdot \mathbf{0} = \mathbf{0}$, so the combination equals $\mathbf{0}$ with coefficients not all zero (the coefficient of $\mathbf{0}$ is $1 \neq 0$). Hence $S$ is dependent. $\blacksquare$

## 👑 4. Theorems

### Theorem 2.1.1 — Span is a Subspace

For any $S \subseteq V$, $\operatorname{span}(S)$ is a subspace of $V$.

### Theorem 2.1.2 — Linear Independence Characterization

A set $\{\mathbf{v}_1, \ldots, \mathbf{v}_k\}$ is linearly dependent if and only if at least one vector in the set is a linear combination of the others.

### Theorem 2.1.3 — Basis Characterization

A set $\mathcal{B} \subseteq V$ is a basis for $V$ if and only if every vector in $V$ has a **unique** representation as a linear combination of elements of $\mathcal{B}$.

### Theorem 2.1.4 — All Bases Have the Same Size (Dimension Theorem)

If $V$ is a finite-dimensional vector space, then any two bases of $V$ have the same number of elements.

## ✍️ 5. Proofs / Derivations

### 5.1 Proof of Theorem 2.1.1 — Span is a Subspace

**Setup.** Let $S = \{\mathbf{v}_1, \ldots, \mathbf{v}_k\} \subseteq V$ and $W = \operatorname{span}(S)$. We must verify three conditions for $W$ to be a subspace:
1. $\mathbf{0} \in W$.
2. $W$ is closed under addition: $\mathbf{u}, \mathbf{w} \in W \Rightarrow \mathbf{u} + \mathbf{w} \in W$.
3. $W$ is closed under scalar multiplication: $\mathbf{u} \in W,\, c \in \mathbb{R} \Rightarrow c\mathbf{u} \in W$.

**Condition 1.** The zero vector can be written $\mathbf{0} = 0\mathbf{v}_1 + \cdots + 0\mathbf{v}_k \in W$. ✓

**Condition 2.** Let $\mathbf{u} = \sum_{i=1}^{k} a_i \mathbf{v}_i \in W$ and $\mathbf{w} = \sum_{i=1}^{k} b_i \mathbf{v}_i \in W$. Then:

$$
\mathbf{u} + \mathbf{w} = \sum_{i=1}^{k} a_i \mathbf{v}_i + \sum_{i=1}^{k} b_i \mathbf{v}_i = \sum_{i=1}^{k} (a_i + b_i)\mathbf{v}_i.
$$

The last expression is a linear combination of $S$ (with new coefficients $a_i + b_i \in \mathbb{R}$), so $\mathbf{u} + \mathbf{w} \in W$. ✓

**Condition 3.** Let $\mathbf{u} = \sum_{i=1}^{k} a_i \mathbf{v}_i \in W$ and $c \in \mathbb{R}$. Then:

$$
c\mathbf{u} = c \sum_{i=1}^{k} a_i \mathbf{v}_i = \sum_{i=1}^{k} (ca_i) \mathbf{v}_i.
$$

Each $ca_i \in \mathbb{R}$, so $c\mathbf{u} \in W$. ✓

All three conditions hold, so $W = \operatorname{span}(S)$ is a subspace of $V$. $\blacksquare$

### 5.2 Proof of Theorem 2.1.2 — Dependence ↔ One Vector is Redundant

**($\Rightarrow$)** Assume $\{\mathbf{v}_1, \ldots, \mathbf{v}_k\}$ is linearly dependent. Then there exist scalars $c_1, \ldots, c_k$, not all zero, such that $\sum_{i=1}^k c_i \mathbf{v}_i = \mathbf{0}$. Say $c_j \neq 0$ for some $j$. Isolate $\mathbf{v}_j$:

$$
c_j \mathbf{v}_j = -\sum_{i \neq j} c_i \mathbf{v}_i \implies \mathbf{v}_j = \sum_{i \neq j} \left(-\frac{c_i}{c_j}\right) \mathbf{v}_i.
$$

So $\mathbf{v}_j$ is a linear combination of the others.

**($\Leftarrow$)** Assume $\mathbf{v}_j = \sum_{i \neq j} a_i \mathbf{v}_i$. Rewrite:

$$
\sum_{i \neq j} a_i \mathbf{v}_i - \mathbf{v}_j = \mathbf{0},
$$

which is a dependence relation with coefficient $-1 \neq 0$ on $\mathbf{v}_j$. Hence the set is dependent. $\blacksquare$

### 5.3 Proof of Theorem 2.1.3 — Basis ↔ Unique Coordinates

**($\Rightarrow$)** Suppose $\mathcal{B} = \{\mathbf{b}_1,\ldots,\mathbf{b}_n\}$ is a basis (independent + spanning). Every $\mathbf{v} \in V$ has at least one representation $\mathbf{v} = \sum a_i \mathbf{b}_i$ (spanning). Suppose also $\mathbf{v} = \sum a'_i \mathbf{b}_i$. Subtract:

$$
\mathbf{0} = \mathbf{v} - \mathbf{v} = \sum_{i=1}^{n}(a_i - a'_i)\mathbf{b}_i.
$$

By independence, each $a_i - a'_i = 0$, so $a_i = a'_i$ for all $i$. The representation is unique.

**($\Leftarrow$)** Suppose every $\mathbf{v} \in V$ has a unique representation. Spanning is immediate ($\mathbf{v}$ has *a* representation). For independence: suppose $\sum c_i \mathbf{b}_i = \mathbf{0}$. The trivial combination $\sum 0 \cdot \mathbf{b}_i = \mathbf{0}$ is also a representation of $\mathbf{0}$. By uniqueness, $c_i = 0$ for all $i$. So $\mathcal{B}$ is independent. $\blacksquare$

### 5.4 Proof of Theorem 2.1.4 — All Bases Have the Same Cardinality

**Key lemma (Steinitz Exchange).** If $\{\mathbf{u}_1, \ldots, \mathbf{u}_m\}$ is linearly independent and $\{\mathbf{w}_1, \ldots, \mathbf{w}_n\}$ spans $V$, then $m \leq n$.

*Proof of lemma.* We show by induction that after $k$ steps we can replace $k$ of the $\mathbf{w}_i$'s with $\mathbf{u}_1, \ldots, \mathbf{u}_k$ and still span $V$.

**Base case ($k=0$):** trivially, $\{\mathbf{w}_1, \ldots, \mathbf{w}_n\}$ spans $V$.

**Inductive step:** Assume $\{\mathbf{u}_1, \ldots, \mathbf{u}_k, \mathbf{w}_{k+1}, \ldots, \mathbf{w}_n\}$ spans $V$ (relabeling). Since $\mathbf{u}_{k+1} \in V$, write:

$$
\mathbf{u}_{k+1} = \alpha_1 \mathbf{u}_1 + \cdots + \alpha_k \mathbf{u}_k + \beta_{k+1}\mathbf{w}_{k+1} + \cdots + \beta_n \mathbf{w}_n.
$$

At least one $\beta_j \neq 0$ (otherwise $\mathbf{u}_{k+1}$ is a combination of $\mathbf{u}_1,\ldots,\mathbf{u}_k$, contradicting independence). So we can solve for $\mathbf{w}_j$ and replace it with $\mathbf{u}_{k+1}$; the new set still spans $V$.

After $m$ steps, $\{\mathbf{u}_1, \ldots, \mathbf{u}_m, \mathbf{w}_{j_1}, \ldots\}$ spans $V$ — which requires $m \leq n$ (otherwise we'd run out of $\mathbf{w}$'s).

**Main result.** Let $\mathcal{B}_1$ (size $m$) and $\mathcal{B}_2$ (size $n$) both be bases. $\mathcal{B}_1$ is independent; $\mathcal{B}_2$ spans $V$: by the lemma, $m \leq n$. Swap roles: $\mathcal{B}_2$ is independent; $\mathcal{B}_1$ spans $V$: by the lemma, $n \leq m$. Hence $m = n$. $\blacksquare$

## 🎯 6. Worked Examples

### Example 2.1.E1 — Vector Arithmetic in ℝ³

Let $\mathbf{u} = (2, -1, 3)^T$ and $\mathbf{v} = (-1, 4, 0)^T$. Compute $3\mathbf{u} - 2\mathbf{v}$.

**Step 1.** Scale each vector:

$$
3\mathbf{u} = \begin{pmatrix} 6 \\ -3 \\ 9 \end{pmatrix}, \qquad 2\mathbf{v} = \begin{pmatrix} -2 \\ 8 \\ 0 \end{pmatrix}.
$$

**Step 2.** Subtract component-wise:

$$
3\mathbf{u} - 2\mathbf{v} = \begin{pmatrix} 6-(-2) \\ -3-8 \\ 9-0 \end{pmatrix} = \begin{pmatrix} 8 \\ -11 \\ 9 \end{pmatrix}.
$$

### Example 2.1.E2 — Testing Linear Independence (2 vectors)

Are $\mathbf{v}_1 = (1, 2)^T$ and $\mathbf{v}_2 = (3, 6)^T$ linearly independent?

**Step 1.** Set up $c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 = \mathbf{0}$:

$$
c_1 \begin{pmatrix}1\\2\end{pmatrix} + c_2 \begin{pmatrix}3\\6\end{pmatrix} = \begin{pmatrix}0\\0\end{pmatrix}.
$$

**Step 2.** This gives the system:

$$
c_1 + 3c_2 = 0, \quad 2c_1 + 6c_2 = 0.
$$

**Step 3.** The second equation is $2 \times$ the first — they're identical. The free variable is $c_2$; choose $c_2 = 1 \Rightarrow c_1 = -3$. A non-trivial solution exists.

**Conclusion.** The vectors are **linearly dependent**. Indeed $\mathbf{v}_2 = 3\mathbf{v}_1$.

### Example 2.1.E3 — Testing Linear Independence via Row Reduction (3 vectors)

Are $\mathbf{v}_1=(1,0,2)^T$, $\mathbf{v}_2=(0,1,-1)^T$, $\mathbf{v}_3=(2,3,1)^T$ independent?

**Step 1.** Form the matrix with these columns and row-reduce:

$$
A = \begin{pmatrix} 1 & 0 & 2 \\ 0 & 1 & 3 \\ 2 & -1 & 1 \end{pmatrix}.
$$

**Step 2.** $R_3 \leftarrow R_3 - 2R_1$:

$$
\begin{pmatrix} 1 & 0 & 2 \\ 0 & 1 & 3 \\ 0 & -1 & -3 \end{pmatrix}.
$$

**Step 3.** $R_3 \leftarrow R_3 + R_2$:

$$
\begin{pmatrix} 1 & 0 & 2 \\ 0 & 1 & 3 \\ 0 & 0 & 0 \end{pmatrix}.
$$

**Step 4.** The third row is all zeros ↔ one free variable ↔ **linearly dependent**. Specifically, $\mathbf{v}_3 = 2\mathbf{v}_1 + 3\mathbf{v}_2$.

### Example 2.1.E4 — Finding a Span

What is $\operatorname{span}\{(1,2,3)^T, (2,4,6)^T\}$?

**Step 1.** Notice $(2,4,6)^T = 2(1,2,3)^T$, so both vectors are collinear.

**Step 2.** By Theorem 2.1.2, adding a scalar multiple does not enlarge the span.

**Step 3.** $\operatorname{span}\{(1,2,3)^T\}$ = the line $\{t(1,2,3)^T : t \in \mathbb{R}\}$ through the origin.

### Example 2.1.E5 — Constructing a Basis for a Subspace

Find a basis for the subspace $W = \operatorname{span}\{(1,2,0)^T,(0,1,1)^T,(1,3,1)^T\}$ of $\mathbb{R}^3$.

**Step 1.** Row-reduce the matrix with these three vectors as rows:

$$
\begin{pmatrix} 1 & 2 & 0 \\ 0 & 1 & 1 \\ 1 & 3 & 1 \end{pmatrix} \xrightarrow{R_3 \leftarrow R_3 - R_1} \begin{pmatrix} 1 & 2 & 0 \\ 0 & 1 & 1 \\ 0 & 1 & 1 \end{pmatrix} \xrightarrow{R_3 \leftarrow R_3 - R_2} \begin{pmatrix} 1 & 2 & 0 \\ 0 & 1 & 1 \\ 0 & 0 & 0 \end{pmatrix}.
$$

**Step 2.** Two non-zero rows → 2 pivot positions → $\dim W = 2$.

**Step 3.** The first two original vectors $(1,2,0)^T$ and $(0,1,1)^T$ are linearly independent and span $W$.

**Basis:** $\mathcal{B} = \{(1,2,0)^T,\,(0,1,1)^T\}$.


### Example 2.1.E6 — Dot Product and Angle

Compute the angle between $\mathbf{u} = (1,2,2)^T$ and $\mathbf{v} = (0,1,-1)^T$.

**Step 1.** Dot product: $\mathbf{u} \cdot \mathbf{v} = (1)(0) + (2)(1) + (2)(-1) = 0 + 2 - 2 = 0$.

**Step 2.** Magnitudes: $\|\mathbf{u}\| = \sqrt{1+4+4} = 3$, $\|\mathbf{v}\| = \sqrt{0+1+1} = \sqrt{2}$.

**Step 3.** $\cos\theta = \dfrac{\mathbf{u}\cdot\mathbf{v}}{\|\mathbf{u}\|\|\mathbf{v}\|} = \dfrac{0}{3\sqrt{2}} = 0 \implies \theta = \dfrac{\pi}{2}$.

These vectors are **orthogonal** — the dot product detects perpendicularity exactly.

### Example 2.1.E7 — Cross Product in ℝ³

Compute $\mathbf{u} \times \mathbf{v}$ for $\mathbf{u} = (1,0,0)^T$ and $\mathbf{v} = (0,1,0)^T$.

**Step 1.** Use the determinant formula:

$$
\mathbf{u} \times \mathbf{v} = \begin{vmatrix} \mathbf{e}_1 & \mathbf{e}_2 & \mathbf{e}_3 \\ 1 & 0 & 0 \\ 0 & 1 & 0 \end{vmatrix}.
$$

**Step 2.** Expand along row 1:

$$
= \mathbf{e}_1(0\cdot0 - 0\cdot1) - \mathbf{e}_2(1\cdot0 - 0\cdot0) + \mathbf{e}_3(1\cdot1 - 0\cdot0) = \mathbf{e}_3 = (0,0,1)^T.
$$

The result is perpendicular to both — it's the standard basis vector $\mathbf{e}_3$, as expected.

### Example 2.1.E8 — Gram-Schmidt Step 1 (Orthogonalization)

Orthogonalize $\mathbf{a} = (1,1,0)^T$ and $\mathbf{b} = (1,0,1)^T$.

**Step 1.** Set $\mathbf{q}_1 = \mathbf{a} = (1,1,0)^T$.

**Step 2.** Project $\mathbf{b}$ onto $\mathbf{q}_1$:

$$
\operatorname{proj}_{\mathbf{q}_1}\mathbf{b} = \frac{\mathbf{b} \cdot \mathbf{q}_1}{\mathbf{q}_1 \cdot \mathbf{q}_1}\,\mathbf{q}_1 = \frac{(1)(1)+(0)(1)+(1)(0)}{1+1+0}\,(1,1,0)^T = \frac{1}{2}(1,1,0)^T.
$$

**Step 3.** Subtract to get the orthogonal component:

$$
\mathbf{q}_2 = \mathbf{b} - \operatorname{proj}_{\mathbf{q}_1}\mathbf{b} = (1,0,1)^T - \tfrac{1}{2}(1,1,0)^T = \left(\tfrac{1}{2}, -\tfrac{1}{2}, 1\right)^T.
$$

**Verify:** $\mathbf{q}_1 \cdot \mathbf{q}_2 = \tfrac{1}{2} - \tfrac{1}{2} + 0 = 0$. ✓ The vectors are now orthogonal.

Show that the set $\{(1,2,1)^T,\,(0,1,1)^T,\,(1,3,2)^T\}$ is linearly dependent and express one vector as a combination of the others.

$$
\begin{pmatrix}1&0&1\\2&1&3\\1&1&2\end{pmatrix} \xrightarrow{R_2-2R_1,\,R_3-R_1} \begin{pmatrix}1&0&1\\0&1&1\\0&1&1\end{pmatrix} \xrightarrow{R_3-R_2} \begin{pmatrix}1&0&1\\0&1&1\\0&0&0\end{pmatrix}.
$$

**Step 2.** Third row zeros → dependent. Read off: $x_3$ is free. From $R_2$: $x_2 + x_3 = 0 \Rightarrow x_2 = -x_3$. From $R_1$: $x_1 + x_3 = 0 \Rightarrow x_1 = -x_3$. Set $x_3 = 1$:

**Step 3.** $c_1 = -1, c_2 = -1, c_3 = 1$, so $-\mathbf{v}_1 - \mathbf{v}_2 + \mathbf{v}_3 = \mathbf{0}$, giving $\mathbf{v}_3 = \mathbf{v}_1 + \mathbf{v}_2$.

### Problem 2.1.P2

Let $V = \{f : \mathbb{R} \to \mathbb{R}\}$ (all real-valued functions). Show that $\{1, \sin x, \cos x\}$ is linearly independent.

<details>
<summary>🔍 View Step-by-Step Solution</summary>

**Step 1.** Suppose $c_1 \cdot 1 + c_2 \sin x + c_3 \cos x = 0$ for all $x$.

**Step 2.** Evaluate at $x=0$: $c_1 + 0 + c_3 = 0 \Rightarrow c_1 + c_3 = 0$.

**Step 3.** Differentiate the relation: $c_2 \cos x - c_3 \sin x = 0$ for all $x$.

**Step 4.** Evaluate at $x=0$: $c_2 = 0$. Evaluate at $x=\pi/2$: $-c_3 = 0 \Rightarrow c_3 = 0$.

**Step 5.** Back-substitute into Step 2: $c_1 = 0$.

All coefficients zero → **linearly independent**. $\blacksquare$

</details>


### Problem 2.1.P3

Find a basis for the subspace $W = \{(x,y,z)^T \in \mathbb{R}^3 : x + y - z = 0\}$ and state $\dim W$.

<details>
<summary>🔍 View Step-by-Step Solution</summary>

**Step 1.** The constraint $x + y - z = 0$ gives $x = z - y$. Parameterize with free variables $y = s$, $z = t$:

$$
\begin{pmatrix}x\\y\\z\end{pmatrix} = \begin{pmatrix}t-s\\s\\t\end{pmatrix} = s\begin{pmatrix}-1\\1\\0\end{pmatrix} + t\begin{pmatrix}1\\0\\1\end{pmatrix}.
$$

**Step 2.** Basis: $\mathcal{B} = \{(-1,1,0)^T,\,(1,0,1)^T\}$. These are clearly non-collinear → independent.

**Step 3.** $\dim W = 2$ (a plane through the origin in $\mathbb{R}^3$).

### Problem 2.1.P4

Prove that if $\{\mathbf{v}_1,\mathbf{v}_2,\mathbf{v}_3\}$ is a basis for $\mathbb{R}^3$, then $\{\mathbf{v}_1+\mathbf{v}_2, \mathbf{v}_2+\mathbf{v}_3, \mathbf{v}_1+\mathbf{v}_3\}$ is also a basis.

### Problem 2.1.P6

Show that $\mathbb{R}^n$ has dimension $n$ by proving the standard basis is indeed a basis.

<details>
<summary>🔍 View Step-by-Step Solution</summary>

**Independence.** Suppose $\sum_{i=1}^n c_i \mathbf{e}_i = \mathbf{0}$. The $j$-th component of the left side is $c_j$, so $c_j = 0$ for all $j$.

**Spanning.** Any $\mathbf{v} = (v_1,\ldots,v_n)^T = \sum_{i=1}^n v_i \mathbf{e}_i \in \operatorname{span}\{\mathbf{e}_i\}$.

Hence $\{\mathbf{e}_1,\ldots,\mathbf{e}_n\}$ is a basis. By Theorem 2.1.4, all bases of $\mathbb{R}^n$ have exactly $n$ elements, so $\dim \mathbb{R}^n = n$. $\blacksquare$

</details>

Compute the Gram-Schmidt orthogonalization of $\{(1,1,1)^T,(1,0,0)^T,(0,1,0)^T\}$.

**Step 1.** $\mathbf{q}_1 = (1,1,1)^T$.

**Step 2.** $\mathbf{q}_2 = (1,0,0)^T - \frac{(1,0,0)\cdot(1,1,1)}{3}(1,1,1)^T = (1,0,0)^T - \tfrac{1}{3}(1,1,1)^T = (\tfrac{2}{3},-\tfrac{1}{3},-\tfrac{1}{3})^T$.

### Problem 2.1.P8

Let $W_1 = \operatorname{span}\{(1,0)^T\}$ and $W_2 = \operatorname{span}\{(0,1)^T\}$ in $\mathbb{R}^2$. Show $W_1 + W_2 = \mathbb{R}^2$ and $W_1 \cap W_2 = \{\mathbf{0}\}$.

<details>
<summary>🔍 View Step-by-Step Solution</summary>

**Step 1.** Any $(x,y)^T = x(1,0)^T + y(0,1)^T \in W_1 + W_2$, so $W_1 + W_2 = \mathbb{R}^2$.

**Step 2.** If $\mathbf{v} \in W_1 \cap W_2$, then $\mathbf{v} = a(1,0)^T = b(0,1)^T$ for some $a,b$. This gives $a=0$ (from the second component) and $b=0$ (from the first), so $\mathbf{v} = \mathbf{0}$.

</details>

## ⚠️ 8. Common Pitfalls

1. **Confusing span with subspace.** Every span *is* a subspace (Theorem 2.1.1), but a subspace need not be presented as a span. Always verify the three subspace conditions directly when the set is defined by constraints.

2. **Wrong independence test.** You cannot check independence by looking at pairs only. Three vectors can be pairwise non-collinear yet still be dependent (they might lie in a common plane). Always use the full row-reduction test.

3. **Zero vector kills independence.** Any set containing $\mathbf{0}$ is automatically dependent (Lemma 2.1.3). Many students try to row-reduce a matrix that includes a zero column — don't; conclude dependence immediately.

4. **Dimension vs. ambient dimension.** $\dim W = 2$ inside $\mathbb{R}^5$ means $W$ is a 2D plane, not that $W = \mathbb{R}^2$. The ambient space is still 5D.

5. **Coordinates depend on the basis.** The *same* vector has *different* coordinate tuples in different bases. Coordinates are not intrinsic to the vector; they are relative to a chosen basis.

6. **Span of the empty set.** By convention, $\operatorname{span}(\emptyset) = \{\mathbf{0}\}$, the trivial subspace. This is consistent with the definition (an empty sum equals the additive identity).
