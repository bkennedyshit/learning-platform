## 📚 1. Point-Source Summation

A 3D scene is approximated by $N$ point sources at $(x_i, y_i, z_i)$ with complex amplitudes $A_i$. Field at the hologram plane:
$$
u(x, y) = \sum_{i=1}^{N} A_i\,\frac{e^{ikr_i}}{r_i},\quad r_i = \sqrt{(x-x_i)^2 + (y-y_i)^2 + z_i^2}
$$
$O(N \cdot M)$ where $M$ is hologram pixel count → quickly intractable for full scenes (millions of points × millions of pixels). Hence the algorithmic + neural approaches below.

---

## 🌊 2. Layer-Based + Angular Spectrum

Slice the scene into $K$ depth layers. For each layer $k$ at depth $z_k$:
1. Compute the field as if 2D content at that depth.
2. Propagate to the hologram plane via angular spectrum (one FFT pair per layer).
3. Sum coherently.

Cost: $O(K \cdot M\log M)$ — practical for hundreds of layers and megapixel holograms.

---

## 🔁 3. Gerchberg-Saxton (Phase Retrieval)

Most SLMs are **phase-only**. We need to encode amplitude + phase in a phase-only signal. GS iteration:

```
Given target intensity I_target at the image plane, initialize random phase at hologram plane:
repeat until convergence:
    1. Propagate hologram → image plane.
    2. Replace amplitude with sqrt(I_target); keep phase.
    3. Propagate image → hologram plane.
    4. Set amplitude = 1 at hologram plane (constraint); keep phase.
```

GS reduces speckle but doesn't eliminate it. Modern variants: **Stochastic Gradient Descent (SGD)** on a differentiable propagator, **Wirtinger flow**, **HoloNet**.

---

## 🎯 4. Double-Phase Encoding

A complex field $A e^{i\phi}$ can be encoded as two phase-only patterns averaged:
$$
\phi_a, \phi_b = \phi \pm \arccos(A / A_{max})
$$

Then $\frac{1}{2}(e^{i\phi_a} + e^{i\phi_b}) = A e^{i\phi}$ in the average sense — at the cost of a 4× spatial-bandwidth halving. Used in production holographic displays.

---

## 🧠 5. Neural CGH (Tensor Holography)

MIT's **Tensor Holography** (Shi, Li, Kim, Matusik, 2021) trains a **CNN** to map RGB-D inputs to a phase-only hologram in a forward pass.

> Source: [Tensor Holography project page](https://cgh.csail.mit.edu/) — content rephrased for compliance.

Key ideas:
1. Collect a **dataset of (RGB-D image, ground-truth hologram)** pairs computed via an expensive but accurate solver.
2. Train a CNN to predict the hologram from RGB-D directly.
3. Achieves **real-time** + **photorealistic** + **per-pixel focal control** on consumer hardware.

This is the kind of leap that makes CGH practical in 2026 — and it's directly relevant to AR/VR headsets that want true holographic displays at frame rate.

Other 2026 progress: lightweight complex-valued deformable CNNs for high-quality CGH; large-depth-range layer-based hologram datasets for ML.

## 🛠️ 6. Worked Example (skeleton) — A 3-Point GS Solver in NumPy

```python
import numpy as np
from numpy.fft import fft2, ifft2, fftshift

def angular_spectrum(u, dx, wavelength, z):
    Ny, Nx = u.shape
    fx = np.fft.fftfreq(Nx, dx)
    fy = np.fft.fftfreq(Ny, dx)
    FX, FY = np.meshgrid(fx, fy, indexing='xy')
    k = 2*np.pi/wavelength
    kz_sq = 1 - (wavelength*FX)**2 - (wavelength*FY)**2
    H = np.exp(1j*k*z*np.sqrt(np.maximum(kz_sq, 0)))
    return ifft2(fft2(u) * H)

def gerchberg_saxton(target, dx, wavelength, z, n_iter=200):
    H = np.exp(1j*2*np.pi*np.random.rand(*target.shape))   # init phase
    for _ in range(n_iter):
        I = angular_spectrum(H, dx, wavelength,  z)
        I = np.sqrt(target) * np.exp(1j*np.angle(I))       # constrain amplitude
        H = angular_spectrum(I, dx, wavelength, -z)
        H = np.exp(1j*np.angle(H))                         # phase-only
    return np.angle(H)
```

## ⚠️ 8. Common Misconceptions

- **"Compute a hologram once, done."** Holographic content is per-frame at video rates; algorithmic + neural acceleration is essential.
- **"Phase-only SLMs lose information."** They do — but with proper encoding (double-phase, GS) the *perceived* image is high quality.
- **"Neural CGH replaces classical methods."** It augments — you still need the differentiable propagator (a classical method) inside the training loop.
- **"More iterations = better hologram."** Past a point GS plateaus; modern SGD + custom loss functions converge faster and to better optima.
