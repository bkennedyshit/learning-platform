# 27.7 — SolidWorks: Mechanical CAD, Assemblies & Simulation

> *"SolidWorks fits drawing-first, revision-heavy mechanical design because parametric assemblies and drafting governance stay stable under change."*
> — paraphrased from [SolidWorks vs Fusion 360 (gaugehow 2026)](https://gaugehow.com/cad/solidworks-vs-fusion-360) (rephrased for compliance)

SolidWorks is the mechanical-engineering CAD that runs the manufacturing world. It is more conservative than Fusion (no integrated cloud CAM by default; PDM is a separate paid product) but more rigorous in **drawings, revisions, and assembly behavior at scale**.

In 2026 SolidWorks added **AI-driven documentation** features for auto-dimensioning and bill-of-materials enrichment — bringing it closer to the integrated experience of Fusion while keeping its drafting governance edge.

---

## 🎯 Learning Objectives

1. Author a parametric part using SolidWorks's **feature tree** (sketch → feature → feature).
2. Build assemblies with **mates** (concentric, coincident, distance, angle, parallel, tangent, gear, cam, belt).
3. Produce a **drawing** with views, dimensions, GD&T, and a bill of materials (BOM).
4. Run **SolidWorks Simulation** for static stress, modal, and frequency analyses.
5. Manage configurations + design tables (Excel-driven family of parts).
6. Use **Toolbox** (standard hardware library) without polluting your file vault.
7. Export to STEP / IGES / Parasolid X_T for cross-tool exchange.

## 📚 1. Mental Model — Feature Tree + Mates

```
Part (.SLDPRT)
└─ FeatureManager Tree
   ├─ Sketch1 → Boss-Extrude1
   ├─ Sketch2 → Cut-Extrude1
   ├─ Fillet1
   └─ Hole-Wizard1

Assembly (.SLDASM)
└─ Component instances + Mates
   ├─ Mate1: Concentric (Bolt.Cylinder, Plate.Hole)
   ├─ Mate2: Coincident (Bolt.UnderHead, Plate.Top)
   └─ ...
```

The Parasolid kernel underneath is the same one SiemensNX uses — explains why SolidWorks STEP exports are extremely clean.

## 🧩 2. Sketching + Features

| Tool | Mechanical Equivalent of … |
|---|---|
| Sketch + Smart Dimension | Revit constrained reference planes |
| Boss-Extrude | Wall by face |
| Cut-Extrude | Boolean subtract |
| Hole Wizard | Standardized hole spec (counterbore, countersink, tap) — **not** a manual cut |
| Fillet / Chamfer | Same |
| Mirror / Pattern | Same |
| Sweep / Loft | Curved geometry, profile + path |
| Sheet Metal | Bend, flatten, K-factor — for stamped parts |
| Weldments | Structural members from libraries |

## 🔗 3. Assemblies — Mates That Actually Behave

| Mate | Use |
|---|---|
| Concentric | Cylindrical surfaces aligned |
| Coincident | Two faces flush |
| Distance / Angle | Driven dimension between faces |
| Parallel / Perpendicular / Tangent | Geometric relationships |
| **Width** | Centers a part inside another |
| **Mechanical mates**: Cam, Gear, Hinge, Slot, Belt | For mechanism prototyping |

Best practice:
- Use the **Width** mate to center bolts/screws — avoids over-defining.
- Avoid mating to imported faces — mate to construction planes / axes when possible.
- **SmartMates** (Alt-drag) speed up insertion of fastener stacks.

## 📝 4. Drawings & GD&T

SolidWorks's **drawing environment** (`.SLDDRW`) is industry-standard for shop drawings:

- **Views**: standard 3, projected, section, detail, broken, alternate-position.
- **Dimensioning**: model items + smart dim + ordinate dimensioning.
- **GD&T (Geometric Dimensioning & Tolerancing)**: feature control frames for flatness, parallelism, position, etc. Critical for inspection and CNC.
- **BOM (Bill of Materials)**: linked to the assembly; updates with revisions.

> SolidWorks 2026's AI-driven auto-dimensioning + BOM enrichment shorten this stage substantially. (Source: [CAD Software Hub 2026 buyer's guide](https://www.cadsoftwarehub.com/blog/the-best-3d-cad-software-of-2026-free-paid/) — content rephrased for compliance.)

## ⚙️ 5. Simulation — FEA Without Leaving the CAD

SolidWorks Simulation tiers:
- **SimulationXpress** (free with SolidWorks) — single body, single load.
- **Simulation Standard** — static linear stress, frequency.
- **Simulation Professional** — non-linear, fatigue, drop-test, optimization.
- **Simulation Premium** — composites, dynamic.

Workflow:
1. Define a **Study** (Static, Frequency, Thermal, Drop Test, …).
2. Apply **fixtures** (fixed, hinge, slider).
3. Apply **loads** (force, pressure, gravity, torque).
4. Generate the **mesh** (curvature-based mesher).
5. Run; review **stress, displacement, factor of safety** plots.
6. Iterate the design; the parametric tree means changes re-solve quickly.

## 🗂️ 6. Configurations & Design Tables

Configurations let one part file represent N variants (size 4, 6, 8, 10, 12 mm bolts) without copy-paste:

- Manual configurations or **Excel design table** as a driver.
- Key for **manufacturer libraries** and **fastener stacks**.

## ⚠️ 9. Common Misconceptions

- **"SolidWorks is the same as Inventor."** Different kernels (Parasolid vs ShapeManager / new Inventor 2024+ kernel), different mate semantics, different drawing flavor.
- **"Top-down vs bottom-up assemblies."** Both legitimate. Top-down (skeleton sketch in assembly drives parts) keeps design intent global; bottom-up assembles pre-made parts.
- **"FEA is exact."** It's a discretized approximation — mesh quality matters more than software brand.
- **"Toolbox files in your project = portable."** They are not. Configure Toolbox to read-only and keep a separate, non-Toolbox copy of any fastener you actually save into a project.
