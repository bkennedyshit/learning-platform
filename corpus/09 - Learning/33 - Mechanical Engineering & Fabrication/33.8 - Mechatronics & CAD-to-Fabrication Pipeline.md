# 33.8 — Mechatronics & CAD-to-Fabrication Pipeline

> *"The gap between drawing and device is where projects die. This chapter is how you close it."*

Mechatronics is the intersection of mechanics, electronics, and software — a system that moves, senses, and thinks. This chapter integrates everything from chapters 34.1–33.7 into a complete design-to-fabrication pipeline, with special focus on electronics enclosure design and robotics chassis integration.

---

## 🎯 Learning Objectives

1. Execute the complete **7-stage CAD-to-fabrication pipeline** for a simple mechatronic device.
2. Design electronics enclosures with correct PCB standoff patterns, connector cutouts, and thermal management.
3. Select appropriate **linear motion** and **power transmission** components (rails, screws, belts, gears).
4. Apply **cable management** principles to an electromechanical assembly.
5. Plan a **rapid iteration loop** (print iteration 1 → validate → iterate → commit to metal).
6. Perform **incoming inspection** of fabricated parts against the drawing using calipers and gauges.

## 📚 1. The 7-Stage CAD-to-Fabrication Pipeline

### Stage 1: Concept & Requirements

Before opening CAD:
- Write a **functional specification** (what the device must DO, not how)
- Define **constraints:** space envelope, weight budget, cost ceiling, operating environment, IP rating
- List **interfaces:** PCBs to mount, motors to attach, shafts to seal, wires to route
- Sketch **kinematic diagram**: degrees of freedom, joints, fixed/moving relationships

### Stage 2: CAD Model (FreeCAD)

- Create parametric assembly in FreeCAD
- Start with **top-level assembly** → define envelopes → model individual components
- Import **PCB STEP files** from KiCad → check fit before printing
- Drive critical dimensions from spreadsheet → motor dimensions, PCB standoff positions

### Stage 3: DFM Review

Before fabrication, answer for every part:
- What process makes this? (FDM, CNC, sheet metal, off-the-shelf)
- Is every feature accessible by the manufacturing process?
- Are all tolerances achievable by that process?
- Are there any thin walls, undercuts, or deep pockets that violate DFM rules?
- Can the number of parts be reduced? (DFMA)

### Stage 4: CAM / Slicer

- For **FDM parts:** PrusaSlicer/Cura → slice with correct settings → validate layer preview → start print
- For **CNC parts:** FreeCAD Path → operations → simulate in CAMotics → post-process → G-code file
- For **laser/waterjet:** Export DXF from FreeCAD sketch → upload to cutting service or local machine

### Stage 5: Fabricate

- **3D print:** Monitor first layer adhesion → check first 5 layers → let run
- **CNC:** Air cut first (Z raised 50mm) → check toolpaths in air → lower to actual Z zero → run
- **Order out:** Hubs, SendCutSend, JLCPCB (PCBs), OSH Cut (sheet metal) — all accept STEP/DXF

### Stage 6: Inspect

- Caliper check: all critical dimensions ±0.1mm of drawing
- Thread check: M3 gauge or bolt thread through all tapped holes
- Fit check: dry-assemble with mating parts before final assembly
- Surface check: no sharp burrs on edges (deburr with file or deburring tool)

### Stage 7: Integrate & Test

- Mount electronics → check connector clearances → route cables
- Functional test before sealing enclosure
- Iterate: failed fit → fix CAD → reprint/recut → retest

## 📚 2. Mechatronic System Components

### 2.1 Linear Motion Systems

| System | Accuracy | Speed | Load | Best use |
|--------|---------|-------|------|---------|
| MGN12 linear rail | ±0.01–0.03mm | High | Med | 3D printers, small CNC, robotics |
| Smooth rod + LM8UU | ±0.1–0.3mm | Med | Low-Med | Budget 3D printers, light robotics |
| Leadscrew (T8) | ±0.1mm/mm | Low (for fast) | Med | Z-axis, positioning stages (non-speed) |
| Ball screw (C5) | ±0.01mm | High | High | Precision CNC axes |
| Rack & pinion | ±0.05–0.2mm | High | High | Long travel CNC axes, large format |

### 2.2 Power Transmission

| System | Efficiency | Backlash | Notes |
|--------|-----------|---------|-------|
| GT2 belt (2mm pitch) | ~95% | Low (tensioned) | 3D printers, plotters, light robotics |
| GT3 belt (3mm pitch) | ~96% | Low | Heavier loads than GT2 |
| Roller chain | 97–99% | Medium | High-torque industrial |
| Spur gear | 95–99% | Depends on quality | High torque, short distance |
| Planetary gearbox | 90–98% | Low | High ratio, compact |
| Worm gear | 30–90% | Very low | Self-locking, right-angle, slow |

### 2.3 Actuator Selection

| Actuator | Control | Precision | Notes |
|---------|---------|----------|-------|
| Stepper motor | Open-loop | Medium | Cheap, simple, hold torque without encoder |
| DC servo + encoder | Closed-loop | High | Better dynamic response, current limiting |
| BLDC + ESC | Closed-loop | High | High speed (drones, spindles) |
| Linear actuator (leadscrew) | Open/closed | Medium | Push/pull force, no rotation |
| Pneumatic cylinder | On/off | Low | Fast, high force, noisy |
| Hydraulic cylinder | Valve control | Medium | Very high force, messy |

## 📚 3. Electronics Enclosure Design

### 3.1 PCB Mounting Rules

**Standoff pattern:**
- Minimum 4 mounting holes at corners
- M3 standoffs at ≥ 3mm from PCB edge
- Drill hole for M3: Ø3.2mm + 0.2mm FDM comp = Ø3.4mm in CAD → prints to ~Ø3.2mm
- Standoff height = component height below PCB + 1–2mm clearance
- Standoff height above PCB = tallest component + 3mm clearance

**KiCad → FreeCAD integration:**
1. In KiCad PCB editor: File → Export → STEP
2. In FreeCAD: File → Import → .step → PCB solid appears
3. Create enclosure body → use PCB outline to drive cavity dimensions → check clearances
4. Parametric link: spreadsheet `pcb_w = 80`, `pcb_h = 60` → all enclosure features reference these

### 3.2 Connector Cutouts

| Connector | Cutout size | Clearance added |
|----------|------------|----------------|
| USB-C | 9.5×3.5mm | +0.3mm all sides → 10.1×4.1mm |
| HDMI | 15×6mm | +0.3mm → 15.6×6.6mm |
| 3.5mm jack | Ø8mm circular | +0.4mm → Ø8.4mm |
| XLR | Ø24mm circular | +0.5mm |
| DB9 | 23.5×9mm + screw holes | D-sub cutout standard |
| RJ45 | 14.5×13.5mm | +0.3mm |

**Panel thickness for connectors:** 1.5–3mm optimal. Thicker = mount screws may be too short; thinner = fragile.

### 3.3 Thermal Management

**Heat sources:** CPU/MCU, motor drivers, switching regulators, power resistors

**Thermal path design:**
1. **Identify heat sources** from datasheet: power dissipation = V_DS × I_D for MOSFETs
2. **Mount on heatsink or chassis wall** — thermal paste, ≥ 0.5mm contact surface
3. **Airflow:** Hot air rises. Bottom intake (fan or passive vents) → components → top exhaust
4. **Fan clearance:** ≥ 20mm from any obstruction on intake face; ≥ 10mm on exhaust
5. **Enclosure venting:** IP54 requires labyrinth vents (protects against splash) — more complex than simple holes

### 3.4 IP Rating Reference

| Rating | Dust | Water | Enclosure design |
|-------|------|-------|-----------------|
| IP20 | Protected >12mm | No water protection | Indoor only |
| IP44 | Protected >1mm | Splash any direction | Outdoor covered |
| IP54 | Dust-protected | Splash all directions | Outdoor general |
| IP65 | Dust-tight | Low-pressure jet | Outdoor harsh |
| IP67 | Dust-tight | 30min submersion 1m | Submersible |
| IP68 | Dust-tight | Continuous submersion | Underwater |

**IP54 enclosure design requirements:**
- All seams: 1.5mm groove + 1.8mm cross-section round cord (silicone) gasket
- All penetrations: cable glands or press-fit sealed connectors
- Fastener holes: countersunk + O-ring under screw head

## 📚 4. Cable Management in Mechatronic Assemblies

**Cable failure is a leading cause of field failures in robots.** Poor cable management creates:
- Chafing against sharp edges → insulation failure
- Excessive flex at strain relief points → conductor fatigue
- Pull-out of connectors → intermittent connection
- Interference with moving parts → collision

**Cable management rules:**

1. **Route cables in CAD before fabricating** — if you can't route it in CAD, you can't route it in hardware
2. **Cable channels and clips:** Integrate into enclosure walls; minimum bend radius = 10× cable diameter
3. **Strain relief at all connectors:** Clamp cable body within 20–30mm of connector — load goes to clamp, not pins
4. **Service loops:** 50–100mm slack at every moving joint — allows full range of motion without tension
5. **Moving cable carriers (e-chains):** For linear or rotary axes with cables — maintain minimum bend radius
6. **Colour coding:** Power = red/black; signal = shielded; ethernet = standard colour codes

## 📚 5. Rapid Iteration Strategy

The physical iteration loop is the equivalent of commit-test-fix in software. Budget for it:

```
Iteration 1: FDM PLA (cheap, fast, ~hours)
  Goal: check geometry, fit, cable routing, assembly sequence
  
Iteration 2: FDM PETG/ASA (functional material)
  Goal: check structural integrity, thermal, outdoor durability
  
Iteration 3: CNC Al or final material (if needed)
  Goal: production-representative; stress test; thermal test
  
Production: commit to tooling/process
```

**Print time budget:** A 100mm×60mm×40mm enclosure in PLA at 0.2mm layer, 20% infill: ~4–8 hours. Budget 3 iterations = 12–24 hours print time. This is nothing compared to the cost of committing to CNC tooling on the wrong geometry.

## ⚠️ 6. Common Misconceptions

1. **"I'll figure out cable routing after the enclosure is printed."** This is how you end up with cables that don't fit, connectors that can't be plugged, and enclosures that can't be closed. Route cables in CAD first.

2. **"A printed part that fits in CAD will fit in hardware."** Assembly tolerances, FDM shrinkage, and insert positions all introduce real-world offsets. Dry-assemble before final assembly. Check with a caliper.

3. **"The motor datasheet says the shaft is 8mm — I'll design for exactly 8mm."** Shaft tolerances vary. Measure your actual motor shaft. Design for measured dimension + fit tolerance (H7 bore for shaft coupling).

4. **"I can add the cable holes later."** Sealing cable penetrations is harder to add after the fact. Plan all cable entry/exit points in CAD from the beginning.

5. **"GT2 belt systems don't need tensioning."** All belt systems require proper tension for backlash-free operation. Under-tensioned belts slip and cause missed steps/position errors. Over-tensioned belts wear bearings prematurely.

6. **"Stepper motors will tell you if they're losing steps."** They won't. Steppers fail silently — the motor moves but the control system doesn't know it skipped. Add an encoder for any safety-critical or position-critical application.
