# 33.7 — FreeCAD & Parametric Modelling

> *"Every dimension in your model should be able to answer: where did this number come from?"*

FreeCAD is a free, open-source, fully parametric CAD system capable of everything from simple brackets to full mechanical assemblies. Since v1.0 (2023), the topological naming problem that plagued earlier versions has been largely resolved — FreeCAD is now a credible free alternative to Fusion 360, SolidWorks, and Inventor for mechanical design.

---

## 🎯 Learning Objectives

1. Navigate FreeCAD's workbench architecture and know which workbench to use for each task.
2. Create a fully constrained sketch in Sketcher with geometric and dimensional constraints.
3. Build a parametric solid using Part Design: Pad, Pocket, Revolution, Fillet, Chamfer, Pattern, Mirror.
4. Drive dimensions from a Spreadsheet workbench, creating a design table.
5. Create a multi-view 2D drawing in TechDraw with dimensions, GD&T annotations, and title block.
6. Export STEP for CAM/exchange and STL for 3D printing.

## 📚 1. FreeCAD Architecture

### 1.1 The Workbench System

FreeCAD is organised into **workbenches** — specialised environments each with their own toolbar and menus. You switch between them from the dropdown at the top.

| Workbench | Purpose |
|---------|---------|
| **Sketcher** | 2D constrained profiles — the foundation of all features |
| **Part Design** | Feature-based solid modelling (primary modelling WB) |
| **Part** | Boolean operations on solids (Part::Cut, Fuse, Common) |
| **TechDraw** | 2D drawing generation from 3D models |
| **Path (CAM)** | Toolpath generation from 3D solids |
| **FEM** | Finite element analysis (meshing, loads, results) |
| **Spreadsheet** | Drive model dimensions from cells |
| **Assembly** | Multi-body assembly (FreeCAD 1.0 built-in WB) |
| **Sheet Metal** | Unfold sheet metal parts, bend calculations |

### 1.2 Model Tree (Feature Tree)

The left panel shows the **model tree** (feature stack):
```
Document
└── Part
    └── Body
        ├── Origin (XY, XZ, YZ planes + axes)
        ├── Sketch (profile)
        ├── Pad (extrude sketch)
        ├── Sketch001 (pocket profile)
        ├── Pocket (cut)
        ├── Fillet (edge selection)
        └── Pattern (polar/linear repetition)
```

**Critical concept:** Features reference earlier features. If you delete Sketch, everything that depends on it breaks. Plan your feature stack from bottom up.

## 📚 2. Sketcher — Fully Constrained 2D Profiles

### 2.1 The Constraint System

Sketcher uses two types of constraints:

**Geometric constraints** (fix relationships):
- Coincident: two points share same location
- Parallel: two lines are parallel
- Perpendicular: two lines are at 90°
- Tangent: line is tangent to arc/circle
- Equal: two lengths or radii are equal
- Symmetric: symmetric about a line
- Horizontal / Vertical: line is horizontal or vertical
- Fixed: point is fixed in absolute position

**Dimensional constraints** (fix values):
- Length: fix a line length (Ctrl+Shift+L)
- Radius / Diameter: fix arc/circle size
- Angle: fix angle between lines
- Distance X/Y: fix horizontal or vertical distance between points

### 2.2 Degrees of Freedom (DOF)

A 2D sketch has:
- Each point: 2 DOF (X, Y)
- Each line: 4 DOF (2 end points)
- Each circle: 3 DOF (center X, Y + radius)

**Goal:** Remove ALL DOF = fully constrained sketch.
- Fully constrained: sketch turns **white** — ready for 3D feature
- Under-constrained: sketch stays **blue** — floating geometry (usually fine to pad, but error-prone)
- Over-constrained: sketch turns **red** — error, one or more constraints conflicts with others

### 2.3 Best Practices for Sketching

1. **Sketch on an existing face or datum plane** — not floating in space
2. **Start from origin** — constrain first point to origin or to an existing feature
3. **Constrain geometry, then dimensions** — geometry constraints reduce DOF efficiently
4. **Use construction lines** for reference geometry (toggle with `M` key)
5. **Name your dimensions** — `motor_dia = 30` instead of anonymous `30`

## 📚 3. Part Design — Feature Stack

### 3.1 Additive Features

| Feature | What it does | Usage |
|---------|-------------|-------|
| **Pad** | Extrude sketch by length | Most common — solid extrusion |
| **Revolution** | Rotate sketch around axis | Cylindrical/conical shapes |
| **Loft** | Blend between multiple sketches | Tapered, complex transitions |
| **Sweep** | Extrude profile along a path | Pipes, channels, extrusion profiles |
| **Additive Pipe** | Sweep with path guide | Complex pipe routing |

### 3.2 Subtractive Features

| Feature | What it does |
|---------|-------------|
| **Pocket** | Cut a sketch profile into an existing solid |
| **Hole** | Parametric hole wizard (through, blind, countersink, counterbore, tap) |
| **Groove** | Rotate a sketch as a subtractive operation |
| **Subtractive Loft/Sweep** | Cut complex shapes |

### 3.3 Dress-up Features

| Feature | Guidance |
|---------|---------|
| **Fillet** | Radius on edge(s); specify by edge selection or by rule (all edges ≥ size X) |
| **Chamfer** | Angled cut on edge; standard 45° or 2-length chamfer |
| **Draft** | Taper vertical walls for mould ejection (typically 1–3°) |
| **Thickness** | Shell a solid to uniform wall thickness |

### 3.4 Pattern Features

| Feature | When to use |
|---------|-------------|
| **Linear pattern** | Bolt hole rows, PCB standoffs, fins |
| **Polar pattern** | Bolt circles, symmetric features around an axis |
| **Mirror** | Mirror entire feature stack about a plane |
| **Multi-transform** | Combine multiple transforms |

## 📚 4. Spreadsheet-Driven Parametric Models

The **Spreadsheet workbench** is FreeCAD's design table. Create named cells and reference them in any sketch dimension or feature parameter.

### 4.1 Setup Workflow

1. **Create spreadsheet:** `Spreadsheet → Create spreadsheet` → appears in model tree
2. **Enter parameters:**

| Cell | Alias | Value |
|------|-------|-------|
| A1 | (label) | motor_dia |
| B1 | motor_dia | 30 |
| A2 | (label) | shaft_dia |
| B2 | shaft_dia | 8 |
| A3 | (label) | wall_thick |
| B3 | wall_thick | 3 |

3. **Set aliases:** Right-click B1 → Properties → Alias = `motor_dia`
4. **Reference in sketch:** In sketcher dimensional constraint, type `Spreadsheet.motor_dia` → FreeCAD fetches value from spreadsheet cell

### 4.2 Result

Change `motor_dia` from 30 to 35 in the spreadsheet → **all features that reference it update automatically** → complete rebuild in seconds.

This is the power of parametric design. Your CAD model becomes a design *system*, not a static drawing.

## 📚 5. TechDraw — 2D Drawing Generation

### 5.1 Basic Drawing Workflow

1. Switch to TechDraw workbench
2. `File → New → Drawing` → choose template (A4, A3, A2…)
3. `TechDraw → Insert view → select solid` → front view appears on sheet
4. Right-click view → add projection views (top, right, isometric)
5. `TechDraw → Insert dimension` → click edges/vertices to add dimensions
6. Right-click dimensions → change format (±tolerance, GD&T reference)
7. Add GD&T annotation symbols
8. Edit title block (click text fields)
9. Export: `File → Export → PDF`

### 5.2 Key TechDraw Settings

- **Scale:** Set per-view; different views can have different scales
- **Line format:** Standard ISO or ANSI line weights
- **Section views:** TechDraw → Section view; define cut plane
- **Detail views:** TechDraw → Detail view; select area + set scale
- **Balloon callouts:** For assembly BOM (parts list)

## 📚 6. Export Formats

| Format | Extension | Use case | Notes |
|--------|-----------|---------|-------|
| FreeCAD native | .FCStd | Saving your work | Preserves full parametric tree |
| STEP | .stp / .step | Exchange, CNC/CAM | Lossless solid interchange — use for machining quotes |
| STL | .stl | 3D printing | Mesh only; loses parametric data; set resolution (deviation 0.01mm) |
| 3MF | .3mf | 3D printing | Better than STL (includes colour, units, orientation) |
| IGES | .igs | Legacy exchange | Older format; STEP preferred |
| DXF | .dxf | Laser cutting, sheet metal | 2D profiles from sketches or TechDraw |
| OBJ | .obj | Blender, game engines | Mesh; use for visual/rendering only |
| GLTF | .gltf / .glb | Web, Unity, Godot | Mesh + PBR materials |
| PDF | via TechDraw | Engineering drawings | Print/send to machine shop |

**Critical:** Always save as `.FCStd` as your master file. Only export when needed.

## 🛠️ 7. Worked Example — Parametric Motor Mount Bracket

**Part:** Bracket to mount a 42mm NEMA 17 stepper motor to a 20×20 aluminium extrusion.

### Step 1: Spreadsheet parameters
```
motor_w   = 42     ; NEMA 17 body width
bolt_pcd  = 31     ; bolt pattern PCD
bolt_dia  = 3.2    ; M3 clearance hole
slot_w    = 6.0    ; T-slot nut slot width  
thick     = 3.0    ; bracket thickness
```

### Step 2: Sketcher on XY plane
- Draw 42×42mm square: reference `Spreadsheet.motor_w` × `Spreadsheet.motor_w`
- Add 4 mounting hole circles at PCD/2 diagonal offsets
- Constrain fully: 8 DOF left → add `bolt_pcd` diagonal, `bolt_dia` circles

### Step 3: Part Design features
```
Pad: thick = 3mm
4× Pocket (holes): Ø3.2mm through
2× Slot pockets: 6mm slot width for T-slot nuts
Fillet: 1mm on all outer edges
```

### Step 4: TechDraw drawing
- Front view + top view
- Dimension motor bolt pattern: Ø31 PCD ±0.1mm
- Surface finish note: Ra 3.2 all machined faces
- Material callout: Al 6061-T6

### Step 5: Export
- `.FCStd` to save parametric model
- `.step` for CNC quote
- `.stl` (deviation 0.05mm) for FDM print test

## ⚠️ 8. Common Misconceptions

1. **"FreeCAD is just like Blender for mechanical parts."** Blender is a mesh modeller for artistic work. FreeCAD is a parametric solid modeller driven by constraints and dimensions. The concepts are fundamentally different. Your AET experience (AutoCAD, Revit) translates directly to FreeCAD.

2. **"I should start with Part workbench, not Part Design."** Part workbench is for Boolean operations on finished solids. Part Design is for building solids through a feature stack (sketch → pad → pocket…). Use Part Design for new parts; use Part for combining finished bodies.

3. **"I can just export to STL and machine from that."** STL is a mesh — it has no flat surfaces, just triangles. CNC/CAM requires a solid (STEP or native format) to generate proper toolpaths. Export STEP for machining, STL for printing.

4. **"A fully constrained sketch is harder to edit."** Correct constraints make editing easier — you change one dimension and everything updates consistently. Unconstrained sketches shift unpredictably when modified.

5. **"FreeCAD crashed and I lost my work."** FreeCAD auto-saves backup files. Check: Edit → Preferences → General → Backup. Also: save frequently, use `.FCStd` format, and keep Undo history deep.

6. **"I can use FreeCAD Assembly like SolidWorks."** FreeCAD Assembly (v1.0 built-in) is functional but less mature than SolidWorks. For complex kinematics, Assembly4 plugin adds joint-based assembly. A2plus plugin supports mating constraints. All free.
