# 12.6 — DOM & Browser APIs

> *"The DOM is not slow. Your interaction with it is."* — **Paul Irish**, Chrome DevTools team

> *"jQuery taught us what the DOM API should have been. Then the DOM API caught up."* — **Wes Bos**

You remember the DOM from the Dreamweaver era — `document.getElementById`, `innerHTML`, maybe some jQuery. The modern DOM API is dramatically better: `querySelector`, `classList`, `dataset`, template literals for HTML, `MutationObserver`, `IntersectionObserver`, and native `fetch`. You no longer need jQuery for anything.

This chapter covers the modern browser platform — not just DOM manipulation, but the full suite of APIs that make the browser a powerful application runtime.

---

## 🎯 Learning Objectives

1. **Manipulate the DOM** efficiently using modern selectors, traversal, and mutation methods.
2. **Implement event delegation** and understand the event propagation model (capture/bubble).
3. **Use the Fetch API** with proper error handling, streaming, and cancellation.
4. **Implement lazy loading** with `IntersectionObserver`.
5. **Offload computation** to Web Workers for non-blocking processing.
6. **Build real-time features** with WebSockets.
7. **Understand Service Workers** for offline-first applications.

## 📚 1. Modern DOM Manipulation

### Definition 12.6.1 — Selecting Elements

```javascript
// Single element (first match)
const header = document.querySelector("h1");
const btn = document.querySelector("#submit-btn");
const active = document.querySelector(".card.active");
const dataEl = document.querySelector('[data-role="admin"]');

// Multiple elements (NodeList — iterable!)
const cards = document.querySelectorAll(".card");
cards.forEach((card) => card.classList.add("visible"));

// Convert to array for full array methods
const cardArray = [...document.querySelectorAll(".card")];
const activeCards = cardArray.filter((c) => c.dataset.active === "true");

// Scoped queries (search within an element)
const nav = document.querySelector("nav");
const navLinks = nav.querySelectorAll("a"); // Only links inside nav
```

### Definition 12.6.2 — Creating & Inserting Elements

```javascript
// Create elements
const card = document.createElement("div");
card.className = "card";
card.dataset.id = "42";
card.innerHTML = `
  <h3>${title}</h3>
  <p>${description}</p>
  <button class="btn-primary">View</button>
`;

// Insert methods (modern — no more appendChild only)
parent.append(card);           // End of parent (accepts strings too)
parent.prepend(card);          // Start of parent
sibling.before(card);          // Before sibling
sibling.after(card);           // After sibling
oldElement.replaceWith(card);  // Replace element

// Remove
card.remove(); // Self-removal (no parent.removeChild needed!)

// DocumentFragment for batch inserts (avoids multiple reflows)
const fragment = document.createDocumentFragment();
items.forEach((item) => {
  const li = document.createElement("li");
  li.textContent = item.name;
  fragment.append(li);
});
list.append(fragment); // Single DOM operation
```

```javascript
// Render a list of cards
function renderCards(cards) {
```

## 📚 2. Events & Event Delegation

### Definition 12.6.5 — Event Propagation

```
                    │ CAPTURE PHASE (top → target)
                    ▼
┌─────────────────────────────────────┐
│ window                               │
│  ┌───────────────────────────────┐  │
│  │ document                       │  │
│  │  ┌─────────────────────────┐  │  │
│  │  │ <html>                   │  │  │
│  │  │  ┌───────────────────┐  │  │  │
│  │  │  │ <body>             │  │  │  │
│  │  │  │  ┌─────────────┐  │  │  │  │
│  │  │  │  │ <button> ●   │  │  │  │  │  ← TARGET
│  │  │  │  └─────────────┘  │  │  │  │
│  │  │  └───────────────────┘  │  │  │
│  │  └─────────────────────────┘  │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
                    ▲
                    │ BUBBLE PHASE (target → top)
```

```javascript
// Third argument controls phase
element.addEventListener("click", handler, { capture: true }); // Capture phase
element.addEventListener("click", handler);                     // Bubble phase (default)

// Stop propagation
element.addEventListener("click", (e) => {
  e.stopPropagation();        // Stop bubbling to parent
  e.stopImmediatePropagation(); // Stop other handlers on same element too
  e.preventDefault();          // Prevent default browser behavior
});
```

### Definition 12.6.6 — Event Delegation

Instead of attaching handlers to every child, attach ONE handler to the parent:

```javascript
// ❌ BAD — 1000 event listeners for 1000 items
document.querySelectorAll(".item").forEach((item) => {
  item.addEventListener("click", handleClick);
});

// ✅ GOOD — 1 event listener handles all items (even future ones)
document.querySelector("#item-list").addEventListener("click", (e) => {
  const item = e.target.closest(".item"); // Find the .item ancestor
  if (!item) return; // Click wasn't on an item

  const id = item.dataset.id;
  handleItemClick(id);
});
```

**Why delegation wins:**
- Fewer event listeners = less memory
- Works for dynamically added elements
- Single point of control

### Modern Event Options

```javascript
// Once — auto-removes after first trigger
button.addEventListener("click", handler, { once: true });

// Passive — promises not to call preventDefault (enables scroll optimization)
window.addEventListener("scroll", onScroll, { passive: true });

// Signal — abort-based removal
const controller = new AbortController();
button.addEventListener("click", handler, { signal: controller.signal });
// Later: remove all listeners attached with this signal
controller.abort();
```

## 📚 3. Fetch API

### Definition 12.6.7 — Modern HTTP Requests

```javascript
// Basic GET
const response = await fetch("https://api.example.com/users");
if (!response.ok) throw new Error(`HTTP ${response.status}: ${response.statusText}`);
const users = await response.json();

// POST with JSON body
const newUser = await fetch("https://api.example.com/users", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ name: "Bill", email: "bill@example.com" }),
}).then((r) => {
  if (!r.ok) throw new Error(`HTTP ${r.status}`);
  return r.json();
});

// PUT, PATCH, DELETE
await fetch(`/api/users/${id}`, { method: "DELETE" });
await fetch(`/api/users/${id}`, {
  method: "PATCH",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ name: "William" }),
});
```

### Fetch with AbortController & Timeout

```javascript
async function fetchJSON(url, options = {}) {
  const { timeout = 10000, ...fetchOptions } = options;

  const controller = new AbortController();
  const timeoutId = setTimeout(() => controller.abort(), timeout);

  try {
    const response = await fetch(url, {
      ...fetchOptions,
      signal: AbortSignal.any([
        controller.signal,
        ...(fetchOptions.signal ? [fetchOptions.signal] : []),
      ]),
    });

    if (!response.ok) {
      throw new Error(`HTTP ${response.status}: ${response.statusText}`);
    }

    return await response.json();
  } finally {
    clearTimeout(timeoutId);
  }
}

// Usage
const data = await fetchJSON("/api/data", { timeout: 5000 });
```

### Streaming Responses

```javascript
// Stream a large response (e.g., AI chat completion)
async function streamResponse(url) {
  const response = await fetch(url);
  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  const output = document.getElementById("output");

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    output.textContent += decoder.decode(value, { stream: true });
  }
}

// Upload with progress
async function uploadWithProgress(url, file, onProgress) {
  const xhr = new XMLHttpRequest(); // fetch doesn't support upload progress yet
  
  return new Promise((resolve, reject) => {
    xhr.upload.addEventListener("progress", (e) => {
      if (e.lengthComputable) onProgress(e.loaded / e.total);
    });
    xhr.addEventListener("load", () => resolve(xhr.response));
    xhr.addEventListener("error", reject);
    xhr.open("POST", url);
    xhr.send(file);
  });
}
```

## 📚 4. IntersectionObserver — Visibility Detection

### Definition 12.6.8 — Lazy Loading & Infinite Scroll

`IntersectionObserver` efficiently detects when elements enter/exit the viewport:

```javascript
// Lazy-load images
const imageObserver = new IntersectionObserver(
  (entries, observer) => {
    entries.forEach((entry) => {
      if (entry.isIntersecting) {
        const img = entry.target;
        img.src = img.dataset.src;       // Load the real image
        img.classList.add("loaded");
        observer.unobserve(img);          // Stop watching this image
      }
    });
  },
  {
    rootMargin: "200px", // Start loading 200px before visible
    threshold: 0.1,      // Trigger when 10% visible
  }
);

// Observe all lazy images
document.querySelectorAll("img[data-src]").forEach((img) => {
  imageObserver.observe(img);
});
```

### Infinite Scroll

```javascript
const sentinel = document.getElementById("scroll-sentinel");
let page = 1;
let loading = false;

const scrollObserver = new IntersectionObserver(async ([entry]) => {
  if (entry.isIntersecting && !loading) {
    loading = true;
    const items = await fetchJSON(`/api/items?page=${++page}`);
    renderItems(items);
    loading = false;

    if (items.length === 0) {
      scrollObserver.disconnect(); // No more pages
    }
  }
});

scrollObserver.observe(sentinel);
```

### Scroll-Triggered Animations

```javascript
const animateObserver = new IntersectionObserver(
```

## 📚 5. Web Workers — True Parallelism

### Definition 12.6.9 — Offloading Heavy Computation

Web Workers run JavaScript in a **separate thread**. They can't access the DOM but can perform CPU-intensive work without blocking the UI:

```javascript
// main.js
const worker = new Worker("./worker.js", { type: "module" });

worker.postMessage({ type: "PROCESS", data: largeDataset });

worker.addEventListener("message", (e) => {
  const { type, result } = e.data;
  if (type === "RESULT") {
    renderChart(result);
  }
});

// Terminate when done
worker.terminate();
```

```javascript
// worker.js
self.addEventListener("message", (e) => {
  const { type, data } = e.data;

  if (type === "PROCESS") {
    // Heavy computation — doesn't block UI
    const result = data.map((item) => expensiveTransform(item));
    self.postMessage({ type: "RESULT", result });
  }
});

function expensiveTransform(item) {
  // Simulate heavy work
  let sum = 0;
  for (let i = 0; i < 1_000_000; i++) sum += Math.sqrt(i);
  return { ...item, computed: sum };
}
```

### SharedArrayBuffer & Atomics (Advanced)

```javascript
// Share memory between main thread and worker
const buffer = new SharedArrayBuffer(1024);
const view = new Int32Array(buffer);

// Main thread
worker.postMessage({ buffer });
Atomics.store(view, 0, 42);       // Write atomically
Atomics.notify(view, 0);          // Wake waiting worker

// Worker
Atomics.wait(view, 0, 0);         // Block until notified
const value = Atomics.load(view, 0); // Read atomically
```

## 📚 6. WebSockets — Real-Time Communication

### Definition 12.6.10 — Bidirectional Communication

```javascript
class WebSocketClient {
  #ws = null;
  #url;
  #reconnectDelay = 1000;
  #maxReconnectDelay = 30000;
  #listeners = new Map();

  constructor(url) {
    this.#url = url;
    this.connect();
  }

  connect() {
    this.#ws = new WebSocket(this.#url);

    this.#ws.addEventListener("open", () => {
      console.log("Connected");
      this.#reconnectDelay = 1000; // Reset on successful connection
    });

    this.#ws.addEventListener("message", (event) => {
      const data = JSON.parse(event.data);
      this.#listeners.get(data.type)?.forEach((cb) => cb(data.payload));
    });

    this.#ws.addEventListener("close", () => {
      console.log(`Reconnecting in ${this.#reconnectDelay}ms...`);
      setTimeout(() => this.connect(), this.#reconnectDelay);
      this.#reconnectDelay = Math.min(
        this.#reconnectDelay * 2,
        this.#maxReconnectDelay
      );
    });

    this.#ws.addEventListener("error", (err) => {
      console.error("WebSocket error:", err);
    });
  }

  send(type, payload) {
    if (this.#ws?.readyState === WebSocket.OPEN) {
      this.#ws.send(JSON.stringify({ type, payload }));
    }
  }

  on(type, callback) {
    if (!this.#listeners.has(type)) this.#listeners.set(type, new Set());
    this.#listeners.get(type).add(callback);
    return () => this.#listeners.get(type).delete(callback);
  }

  close() {
    this.#ws?.close();
  }
}

// Usage
const ws = new WebSocketClient("wss://api.example.com/ws");
ws.on("chat:message", (msg) => appendMessage(msg));
ws.send("chat:join", { room: "general" });
```

## 📚 7. Service Workers — Offline & Caching

### Definition 12.6.11 — The Service Worker Lifecycle

```javascript
// Register (in main.js)
if ("serviceWorker" in navigator) {
  const registration = await navigator.serviceWorker.register("/sw.js");
  console.log("SW registered:", registration.scope);
}
```

```javascript
// sw.js — Service Worker
const CACHE_NAME = "app-v1";
const STATIC_ASSETS = ["/", "/index.html", "/styles.css", "/app.js"];

// Install — cache static assets
self.addEventListener("install", (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => cache.addAll(STATIC_ASSETS))
  );
  self.skipWaiting(); // Activate immediately
});

// Activate — clean old caches
self.addEventListener("activate", (event) => {
  event.waitUntil(
    caches.keys().then((keys) =>
      Promise.all(
        keys.filter((k) => k !== CACHE_NAME).map((k) => caches.delete(k))
      )
    )
  );
  self.clients.claim(); // Take control of all pages
});

// Fetch — cache-first strategy
self.addEventListener("fetch", (event) => {
  event.respondWith(
    caches.match(event.request).then((cached) => {
      return cached || fetch(event.request).then((response) => {
        // Cache new responses for next time
        const clone = response.clone();
        caches.open(CACHE_NAME).then((cache) => cache.put(event.request, clone));
        return response;
      });
    })
  );
});
```

### 8.1 — ResizeObserver & IntersectionObserver Patterns

#### IntersectionObserver — Lazy Loading & Infinite Scroll

```js
// Lazy-load images when they enter the viewport
function lazyLoadImages() {
  const observer = new IntersectionObserver(
    (entries, obs) => {
      for (const entry of entries) {
        if (entry.isIntersecting) {
          const img = entry.target;
          img.src = img.dataset.src;
          img.removeAttribute("data-src");
          obs.unobserve(img); // Stop observing once loaded
        }
      }
    },
    {
      rootMargin: "200px", // Start loading 200px before visible
      threshold: 0,
    }
  );

  document.querySelectorAll("img[data-src]").forEach(img => {
    observer.observe(img);
  });

  return observer;
}

// Infinite scroll with IntersectionObserver
function infiniteScroll(container, loadMore) {
  const sentinel = document.createElement("div");
  sentinel.className = "scroll-sentinel";
  container.appendChild(sentinel);

  let loading = false;

  const observer = new IntersectionObserver(
    async ([entry]) => {
      if (entry.isIntersecting && !loading) {
        loading = true;
        const hasMore = await loadMore();
        loading = false;

        if (!hasMore) {
          observer.disconnect();
          sentinel.remove();
        }
      }
    },
    { rootMargin: "500px" } // Trigger 500px before reaching bottom
  );

  observer.observe(sentinel);
  return () => observer.disconnect();
}

// Usage
const cleanup = infiniteScroll(
  document.getElementById("feed"),
  async () => {
    const posts = await fetchNextPage();
    renderPosts(posts);
    return posts.length > 0; // Return false when no more data
  }
);

// Scroll-driven animations (reveal on scroll)
function revealOnScroll(selector, options = {}) {
  const { threshold = 0.2, rootMargin = "0px", once = true } = options;

  const observer = new IntersectionObserver(
    (entries) => {
      for (const entry of entries) {
        if (entry.isIntersecting) {
          entry.target.classList.add("revealed");
          if (once) observer.unobserve(entry.target);
        } else if (!once) {
          entry.target.classList.remove("revealed");
        }
      }
    },
    { threshold, rootMargin }
  );

  document.querySelectorAll(selector).forEach(el => observer.observe(el));
  return observer;
}
```

#### ResizeObserver — Responsive Components Without Media Queries

```js
// Container queries (before CSS container queries existed)
function containerQuery(element, breakpoints) {
  const observer = new ResizeObserver(([entry]) => {
    const width = entry.contentBoxSize[0].inlineSize;

    // Remove all size classes
    for (const bp of Object.keys(breakpoints)) {
      element.classList.remove(bp);
    }

    // Add appropriate class based on width
    for (const [className, minWidth] of Object.entries(breakpoints)) {
      if (width >= minWidth) {
        element.classList.add(className);
      }
    }
  });

  observer.observe(element);
  return () => observer.disconnect();
}

// Usage: component adapts to its container, not viewport
containerQuery(document.querySelector(".card-grid"), {
  "grid-sm": 0,      // < 600px: 1 column
  "grid-md": 600,    // 600-900px: 2 columns
  "grid-lg": 900,    // > 900px: 3 columns
});

// Auto-sizing textarea
function autoResize(textarea) {
  const observer = new ResizeObserver(() => {
    textarea.style.height = "auto";
    textarea.style.height = textarea.scrollHeight + "px";
  });

  observer.observe(textarea);
  textarea.addEventListener("input", () => {
    textarea.style.height = "auto";
    textarea.style.height = textarea.scrollHeight + "px";
  });

  return () => observer.disconnect();
}

// Responsive chart that redraws on container resize
function responsiveChart(container, drawFn) {
  let rafId = null;

  const observer = new ResizeObserver(([entry]) => {
    // Debounce with requestAnimationFrame
    if (rafId) cancelAnimationFrame(rafId);
    rafId = requestAnimationFrame(() => {
      const { inlineSize: width, blockSize: height } = entry.contentBoxSize[0];
      drawFn(container, width, height);
    });
  });

  observer.observe(container);
  return () => {
    observer.disconnect();
    if (rafId) cancelAnimationFrame(rafId);
  };
}
```

### 8.2 — Web Workers vs SharedArrayBuffer

#### Dedicated Web Workers

```js
// main.js — Create and communicate with a worker
const worker = new Worker("./worker.js", { type: "module" });

// Send data to worker
worker.postMessage({ type: "process", data: largeArray });

// Receive results
worker.addEventListener("message", (event) => {
  const { type, result } = event.data;
  if (type === "result") {
    console.log("Processed:", result);
  }
});

// Transfer ownership (zero-copy for ArrayBuffers)
const buffer = new ArrayBuffer(1024 * 1024); // 1MB
worker.postMessage({ type: "heavy", buffer }, [buffer]);
// buffer is now EMPTY in main thread (transferred, not copied)

// Terminate worker
worker.terminate();
```

```js
// worker.js — Runs in separate thread
self.addEventListener("message", (event) => {
  const { type, data, buffer } = event.data;

  switch (type) {
    case "process": {
      // CPU-intensive work doesn't block main thread
      const result = data.map(item => expensiveComputation(item));
      self.postMessage({ type: "result", result });
      break;
    }
    case "heavy": {
      // Work with transferred buffer
      const view = new Float64Array(buffer);
      for (let i = 0; i < view.length; i++) {
        view[i] = Math.sqrt(view[i]);
      }
      // Transfer back
      self.postMessage({ type: "result", buffer }, [buffer]);
      break;
    }
  }
});
```

#### Worker Pool Pattern

```js
// worker-pool.js — Reuse workers for multiple tasks
class WorkerPool {
  #workers = [];
  #queue = [];
  #activeWorkers = new Map();

  constructor(workerUrl, poolSize = navigator.hardwareConcurrency) {
    for (let i = 0; i < poolSize; i++) {
      const worker = new Worker(workerUrl, { type: "module" });
      worker.addEventListener("message", (event) => {
        this.#onWorkerDone(worker, event.data);
      });
      this.#workers.push(worker);
    }
  }

  execute(task) {
    return new Promise((resolve, reject) => {
      const job = { task, resolve, reject };

      const availableWorker = this.#workers.find(
        w => !this.#activeWorkers.has(w)
      );

      if (availableWorker) {
        this.#dispatch(availableWorker, job);
      } else {
        this.#queue.push(job);
      }
    });
  }

  #dispatch(worker, job) {
    this.#activeWorkers.set(worker, job);
    worker.postMessage(job.task);
  }

  #onWorkerDone(worker, result) {
    const job = this.#activeWorkers.get(worker);
    this.#activeWorkers.delete(worker);

    if (result.error) {
      job.reject(new Error(result.error));
    } else {
      job.resolve(result.data);
    }

    // Process next queued job
    const nextJob = this.#queue.shift();
    if (nextJob) {
      this.#dispatch(worker, nextJob);
    }
  }

  terminate() {
    this.#workers.forEach(w => w.terminate());
  }
}

// Usage
const pool = new WorkerPool("./compute-worker.js", 4);

const results = await Promise.all(
  largeDataset.map(chunk => pool.execute({ type: "process", data: chunk }))
);
```

```js
// sw.js — Service Worker (runs in background, intercepts network)
const CACHE_NAME = "app-v2";
const STATIC_ASSETS = [
  "/",
  "/index.html",
  "/styles.css",
  "/app.js",
  "/offline.html",

self.addEventListener("install", (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => {
      return cache.addAll(STATIC_ASSETS);
    })
  );
  self.skipWaiting(); // Activate immediately (don't wait for old SW to die)
});

// Activate: clean up old caches
self.addEventListener("activate", (event) => {
  event.waitUntil(
    caches.keys().then((keys) => {
      return Promise.all(
        keys
          .filter((key) => key !== CACHE_NAME)
          .map((key) => caches.delete(key))
      );
    })
  );
  self.clients.claim(); // Take control of all pages immediately
});

// Fetch: intercept network requests
self.addEventListener("fetch", (event) => {
  const { request } = event;

  // Strategy: Stale-While-Revalidate for API calls
  if (request.url.includes("/api/")) {
    event.respondWith(staleWhileRevalidate(request));
    return;
  }

  // Strategy: Cache-First for static assets
  if (request.destination === "image" || request.url.match(/\.(css|js)$/)) {
    event.respondWith(cacheFirst(request));
    return;
  }

  // Strategy: Network-First for HTML pages
  event.respondWith(networkFirst(request));
});

// Caching strategies
async function cacheFirst(request) {
  const cached = await caches.match(request);
  if (cached) return cached;

  try {
    const response = await fetch(request);
    const cache = await caches.open(CACHE_NAME);
    cache.put(request, response.clone());
    return response;
  } catch {
    return new Response("Offline", { status: 503 });
  }
}

async function networkFirst(request) {
  try {
    const response = await fetch(request);
    const cache = await caches.open(CACHE_NAME);
    cache.put(request, response.clone());
    return response;
  } catch {
    const cached = await caches.match(request);
    return cached || caches.match("/offline.html");
  }
}

async function staleWhileRevalidate(request) {
  const cache = await caches.open(CACHE_NAME);
  const cached = await cache.match(request);

  // Revalidate in background
  const fetchPromise = fetch(request).then((response) => {
    cache.put(request, response.clone());
    return response;
  });

  // Return cached immediately, update cache in background
  return cached || fetchPromise;
}
```

```js
// requestAnimationFrame — sync with display refresh (60fps = 16.67ms budget)
function smoothAnimation(element, duration = 1000) {
  const start = performance.now();
  const initialX = 0;
  const targetX = 300;

  function frame(timestamp) {
    const elapsed = timestamp - start;
    const progress = Math.min(elapsed / duration, 1);

    // Easing function (ease-out cubic)
    const eased = 1 - Math.pow(1 - progress, 3);

    element.style.transform = `translateX(${initialX + (targetX - initialX) * eased}px)`;

    if (progress < 1) {
      requestAnimationFrame(frame);
    }
  }

  requestAnimationFrame(frame);
}

// requestIdleCallback — run non-critical work when browser is idle
function processLargeList(items, processFn) {
  let index = 0;

  function workLoop(deadline) {
    // Process items while we have time remaining in this idle period
    while (index < items.length && deadline.timeRemaining() > 1) {
      processFn(items[index]);
      index++;
    }

    if (index < items.length) {
      // More work to do — schedule next idle callback
      requestIdleCallback(workLoop, { timeout: 2000 }); // Max 2s wait
    }
  }

  requestIdleCallback(workLoop);
}

// Combining both for smooth UI + background work
class Scheduler {
  #highPriority = []; // Visual updates (rAF)
  #lowPriority = [];  // Background work (rIC)
  #running = false;

  scheduleHigh(task) {
    this.#highPriority.push(task);
    this.#start();
  }

  scheduleLow(task) {
    this.#lowPriority.push(task);
    this.#start();
  }

  #start() {
    if (this.#running) return;
    this.#running = true;
    this.#processHigh();
    this.#processLow();
  }

  #processHigh() {
    if (this.#highPriority.length === 0) return;

    requestAnimationFrame(() => {
      const task = this.#highPriority.shift();
      if (task) task();
      this.#processHigh();
    });
  }

  #processLow() {
    if (this.#lowPriority.length === 0) {
      this.#running = false;
      return;
    }

    requestIdleCallback((deadline) => {
      while (this.#lowPriority.length > 0 && deadline.timeRemaining() > 1) {
        const task = this.#lowPriority.shift();
        if (task) task();
      }
      this.#processLow();
    });
  }
}
```

### 9.1 — How the Browser Parses HTML (Preload Scanner & Deferred Execution)

#### The HTML Parsing Pipeline

```
┌─────────────────────────────────────────────────────────────────────┐
│                    BROWSER PARSING PIPELINE                           │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  Network → Bytes → Characters → Tokens → Nodes → DOM Tree          │
│                                                                      │
│  1. NETWORK LAYER                                                    │
│     - TCP connection, TLS handshake                                 │
│     - HTTP response headers (determine encoding, content-type)      │
│     - Streaming: parsing starts BEFORE full download                │
│                                                                      │
│  2. TOKENIZER (Lexer)                                               │
│     - Converts character stream into tokens                         │
│     - Tokens: StartTag, EndTag, Character, Comment, DOCTYPE         │
│     - Runs incrementally as bytes arrive                            │
│                                                                      │
│  3. TREE BUILDER                                                     │
│     - Converts tokens into DOM nodes                                │
│     - Maintains a stack of open elements                            │
│     - Handles implicit tag closing (e.g., <p> inside <p>)          │
│     - Handles error recovery (malformed HTML)                       │
│                                                                      │
│  4. SCRIPT HANDLING (the complex part)                              │
│     - <script> (no attributes): BLOCKS parsing                      │
│       Parser stops → downloads script → executes → resumes         │
│     - <script defer>: Download in parallel, execute after parsing   │
│     - <script async>: Download in parallel, execute ASAP            │
│     - <script type="module">: Deferred by default                   │
│                                                                      │
│  5. PRELOAD SCANNER (speculative parsing)                           │
│     - Runs AHEAD of the main parser while it's blocked             │
│     - Scans upcoming HTML for resources to prefetch                 │
│     - Finds: <img src>, <link href>, <script src>                   │
│     - Starts downloads early (before main parser reaches them)      │
│     - Does NOT build DOM — only discovers resources                 │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

#### Script Loading Strategies

```html
<!-- 1. Regular script — BLOCKS parsing (worst for performance) -->
```

### 9.2 — Critical Rendering Path Optimization

#### The Rendering Pipeline

```
DOM Tree + CSSOM → Render Tree → Layout → Paint → Composite

1. DOM Tree: Built from HTML parsing
2. CSSOM: Built from CSS parsing (BLOCKS rendering until complete!)
3. Render Tree: Combines DOM + CSSOM (only visible elements)
4. Layout (Reflow): Calculate geometry (position, size) of each element
5. Paint: Fill in pixels (colors, borders, shadows, text)
6. Composite: Layer composition (GPU-accelerated transforms, opacity)
```

#### What Triggers Layout (Reflow) — EXPENSIVE

```js
// Reading these properties forces synchronous layout calculation:
element.offsetTop;
element.offsetLeft;
element.offsetWidth;
element.offsetHeight;
element.scrollTop;
element.clientWidth;
element.getBoundingClientRect();
window.getComputedStyle(element);

// LAYOUT THRASHING: alternating reads and writes
// ❌ BAD — forces layout recalculation on EVERY iteration
for (const el of elements) {
  const height = el.offsetHeight;        // READ → forces layout
  el.style.height = (height * 2) + "px"; // WRITE → invalidates layout
  // Next iteration's READ forces ANOTHER layout!
}

// ✅ GOOD — batch reads, then batch writes
const heights = elements.map(el => el.offsetHeight); // All reads first
elements.forEach((el, i) => {
  el.style.height = (heights[i] * 2) + "px"; // All writes after
});

// ✅ BETTER — use requestAnimationFrame to batch DOM writes
function batchDOMUpdates(updates) {
  requestAnimationFrame(() => {
    for (const update of updates) {
      update();
    }
  });
}
```

#### CSS Properties and Their Rendering Cost

```
COMPOSITE ONLY (cheapest — GPU only):
  transform, opacity, filter, will-change
  → No layout, no paint, just GPU layer manipulation

PAINT ONLY (medium — no geometry change):
  color, background, box-shadow, border-color, visibility
  → Repaint affected pixels, no layout recalculation

LAYOUT + PAINT + COMPOSITE (most expensive):
  width, height, padding, margin, top, left, font-size, display
  → Recalculate geometry of element AND all affected elements
  → Then repaint, then composite
```

```js
// Streaming response (process data as it arrives)
async function streamResponse(url) {
  const response = await fetch(url);
  const reader = response.body.getReader();
  const contentLength = +response.headers.get("Content-Length");

  let receivedLength = 0;
  const chunks = [];

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    chunks.push(value);
    receivedLength += value.length;

    // Progress callback
    const progress = (receivedLength / contentLength) * 100;
    updateProgressBar(progress);
  }

  // Combine chunks
  const allChunks = new Uint8Array(receivedLength);
  let position = 0;
  for (const chunk of chunks) {
    allChunks.set(chunk, position);
    position += chunk.length;
  }

  return new TextDecoder().decode(allChunks);
}

// Upload with progress (using XMLHttpRequest — fetch doesn't support upload progress yet)
function uploadWithProgress(url, file, onProgress) {
  return new Promise((resolve, reject) => {
    const xhr = new XMLHttpRequest();
    xhr.open("POST", url);

    xhr.upload.addEventListener("progress", (event) => {
      if (event.lengthComputable) {
        onProgress(event.loaded / event.total);
      }
    });

    xhr.addEventListener("load", () => {
      if (xhr.status >= 200 && xhr.status < 300) {
        resolve(JSON.parse(xhr.responseText));
      } else {
        reject(new Error(`HTTP ${xhr.status}`));
      }
    });

    xhr.addEventListener("error", () => reject(new Error("Network error")));

    const formData = new FormData();
    formData.append("file", file);
    xhr.send(formData);
  });
}

// Fetch with retry, timeout, and caching
class HttpClient {
  #baseUrl;
  #cache = new Map();

  constructor(baseUrl) {
    this.#baseUrl = baseUrl;
  }

  async get(path, options = {}) {
    const { cache = false, ttl = 60000, timeout = 10000, retries = 3 } = options;
    const url = `${this.#baseUrl}${path}`;

    // Check cache
    if (cache) {
      const cached = this.#cache.get(url);
      if (cached && Date.now() - cached.timestamp < ttl) {
        return cached.data;
      }
    }

    // Fetch with timeout and retry
    let lastError;
    for (let attempt = 0; attempt < retries; attempt++) {
      try {
        const response = await fetch(url, {
          signal: AbortSignal.timeout(timeout),
        });

        if (!response.ok) throw new Error(`HTTP ${response.status}`);
        const data = await response.json();

        // Update cache
        if (cache) {
          this.#cache.set(url, { data, timestamp: Date.now() });
        }

        return data;
      } catch (error) {
        lastError = error;
        if (error.name === "AbortError") continue; // Retry on timeout
        if (attempt < retries - 1) {
          await new Promise(r => setTimeout(r, 1000 * (attempt + 1)));
        }
      }
    }
    throw lastError;
  }
}
```

```js
channel.addEventListener("message", (event) => {
  const { type } = event.data;

  switch (type) {
    case "user-logout":
      // Another tab logged out — sync state
      clearSession();
      redirectToLogin();
      break;
    case "theme-change":
      applyTheme(event.data.theme);
      break;
    case "cart-update":
      refreshCart(event.data.cart);
      break;
  }
});

// Close when done
channel.close();

// Leader election (only one tab runs background sync)
class LeaderElection {
  #channel;
  #isLeader = false;
  #heartbeatInterval;

  constructor(channelName) {
    this.#channel = new BroadcastChannel(channelName);
    this.#channel.addEventListener("message", this.#onMessage.bind(this));
    this.#elect();
  }

  get isLeader() { return this.#isLeader; }

  #elect() {
    // Try to become leader
    this.#channel.postMessage({ type: "election", id: this.#id });

    // If no objection within 100ms, we're leader
    setTimeout(() => {
      if (!this.#isLeader) {
        this.#isLeader = true;
        this.#startHeartbeat();
        this.onBecomeLeader?.();
      }
    }, 100);
  }

  #onMessage(event) {
    if (event.data.type === "heartbeat" && event.data.id !== this.#id) {
      // Another leader exists
      this.#isLeader = false;
    }
    if (event.data.type === "leader-died") {
      this.#elect(); // Re-election
    }
  }

  #startHeartbeat() {
    this.#heartbeatInterval = setInterval(() => {
      this.#channel.postMessage({ type: "heartbeat", id: this.#id });
    }, 1000);
  }

  #id = crypto.randomUUID();
}
```
