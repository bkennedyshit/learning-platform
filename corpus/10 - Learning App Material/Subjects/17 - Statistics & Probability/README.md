## 📚 Authoritative Catalogs & Sources

_Pulled verbatim from `Subject_Plan.md §2 — Free Learning Catalog`. Source of truth is the Subject_Plan; this section is a convenience copy._

- **[OpenStax Introductory Statistics 2e](https://openstax.org/details/books/introductory-statistics-2e)** — free, college-grade; covers this full curriculum ← **primary text**
- **[Khan Academy AP Statistics](https://www.khanacademy.org/math/ap-statistics)** — complete AP Stats; excellent practice problems
- **[StatQuest with Josh Starmer (YouTube)](https://www.youtube.com/@statquest)** — the best intuitive statistics explanations on YouTube; machine-learning focus
- **[AP Stats Guy (YouTube)](https://www.youtube.com/@APStatisticsGuy)** — exam-focused; great for AP prep
- **[CrunchIt / StatKey](https://www.lock5stat.com/StatKey/)** — free online simulation tools for bootstrapping, randomization tests
- **[Seeing Theory (Brown University)](https://seeing-theory.brown.edu/)** — free, beautiful interactive visualizations of all probability and stats concepts
- **[R (free)](https://www.r-project.org/) or Python (numpy/scipy/matplotlib)** — for data analysis; drill scripts in this vault use Python
- **[Statmethods.net](https://www.statmethods.net/)** — free R reference; statistics in R
- **[Rossman/Chance ISCAM](http://www.rossmanchance.com/iscam3/)** — free simulation-based statistics curriculum
