┌──────────────────────────────────────────────────────────────────────────────┐
│ 🚀 HOW TO BUILD & RUN                                                        │
└──────────────────────────────────────────────────────────────────────────────┘

Windows:
    1. Install Qt 6.x with MinGW
    2. Add Qt bin to PATH
    3. Run: build.bat
    4. Execute: build\release\MatrixCommander.exe

Linux:
    1. Install: sudo apt-get install qt6-base-dev
    2. Run: chmod +x build.sh && ./build.sh
    3. Execute: ./build/MatrixCommander

macOS:
    1. Install: brew install qt
    2. Run: chmod +x build.sh && ./build.sh
    3. Execute: ./build/MatrixCommander

Alternative (CMake):
    mkdir build && cd build
    cmake ..
    cmake --build .
